# Module 5: Episode Idea Generator

**Purpose:** Generate specific, non-repetitive episode ideas (or guest-angle ideas for interview shows) mapped to Module 4's calendar — adapted from `grow-on-youtube`'s Video Idea Generator.

## Process

1. **For each episode slot, generate one specific idea** within the assigned theme, drawing on Module 3's pains/desires/questions.
2. **For interview-format shows**, generate a specific *angle* per episode rather than just "interview someone in X field" — the angle should be specific enough to guide both guest selection (Module 8) and the question bank, e.g. "a founder who bootstrapped past $1M without ads" rather than "a successful founder."
3. **Check for repetition across the calendar.**
4. **Note each idea's premise** — feeds Module 6's packaging.

## Output format

```
EPISODE IDEAS:
EPISODE [n] — Theme: [x]
Idea/angle: [specific, concrete summary — for interviews, specific enough to guide guest selection]
Premise: [one line]

REPETITION CHECK: [...]
```

## Handoff

Feeds Module 6 (packaging), Module 7 (outline), and Module 8 (guest targeting, if interview-based).
