# Module 4: Content Pillar & Calendar Planner

**Purpose:** Define recurring episode themes/segments and a release calendar — adapted from `30-days-of-content`/`grow-on-youtube`'s equivalent modules.

## Process

1. **Define 3-5 recurring episode themes/segment types** connecting to Module 2's transformation — e.g. for an interview show: "founder stories," "tactical how-to," "industry news reaction." For a solo show: recurring segment formats within each episode work as well as full-episode themes.
2. **Set a realistic release cadence** from Module 1's capacity — podcasting rewards consistency heavily; a reliable weekly or biweekly release beats an ambitious cadence that lapses.
3. **Distribute themes across the calendar** for variety, and plan guest-booking lead time into the calendar if the format is interview-based (guests typically need 2-4+ weeks of lead time).

## Output format

```
EPISODE THEMES/SEGMENTS: [1-5, with job + connection to transformation]
RELEASE CADENCE: [frequency]
CALENDAR: [theme assignment per episode, guest-booking lead time noted if applicable]
```

## Handoff

Feeds Module 5's idea generation and Module 8's guest-booking timeline if interview-based.
