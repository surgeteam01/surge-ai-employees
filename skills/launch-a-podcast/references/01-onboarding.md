## When to run this

First thing, every time — but skip re-asking anything already known. Check whether a `find-your-niche` profile or `write-like-a-human` voice profile exists.

## What to collect (the Podcast Brief)

- **Show concept/name** — what is the show about?
- **Format** — solo/monologue, interview-based, or co-hosted? This is the single biggest decision affecting Module 7 and whether Module 8 is needed at all.
- **Target episode length** — shapes Module 7's pacing plan.
- **Publishing platform(s)** — Spotify, Apple Podcasts, YouTube (as video podcast), or a combination? Affects Module 11's distribution strategy.
- **Production capacity/equipment** — solo with basic mic, a small setup, or full production support?
- **Release cadence goal.**
- **Existing show stats, if any** — downloads, reviews, top episodes.
- **Constraints** — topics to avoid, required disclosures.

## Output format

```
PODCAST BRIEF
Show: [name/concept]
Format: [solo / interview / co-hosted]
Target episode length: [x]
Platforms: [list]
Production capacity: [detail]
Release cadence goal: [detail]
Existing stats: [detail, or "new show"]
Constraints: [list or "none"]
```

## Handoff

Pass this brief forward unchanged to every subsequent module.
