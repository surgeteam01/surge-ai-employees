# Module 10: Show Branding & Audio Identity

**Purpose:** Design the show's consistent audio and visual identity — adapted from `start-a-faceless-channel`'s Channel Branding Without a Face, since a podcast (even one with a visible host) benefits from the same consistency-builds-recognition logic across dozens or hundreds of episodes.

## Process

1. **Design a consistent intro/outro treatment** — the same music, the same spoken introduction format, and the same sign-off across every episode, so a listener recognizes the show within seconds regardless of which episode they've started with.
2. **Design a consistent cover art system** — a strong, simple show-level cover (the primary visual most listeners ever see, shown small in an app list) and, if per-episode art is used, a consistent template (per Module 6) that varies just enough per episode while staying recognizably part of the same show.
3. **Confirm a consistent recurring segment structure** (per Module 7) — the same named segments/format beats appearing episode to episode gives the show a felt identity beyond just content topic.
4. **Confirm the host's (or hosts') on-mic persona stays consistent** — tone, energy, and recurring verbal habits (a signature sign-off line, a recurring phrase) function similarly to `write-like-a-human`'s voice consistency work; if a `write-like-a-human` profile exists for the host, reference it directly here.

## Output format

```
INTRO/OUTRO TREATMENT: [music, spoken format, sign-off — consistent across episodes]
COVER ART SYSTEM: [show-level cover + per-episode template if used]
RECURRING SEGMENT STRUCTURE: [confirmed from Module 7]
HOST PERSONA CONSISTENCY: [tone/energy/signature phrases — reference write-like-a-human profile if it exists]
```

## Handoff

This identity system feeds Module 13's assembly as a standing reference, and every future episode should be checked against it for consistency.
