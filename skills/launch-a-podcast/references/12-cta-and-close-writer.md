# Module 12: CTA & Close Writer

**Purpose:** Write the subscribe/review/follow asks for each episode — reused directly from `sales-page-that-converts`'s CTA & Close Writer logic, sized for a podcast outro's tolerance for a specific, brief ask.

## Process

1. **Write a specific review/rating ask** — "if this episode helped, a quick rating on Apple Podcasts genuinely helps the show reach more people like you" beats a generic "please rate and subscribe."
2. **Write a specific share ask** — pointing to a specific type of person the episode would help, not a generic "share with a friend."
3. **Vary the exact CTA phrasing across episodes** so the outro doesn't feel like a copy-pasted read every time, while keeping the overall outro structure consistent (per Module 10).
4. **Keep total CTA load light** — one or two specific asks per episode outro, not a stacked list.

## Output format

```
EPISODE [n]:
Review/rating ask: [specific copy]
Share ask: [specific copy]
```

## Handoff

Feeds Module 13's assembly, placed in the outro per Module 10's consistent format.
