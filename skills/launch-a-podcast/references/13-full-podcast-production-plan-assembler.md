# Module 13: Full Podcast Production Plan Assembler

**Purpose:** Assemble every prior module's output into one cohesive, ready-to-produce plan — the calendar, packaging, episode outlines, guest prep, branding, and distribution strategy.

## Process

1. **Follow Module 4's calendar** as the skeleton, dropping each episode's package into place: idea/angle (Module 5), title/description/artwork (Module 6), outline (Module 7), guest prep if applicable (Module 8), retention mechanics (Module 9), and CTA (Module 12).
2. **Include the standing brand identity (Module 10) and distribution strategy (Module 11)** as clearly separated sections.
3. **Check that each episode's outline delivers on its packaging's promise.**
4. **Verify nothing was lost**, and that guest-booking lead times (Module 8) are reflected accurately against the calendar dates.

## Output format

```
=== EPISODE CALENDAR ===
[from Module 4]

=== SHOW BRANDING (standing reference) ===
[from Module 10]

=== DISTRIBUTION & DISCOVERABILITY STRATEGY ===
[from Module 11]

=== PER-EPISODE PRODUCTION PACKAGES ===

EPISODE [n] — Release date: [x]
Title: [from Module 6]
Description: [from Module 6]
Outline (cold open → content → outro): [from Module 7, with Module 9's mechanics woven in]
Guest prep (if applicable): [from Module 8]
CTA: [from Module 12]

(repeat per episode)
```

## Handoff

This draft goes straight to Module 14 for scoring before being presented as final.
