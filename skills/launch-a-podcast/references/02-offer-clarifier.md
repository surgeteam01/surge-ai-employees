# Module 2: Offer Clarifier

**Purpose:** Sharpen the show's core value proposition — reused directly from `sales-page-that-converts`'s Offer Clarifier logic.

## Process

1. **State the current show concept in one sentence.**
2. **Stress-test against the Value Equation**: Dream Outcome, Likelihood of Success, Time Delay, Effort & Sacrifice.
3. **Rewrite as a before → after transformation for the listener.**
4. **Check specificity** — a vague show premise produces generic episode topics and forgettable packaging.
5. **Flag anything unprovable or overclaimed.**

## Output format

```
CURRENT SHOW CONCEPT: [one sentence]
WEAKEST LINK: [Dream Outcome / Likelihood / Time / Effort]
SHARPENED CONCEPT: [rewrite]
TRANSFORMATION STATEMENT: [rewrite]
RED FLAGS: [...]
```
