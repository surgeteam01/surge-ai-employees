# Launch a Podcast

A 14-stage pipeline that takes a raw show concept through to a finished, hook- and discoverability-scored podcast production system — content pillars, an episode calendar, episode packaging (title/artwork/description), full episode outlines built for audio-only retention, guest booking and interview prep, show branding, and a distribution strategy suited to how podcast discovery actually works (far less algorithmic than video, far more dependent on reviews, directories, and cross-promotion). Each stage is a focused reference module in `references/`. Run them in order.

This skill reuses the narration/retention/branding logic from `start-a-faceless-channel` and `grow-on-youtube` directly, adapted from video to audio-only delivery, and adds what's genuinely unique to podcasting: guest booking and interview prep, and a discovery strategy built around podcast directories and cross-promotion rather than a recommendation algorithm.

## How to run this skill

1. **Check for an existing Podcast Brief, `find-your-niche` profile, or related content-calendar assets** before re-asking anything.
2. **Work through stages 1–14 in order.**
3. **If the show is interview-format, treat Module 8 as essential, not optional** — a podcast's guest-booking and prep quality directly determines episode quality in a way no other module can compensate for.
4. **Always end with Module 14.**

## Inputs this skill needs (collected in Stage 1)

Show concept/name, format (solo/monologue, interview, co-hosted), target episode length, publishing platform(s) (Spotify, Apple Podcasts, YouTube, etc.), production capacity/equipment, release cadence goal, existing show stats if any, and any constraints.
