# Module 8: Price Point Calculator

**Purpose:** Set the actual number(s) — the module every prior stage has been building toward. This is where strategy, market data, and psychology converge into a specific, defensible price that also clears the business's real cost floor.

## Process

1. **Establish the hard floor first.** From Module 1's cost/margin data, calculate the absolute minimum price per unit/engagement that meets the stated minimum acceptable margin. No output from this module may go below this floor, regardless of what competitive or psychological reasoning suggests — margin math is non-negotiable in a way that positioning strategy isn't.
2. **Establish the ceiling** from Module 5's competitor scan and Module 3's willingness-to-pay signals — the point past which the offer becomes hard to justify given the market and the audience's budget reality, unless the positioning strategy (Module 4) is deliberately premium with strong enough proof to support it.
3. **Triangulate within the floor-to-ceiling range** using three lenses, and reconcile them rather than picking just one:
   - **Cost-plus check**: floor price + target margin.
   - **Competitive anchor**: where this sits relative to Module 5's landscape, consistent with the chosen positioning.
   - **Value-based check**: a fraction of the total value stack (Module 6) or the transformation's real-world worth to the buyer (e.g. a fraction of the cost/revenue the transformation affects) — this ceiling-side check often justifies a higher number than cost-plus alone would suggest.
4. **Apply pricing psychology to the final number**: charm pricing (ending in 7 or 9) for value/mid-market positioning, round numbers for premium positioning (round numbers read as more confident and less "salesy" at the high end), and price-anchoring order effects if presented alongside tiers (Module 7) or the value stack (Module 6).
5. **Sanity-check the final number out loud** against the transformation statement (Module 2) — does this price feel proportionate to what's being promised, or does it feel randomly picked? If it still feels arbitrary, that's a signal to revisit Module 4 or Module 6, not to just pick a different number by feel.

## Output format

```
HARD FLOOR: $[x] — basis: [cost + minimum margin]
CEILING: $[x] — basis: [competitive/willingness-to-pay limit, or "premium — limited only by proof strength"]

TRIANGULATION:
Cost-plus check: $[x]
Competitive anchor check: $[x]
Value-based check: $[x]

FINAL PRICE(S): [$x, or per-tier if tiered]
PSYCHOLOGY APPLIED: [charm pricing / round-number premium / anchor ordering — reasoning]
SANITY CHECK: [does the number feel proportionate to the transformation — yes/no, and why]
```

## Handoff

This is the number every later module builds around. Module 9 must be ready to defend this exact price, Module 11 structures payment around it, and Module 12 presents it — none of those modules should second-guess or silently change the number decided here; if a later stage surfaces a reason to reconsider it, come back to this module explicitly rather than letting the price drift.
