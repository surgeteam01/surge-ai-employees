# Module 8: Cart-Close / Urgency Sequence Writer

**Purpose:** Write the final push sequence as the real cart-close deadline approaches — this converts the readers who were persuaded by the cart-open sequence but hadn't yet acted, using the same honest-urgency standard applied everywhere in this repo.

## Process

1. **Confirm the cart-close date is real before writing a word of this sequence.** A live launch's cart-close date (from Module 4) is genuine — the product is actually unavailable (or reverts to a higher/no price) after this point. Never run this sequence against a fake deadline; if the launch is evergreen (no real close), this module doesn't apply — say so and skip to Module 11.
2. **Confirm sequence length and cadence from Module 4's map.** Cart-close sequences typically run 3-4 emails over the final 24-72 hours, with cadence tightening as the deadline nears (48 hours out, 24 hours out, morning-of, final hours).
3. **Email 1 (deadline announced)** — name the deadline plainly, restate the transformation and the fast-action bonus deadline (from Module 9) if it closes earlier than the cart itself.
4. **Email 2 (mid-countdown)** — answer the single most common last-minute hesitation briefly, referencing the sales page's objection handling rather than repeating it in full.
5. **Final email(s) (last chance)** — short, direct, and honest about the stakes: what happens if they don't act (cart closes, price reverts, bonus disappears) stated factually, not manipulatively. Brevity itself is persuasive here — a long final-hours email reads as anxious, not confident.
6. **Never manufacture guilt or shame**, and never fabricate scarcity beyond the real cart-close date and any real bonus deadlines.

## Output format

```
CART-CLOSE SEQUENCE ([count] emails, cadence: [spacing before deadline]):
REAL DEADLINE: [cart-close date/time, and what actually changes after it]

EMAIL 1 — Deadline Announced
Body: [full email copy]

EMAIL 2 — Mid-Countdown / Objection Reminder
Body: [full email copy]

FINAL EMAIL(S) — Last Chance
Body: [full email copy, stating stakes plainly]
```

## Handoff

Feeds directly into Module 13 for placement as the launch's final sales push, and Module 14 will check whether the urgency used here is both honest and strong enough. If the launch model is evergreen (no cart-close), flag this module as not applicable rather than leaving a placeholder.
