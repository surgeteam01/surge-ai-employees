# Module 5: Pre-Launch Content Sequence Writer

**Purpose:** Write the anticipation-building content that runs before the cart opens — this is what separates a launch from a plain product announcement. Good pre-launch content builds belief in the transformation and creates real anticipation, so that by the time the cart opens, the audience is already halfway sold.

## Process

1. **Confirm length and format from Module 4's map.** A typical 3-part pre-launch sequence (delivered as email, video, or both, depending on Module 1's platform/voice):
   - **Content 1 — Opportunity**: reframe the problem and show the audience the scale of what's possible, using the top pain/desire from Module 3. This piece should be genuinely valuable on its own, not just a teaser.
   - **Content 2 — Transformation/proof**: go deeper into how the transformation actually happens, woven with a specific case study or result (from proof gathered separately, or flagged as a gap if none exists yet). This is where belief in the mechanism gets built.
   - **Content 3 — Ownership/objection-softening**: help the audience see themselves succeeding specifically, address the most common hesitation head-on (without pitching yet), and explicitly announce that the cart is opening soon, with the date.
2. **End every piece with a soft loop toward cart-open** — not a hard pitch, but a clear, building sense that something is coming, so the cart-open announcement doesn't arrive as a surprise.
3. **Use the exact-phrase bank from Module 3** throughout so the content feels like it's speaking directly to this specific audience's situation, not generic pre-launch hype.
4. **Adjust depth to awareness stage and list warmth** — a cold, less-aware list needs all three pieces to do real persuasive work; a warm, highly aware list (existing customers, an engaged waitlist) can compress this to a single announcement-style piece focused on excitement rather than education.

## Output format

```
PRE-LAUNCH CONTENT ([count] pieces):

CONTENT 1 — Opportunity
Body/script: [full content]
Soft loop: [line pointing toward what's coming]

CONTENT 2 — Transformation/Proof
Body/script: [full content]
Soft loop: [line pointing toward what's coming]

CONTENT 3 — Ownership/Objection-Softening
Body/script: [full content, including the cart-open date announcement]
```

## Handoff

This sequence should end in a way that makes Module 7's cart-open announcement feel like the natural next beat, not a new topic. If proof wasn't available for Content 2, flag it plainly and recommend either a founder-story substitute or gathering a beta result first.
