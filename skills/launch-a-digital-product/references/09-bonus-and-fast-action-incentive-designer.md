# Module 9: Bonus & Fast-Action Incentive Designer

**Purpose:** Design a fast-action bonus — a real incentive for buying early in the cart-open window rather than waiting until the last hour — which spreads sales across the launch instead of concentrating them all in the final-hours panic.

## Process

1. **Confirm this is worth including** — fast-action bonuses work best for live launches with a meaningful cart-open window (several days or more); skip this module for a short cart-open window or an evergreen launch where "fast action" has no natural meaning.
2. **Design a bonus that's genuinely valuable and cheap to deliver** — a live Q&A/office-hours call, an extra template or resource, early access to a future module or community, or a personal onboarding call for high-ticket offers. Avoid anything that feels like a consolation prize or padding just to have something to offer.
3. **Set a real, tight deadline** — typically the first 24-48 hours of the cart-open window, separate from and earlier than the full cart-close date. This deadline must be genuinely enforced (the bonus genuinely disappears after it) — the same honest-urgency standard applies here as everywhere else in this pipeline.
4. **Write the bonus announcement copy** — a short, specific description of what it is, why it's valuable, and exactly when it disappears, ready to drop into Module 7's early cart-open emails and the sales page (Module 6) if there's still time to add it before that page is finalized.

## Output format

```
FAST-ACTION BONUS: [what it is] — value: $[x] (if applicable) — why it's valuable: [one line]
DEADLINE: [exact date/time, tied to a real, enforced cutoff]
ANNOUNCEMENT COPY: [short, specific description ready for the cart-open sequence and/or sales page]
```

## Handoff

If included, this bonus must be referenced in Module 7's early cart-open emails and, if timing allows, added to Module 6's sales page before it's finalized. If this module is skipped (short window or evergreen launch), say so plainly rather than leaving an unused placeholder in Module 13's assembly.
