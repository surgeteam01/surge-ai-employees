# Module 12: Evergreen Transition Planner

**Purpose:** Plan how a live launch's materials convert into an always-on, automated funnel afterward — this only applies if Module 1/4 confirmed a hybrid model, and it's what lets a single burst of launch effort keep producing sales long after the live cart-open window closes.

## Process

1. **Confirm scope from Module 4** — skip this module entirely if the launch model is purely live (one-time, no evergreen afterward) or purely evergreen from the start (nothing to "transition" from).
2. **Decide what carries over automated**: the pre-launch content (Module 5) can usually become an automated nurture sequence triggered on opt-in, the sales page (Module 6) stays live permanently, and the cart-open sequence (Module 7) can become an automated sales sequence — reference `build-your-email-funnel`'s Nurture Sequence Writer and Sales Sequence Writer modules directly for this adaptation rather than re-deriving the logic here.
3. **Decide what does NOT carry over** — the cart-close/urgency sequence (Module 8) and any fast-action bonus (Module 9) relied on a real, public deadline that no longer exists once the launch is evergreen; either drop this stage entirely for the evergreen version or replace it with an honest, individually-real trigger if one exists (e.g. a bonus tied to each buyer's personal enrollment window, not a fake recurring "closing tonight").
4. **Decide the evergreen trigger** — what starts a new subscriber's personal automated journey (typically: opt-in for the same lead magnet/content that drove the original launch's pre-launch list).
5. **Flag any content that referenced the live launch's specific dates or "this is a limited launch" framing** — this must be rewritten for the evergreen version, since keeping live-launch language in permanent always-on content reads as either stale or dishonest once the original date has passed.

## Output format

```
EVERGREEN TRANSITION: [in scope / not applicable]

CARRIES OVER (automated):
- Pre-launch content → automated nurture sequence, adapted per build-your-email-funnel's Nurture Sequence Writer
- Sales page → stays live permanently
- Cart-open sequence → automated sales sequence, adapted per build-your-email-funnel's Sales Sequence Writer

DOES NOT CARRY OVER:
- Cart-close/urgency sequence (Module 8) — [dropped / replaced with: individually-real trigger, if any]
- Fast-action bonus (Module 9) — [dropped / replaced with: individually-real trigger, if any]

EVERGREEN TRIGGER: [what starts a new subscriber's automated journey]

LIVE-LAUNCH LANGUAGE TO REWRITE: [specific dates or "limited launch" framing flagged for removal]
```

## Handoff

If in scope, this plan feeds Module 13's assembly as a second, evergreen version of the funnel alongside the original live-launch materials. If not applicable, say so plainly rather than leaving this section blank in the final package.
