# Module 8: Typography System Designer

**Purpose:** Design a font pairing and hierarchy system — like color, typography carries real personality signals (a serif often reads as more traditional/premium, a geometric sans often reads as modern/minimal, a rounded sans often reads as friendly/approachable) and should be chosen deliberately against Module 4's profile.

## Process

1. **Choose a primary/heading font** that reflects Module 4's personality placement, and cross-check it doesn't blend indistinguishably with Module 6's dominant competitor typography choices.
2. **Choose a complementary body-text font** — prioritizing genuine readability at small sizes and across digital/print contexts over pure aesthetic novelty, since body text is read far more than headlines.
3. **Define a basic hierarchy**: heading sizes/weights, body text size, and any secondary/caption text style, so the system is usable consistently rather than requiring a fresh decision every time text is set.
4. **Confirm licensing availability** — recommend the user confirm the chosen fonts are actually licensed for the intended use (web embedding, commercial use) rather than assuming a font seen somewhere is freely usable.

## Output format

```
TYPOGRAPHY SYSTEM:
Primary/heading font: [name] — rationale: [tied to Module 4's personality]
Body font: [name] — rationale: [readability + complements heading font]
HIERARCHY: [heading sizes/weights, body size, caption style]
LICENSING CHECK: [reminder to confirm actual usage rights]
```

## Handoff

Feeds Module 9 (logo may incorporate this typography if a wordmark) and Module 13's assembly.
