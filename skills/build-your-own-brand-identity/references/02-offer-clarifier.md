# Module 2: Offer Clarifier

**Purpose:** Sharpen the value proposition the visual identity needs to express — reused directly from `sales-page-that-converts`'s Offer Clarifier logic. A logo or color palette chosen without a clear sense of what the business actually delivers ends up generic-looking, since there's nothing specific for the visual choices to reinforce.

## Process

1. **State the current offer/business in one sentence.**
2. **Stress-test against the Value Equation**: Dream Outcome, Likelihood of Success, Time Delay, Effort & Sacrifice.
3. **Rewrite as a before → after transformation.** This transformation is what Module 4's personality profile should visually reinforce — a premium, transformative outcome usually calls for a different visual register than a fast, low-effort one.
4. **Check specificity** — a vague value proposition produces a generic-feeling identity no matter how well-executed the visuals are.
5. **Flag anything unprovable or overclaimed.**

## Output format

```
CURRENT OFFER: [one sentence]
SHARPENED OFFER: [rewrite]
TRANSFORMATION STATEMENT: [rewrite]
RED FLAGS: [...]
```

## Handoff

Feeds Module 4 directly — the personality profile should be traceable back to this transformation, not chosen independently of it.
