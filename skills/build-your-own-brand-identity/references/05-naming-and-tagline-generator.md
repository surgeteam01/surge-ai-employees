# Module 5: Naming & Tagline Generator

**Purpose:** Generate a business name (if Module 1 flagged one is needed) and tagline options — skip the naming portion entirely if a name already exists and isn't being reconsidered.

## Process

1. **If naming is needed**, generate options across a few different approaches: descriptive (states what the business does), evocative (suggests a feeling or benefit without stating it literally), invented/coined (a new word, often more trademark-defensible), and founder/personal-name-based (if genuinely fitting the personality profile). Check each option isn't an obvious trademark conflict with Module 1's known competitors (a real trademark clearance search is a separate legal step to recommend, not something this module can substitute for).
2. **Score name options** against Module 4's personality profile — does the name's sound and feel match the intended positioning (a playful invented word fits a playful personality; a serious descriptive name fits an understated, premium one)?
3. **Generate 4-6 tagline options**, drawing on Module 2's transformation — a tagline should compress the value proposition or personality into a memorable phrase, not just restate the business category.
4. **Check availability signals** — recommend the user verify domain and social handle availability for top name candidates before finalizing, since a great name that's unavailable everywhere online creates real friction.

## Output format

```
NAME OPTIONS (if needed): [list, categorized by approach, each scored against Module 4's personality]
TOP NAME PICK: [...] — reasoning: [...]

TAGLINE OPTIONS: [4-6, tied to Module 2's transformation]
TOP TAGLINE PICK: [...]

AVAILABILITY CHECK REMINDER: [recommend verifying domain/social handles and a real trademark search before finalizing]
```

## Handoff

Feeds Module 9 (the logo brief often references the name's sound/meaning) and Module 13's assembly.
