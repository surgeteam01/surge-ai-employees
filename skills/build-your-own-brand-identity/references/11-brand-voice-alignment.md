# Module 11: Brand Voice Alignment

**Purpose:** Confirm the visual identity built so far actually matches the brand's verbal identity — a mismatch between how a brand looks and how it sounds (a playful, casual visual identity paired with stiff, corporate copy, or vice versa) undermines trust even when each half is individually well-executed.

## Process

1. **Check for an existing `write-like-a-human` voice profile** for this business. If one exists, compare its spectrum map (formal/casual, warm/blunt, serious/playful) directly against Module 4's visual personality spectrums — they should tell a consistent story, not contradict each other.
2. **If no voice profile exists yet**, recommend running `write-like-a-human` using Module 4's personality profile as a starting anchor, so the verbal voice gets built consistent with the visual identity from the start rather than developing independently later.
3. **Flag any specific mismatch** found (e.g. visual identity reads as premium/exclusive while the existing voice/copy reads as casual and jokey) and recommend which side should adjust, based on which was more deliberately researched (Module 3/4's grounded research should usually win over an ungrounded existing habit).

## Output format

```
VOICE PROFILE STATUS: [existing write-like-a-human profile found / none yet — recommend running it]

ALIGNMENT CHECK: [consistent / mismatch found — specifics]
RECOMMENDATION (if mismatch): [which side to adjust, and why]
```

## Handoff

Feeds Module 13's assembly as a cross-reference note, ensuring the guidelines document points to the voice profile explicitly rather than treating visual and verbal identity as unrelated documents.
