# Module 4: Brand Personality & Positioning Mapper

**Purpose:** Translate the business's transformation and audience research into a structured personality profile — the single reference every visual decision downstream (color, type, logo, imagery) gets checked against, adapted from `write-like-a-human`'s Voice Attribute Mapper logic but for visual/emotional brand personality rather than writing style.

## Process

1. **Place the brand on personality spectrums**, grounded in Module 2's transformation and Module 3's audience research, not personal taste: **Classic ↔ Modern**, **Playful ↔ Serious**, **Minimal ↔ Maximal**, **Warm ↔ Cool**, **Premium/Exclusive ↔ Accessible/Everyday**, **Bold ↔ Understated**.
2. **Choose a brand archetype** if useful for the user's mental model (e.g. Explorer, Sage, Caregiver, Rebel, Everyman) — a shorthand for the personality, not a rigid template to force everything into.
3. **Write a one-paragraph personality summary** in plain language — what should someone feel when they encounter this brand for the first time?
4. **Flag any tension** between the personality profile and Module 3's audience register (e.g. a bold, maximalist personality chosen for an audience that research shows trusts minimal, understated brands) — name it explicitly rather than letting it go unresolved.

## Output format

```
PERSONALITY SPECTRUMS: [placement + brief note per spectrum]
ARCHETYPE (if useful): [...]
PERSONALITY SUMMARY (plain language): [...]
TENSION FLAGS: [any mismatch between personality choice and Module 3's audience register]
```

## Handoff

This profile is the reference every subsequent visual module (5-10) checks against — Module 13's assembler should be able to trace every major visual choice back to a specific line in this profile.
