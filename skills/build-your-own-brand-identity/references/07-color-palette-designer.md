# Module 7: Color Palette Designer

**Purpose:** Design a primary/secondary/accent color system with clear rationale — colors carry real psychological and category associations, and each choice here should be traceable to Module 4's personality profile, not picked on aesthetic preference alone.

## Process

1. **Choose a primary color** that reflects Module 4's core personality placement (e.g. warm/energetic personalities often use warm hues; premium/exclusive personalities often use deep, saturated or neutral tones; accessible/everyday personalities often use bright, approachable hues) — while checking it doesn't collide confusingly with Module 6's dominant competitor color (e.g. becoming "the other blue one" in a category already dominated by blue).
2. **Choose 1-2 secondary colors** that complement the primary and add versatility for different applications (text, backgrounds, secondary UI elements).
3. **Choose 1-2 accent colors** for calls-to-action and emphasis — often higher contrast or more saturated than the primary/secondary set, used sparingly.
4. **Provide specific color values** (hex codes) for each color, plus a brief note on appropriate usage (primary for dominant brand moments, accent only for CTAs/emphasis, not evenly distributed).
5. **Check accessibility** — confirm sufficient contrast between text and background color combinations for basic readability/accessibility standards.

## Output format

```
COLOR PALETTE:
Primary: [hex] — rationale: [tied to Module 4's personality]
Secondary: [hex, hex] — usage: [...]
Accent: [hex] — usage: [CTAs/emphasis only]

COMPETITOR COLLISION CHECK: [confirmed distinct from Module 6's dominant competitor colors]
ACCESSIBILITY CHECK: [contrast confirmed for primary text/background combinations]
```
