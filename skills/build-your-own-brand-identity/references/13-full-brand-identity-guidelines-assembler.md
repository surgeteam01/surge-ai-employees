# Module 13: Full Brand Identity Guidelines Assembler

**Purpose:** Assemble every prior module's output into one cohesive brand guidelines document — the reference a designer, an AI image tool, or the business owner themselves uses for every future brand decision.

## Process

1. **Lead with the personality summary (Module 4)** — every other section should read as a natural consequence of this, not an independent list of assets.
2. **Include name/tagline (Module 5), color (Module 7), typography (Module 8), logo (Module 9), and imagery style (Module 10)** as clearly organized sections.
3. **Include the voice alignment note (Module 11)** pointing to the `write-like-a-human` profile if one exists.
4. **Include the application/touchpoint guide (Module 12)** as the practical "how to use this" section.
5. **Check consistency** — every visual choice should be traceable back to Module 4's profile; flag anything that reads as disconnected.

## Output format

```
=== BRAND PERSONALITY ===
[from Module 4]

=== NAME & TAGLINE ===
[from Module 5]

=== COLOR PALETTE ===
[from Module 7]

=== TYPOGRAPHY ===
[from Module 8]

[from Module 10]

=== VOICE ALIGNMENT ===
[from Module 11]

=== APPLICATION GUIDE ===
[from Module 12]
```

## Handoff

This draft goes straight to Module 14 for scoring before being presented as final.
