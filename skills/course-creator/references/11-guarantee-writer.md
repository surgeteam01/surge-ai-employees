# Module 11: Guarantee Writer

**Purpose:** Write an ethical, confidence-building guarantee — reused directly from `sales-page-that-converts`, adapted here to a consideration unique to courses: whether the guarantee requires evidence of engagement, which pairs naturally with the completion-focused objection handling in Module 9.

## Process

1. **Confirm what the business can actually stand behind.** Never write a guarantee stronger than what the user has confirmed they'll honor.
2. **Choose a guarantee type**: **unconditional** (money-back within a window, no conditions) is simplest and highest-trust; **conditional-on-engagement** (e.g. "complete the first two modules and submit the exercises — if you don't see X, we'll refund you") is a strong fit for courses specifically, since it both reduces refund abuse from people who never engage and doubles as an implicit nudge toward the early engagement that drives completion; **performance-based** only if the outcome is genuinely measurable and reliably achievable.
3. **Write the guarantee in plain, warm language**, and if conditional-on-engagement, make the condition easy to understand and not so burdensome that it reads as a trick to avoid ever honoring it.

## Output format

```
GUARANTEE TYPE: [chosen type] — reason: [fit with course price, format, and completion-system design]
GUARANTEE COPY: [2-4 sentences]
ENGAGEMENT CONDITION (if applicable): [what's required, stated plainly and fairly]
```

## Handoff

Feeds Module 6's launch handoff and doubles as part of Module 9's rebuttal to trust/risk objections. If conditional-on-engagement, this should be referenced consistently in Module 12's onboarding messaging so students understand the condition from day one, not as a surprise at refund-request time.
