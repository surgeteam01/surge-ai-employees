# Module 7: Offer Stack Builder

**Purpose:** Present the course as a value-anchored stack — every component named, valued, and justified — reused directly from `sales-page-that-converts`, adapted here to course-specific components.

## Process

1. **List every component**: the core curriculum, plus course-specific bonuses — templates/worksheets, a private community, live Q&A calls, a certificate of completion, bonus modules, lifetime access vs. time-limited access.
2. **Assign an honest perceived value to each component** — defensible, not inflated to the point of being unbelievable.
3. **Order components by weight** — the core curriculum first and biggest, bonuses supporting it.
4. **Total the stack** and set it against the actual price (once Module 10 runs).
5. **Write one line of justification per component**, tied to how it supports completion or the transformation specifically — e.g. a community isn't just "access," it's "accountability and unstuck-ness when you hit a wall," which matters more for a course than for most other offer types given how central completion is to satisfaction.

## Output format

```
OFFER STACK:
- [Core curriculum] — Value: $[x] — [one line: what it delivers]
- [Bonus 1, e.g. community/live calls] — Value: $[x] — [one line, tied to completion/support]
- [Bonus 2] — Value: $[x] — [one line]
...
TOTAL VALUE: $[sum]
```

## Handoff

This stack feeds Module 6's launch handoff (used inside the sales page and pre-launch content) and Module 10 (price point calculation).
