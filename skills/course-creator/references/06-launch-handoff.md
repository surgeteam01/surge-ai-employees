# Module 6: Launch Handoff

**Purpose:** Produce the actual launch — pre-launch content, sales page, cart-open and cart-close sequences, bonuses, and affiliate enablement — by handing off entirely to `launch-a-digital-product`'s pipeline rather than re-deriving launch mechanics here. This module exists to make that handoff deliberate and complete.

## Process

1. **Do not re-run `launch-a-digital-product`'s Stage 1 (Onboarding), Stage 2 (Offer Clarifier), or Stage 3 (Customer Research) from scratch.** Pass forward this skill's own Course Brief (Module 1), sharpened offer (Module 2), and VoC/student profile (Module 3) directly as their equivalents.
2. **Pass forward curriculum highlights from Module 4 and Module 5** as content previews — the module list and a few standout lesson examples make excellent pre-launch content teasers and sales page bullet points, and `launch-a-digital-product`'s Stage 5 (Pre-Launch Content) and its Stage 6 (Sales Page Handoff, which itself hands off to `sales-page-that-converts`) should use these rather than inventing generic content descriptions.
3. **Invoke `launch-a-digital-product`'s Stage 4 through Stage 13** (Launch Architect, Pre-Launch Content, Sales Page Handoff, Cart-Open Sequence, Cart-Close/Urgency, Fast-Action Bonus, Affiliate Kit, and the Assembler) using the carried-forward brief, offer, VoC profile, and curriculum highlights as inputs.
4. **Note the course-specific framing the launch needs**: emphasis on the learning path and early wins (from Module 4) as a differentiator, and — if cohort-based — the fixed start date as the real driver of any cart-close urgency, rather than an arbitrary deadline.
5. **Carry the resulting launch package forward as a finished asset.**

## Output format

```
LAUNCH HANDOFF

Inputs passed to launch-a-digital-product:
- Course Brief → Launch Brief equivalent: [confirmed passed]
- Sharpened Offer (Module 2): [confirmed passed]
- VoC/Student Profile (Module 3): [confirmed passed]
- Curriculum highlights (Modules 4-5): [module list + standout lesson examples, confirmed passed]

COURSE-SPECIFIC FRAMING NOTES: [learning-path differentiation / cohort start-date urgency if applicable]

RESULTING LAUNCH PACKAGE: [the finished, scored launch produced by launch-a-digital-product's Stage 4-13]
```

## Handoff

The finished launch package feeds Module 13 (assembled as part of the full course package). If cart-open/close dates are set here (cohort-based format), Module 12's completion system should align its own start date and cohort pacing to match exactly.
