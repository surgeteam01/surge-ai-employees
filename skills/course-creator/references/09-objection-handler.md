# Module 9: Objection Handler

**Purpose:** Surface the real objections a buyer will have about a course specifically — the completion objection is unique to this category and deserves more weight here than in almost any other skill in this repo.

## Process

1. **Start from Module 3's objection list**, then add course-specific objections: "will I actually finish this" (the single most common and most damaging objection for any course purchase decision — buyers have a graveyard of unfinished courses and know it), "I've bought courses before and they didn't work," "is this too advanced/too basic for where I'm at," "how much time will this actually take," and standard price/trust objections.
2. **Write a direct rebuttal for the completion objection specifically, pointing to Module 12's actual completion system** (drip pacing, accountability, community, early wins) rather than a generic reassurance — a real, specific answer ("here's exactly how this is structured to prevent that: weekly drip, a private community for accountability, and your first real result by the end of Module 1") is far more convincing than "you'll definitely finish this one!"
3. **Write a direct rebuttal for the "too advanced/basic" objection** pointing to Module 3's starting-skill-level research and Module 4's design decisions.
4. **Write the FAQ in the student's actual phrasing** (from Module 3's phrase bank), including realistic time-commitment answers rather than understating the effort required.

## Output format

```
OBJECTIONS HANDLED:
1. "Will I actually finish this?" → [Rebuttal, pointing to specific completion-system features from Module 12] → placement: [sales page / dedicated objection content]
2. [Other objection] → [Rebuttal] → placement: [...]
(repeat)

FAQ (student-phrased):
Q: [question in student's actual words]
A: [direct, honest answer, including realistic time commitment]
(repeat)
```

## Handoff

The completion-objection rebuttal specifically depends on Module 12's actual design — if this module runs before Module 12, come back and update this rebuttal once the completion system is finalized rather than leaving it generic. Feeds Module 6's launch handoff.
