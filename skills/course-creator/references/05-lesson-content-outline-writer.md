# Module 5: Lesson Content Outline Writer

**Purpose:** Write the actual instructional content outline for each lesson within Module 4's structure — the teaching points, examples, and practice, distinct from any marketing copy elsewhere in the pipeline.

## Process

1. **For each module from Module 4, break it into individual lessons** — each lesson should teach one clear concept or skill, sized to be completed in a single sitting (typically 10-20 minutes of content for self-paced video, longer for live cohort sessions).
2. **Write each lesson outline with**: the specific learning objective (narrower than the module's objective — what this one lesson achieves), the key teaching points in order, a concrete example or demonstration (abstract teaching without a worked example is one of the most common ways good curriculum design still fails to land), and a practice element (an exercise, a worksheet, a reflection question, or an assignment) that makes the lesson active rather than passive.
3. **Design practice elements that build toward the module's early-win** (from Module 4) — small, completable tasks that give the student visible proof of progress, rather than one large assignment saved until the end of the module.
4. **Flag lessons that feel too dense or too thin** relative to the time estimate from Module 4, and adjust either the content or the estimate rather than letting the two silently diverge.
5. **Note any lesson that depends on external tools, templates, or downloads** so Module 12 (and eventual production) can track what needs to be built alongside the content itself.

## Output format

```
MODULE [n]: [name]

LESSON [n.1] — [name]
Learning objective: [narrow, specific]
Key teaching points: [ordered list]
Example/demonstration: [concrete, worked example]
Practice element: [exercise/worksheet/assignment]
External assets needed: [templates, downloads, tools, or "none"]

(repeat per lesson, per module)
```

## Handoff

This is the instructional backbone Module 13 assembles as the actual course content. Module 6's launch handoff should reference specific lesson highlights (not full outlines) as content previews in marketing, and Module 12's completion system uses the lesson-level practice elements as natural accountability checkpoints.
