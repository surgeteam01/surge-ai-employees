# Module 10: Pricing Model, Tier & Price Designer

**Purpose:** Set the pricing model, any tier structure, and the actual price — consolidating `nail-your-pricing`'s Pricing Model Selector, Value Metric & Tier Designer, and Price Point Calculator into a single module sized for what a course typically needs, rather than running that skill's full standalone pipeline.

## Process

1. **Choose a pricing model**: one-time flat fee (most common for self-paced courses), payment plan (common for higher-ticket courses to reduce purchase friction), or a subscription/membership model (if the course is part of an ongoing content library rather than a single discrete program).
2. **Decide if tiers are warranted** — a common, well-justified course tier split is self-study only vs. self-study plus live coaching/feedback/community access, since that's a genuine difference in delivered value and support level, not an arbitrary feature-gate. Don't add tiers just to have them if a single well-priced option fits the offer better.
3. **Calculate the actual price**: establish a floor from real production/delivery cost (content creation time amortized, any live component's ongoing cost, platform fees) and minimum acceptable margin; establish a ceiling from comparable courses in the space and the audience's willingness to pay (from Module 3); triangulate to a defensible number, applying pricing psychology (charm pricing, round-number premium) consistent with the positioning implied by Module 2's offer strength and Module 8's proof quality.
4. **Set payment plan terms if offered** — installment count, and a small premium over the one-time price to account for payment risk, consistent with fair pricing practice.

## Output format

```
PRICING MODEL: [one-time / payment plan / subscription] — reason: [delivery pattern]
TIER STRUCTURE: [single option / self-study vs. with-coaching, or other] — reason: [genuine value difference, or "single option — no tiers warranted"]

PRICE(S): [$x per tier if tiered]
PAYMENT PLAN (if offered): [n] payments of $[x] — premium over full price: [x%]
PSYCHOLOGY/POSITIONING NOTE: [why this price fits the offer strength and proof quality]
```

## Handoff

Feeds Module 6's launch handoff (passed to `launch-a-digital-product`'s own pricing presentation, delegated further to `sales-page-that-converts`) and Module 7 (offer stack is priced against this number). For unusually complex pricing decisions (e.g. genuine uncertainty about model or heavy competitive pressure), recommend running the full `nail-your-pricing` skill instead of this condensed module.
