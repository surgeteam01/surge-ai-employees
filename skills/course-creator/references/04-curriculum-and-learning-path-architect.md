# Module 4: Curriculum & Learning Path Architect

**Purpose:** Design the full module/lesson structure, sequenced from the student's real starting point (Module 3) to the sharpened transformation (Module 2) — this is the educational-design equivalent of a sales page outline, and the foundation everything else in the course is built on.

## Process

1. **Work backward from the transformation.** State the end result in concrete, observable terms (what the student can do/produce at the end), then work backward to identify the major milestones/skills required to get there — this prevents the common failure mode of a curriculum organized around "topics to cover" rather than "the path to the outcome."
2. **Sequence modules from the real starting point** (Module 3's starting skill level), not from an idealized beginner or an assumed expert — a course that starts too advanced loses students in the first module; one that starts too basic loses them to boredom before the material gets useful.
3. **Break the path into modules, each with a clear learning objective** (what the student can do after this module that they couldn't before) and estimate the realistic time commitment per module, given the audience's likely available time (from Module 3).
4. **Design for early wins.** The first module especially should get the student to a small, real result quickly — early momentum is one of the strongest predictors of eventual completion, more so than the quality of later content.
5. **Choose format mix per module** (video, text, live sessions, templates/worksheets, exercises) based on the format decision from Module 1 (self-paced vs. cohort-based) and what actually suits the content — a skill requiring practice needs exercises, not just video explanation.
6. **Note total course length and realistic completion timeline**, and flag if it looks too long relative to Module 3's likely time scarcity — a shorter, tightly-sequenced course that gets finished beats a comprehensive one that doesn't.

## Output format

```
TRANSFORMATION (recap): [from Module 2]
STARTING POINT (recap): [from Module 3]

MODULE STRUCTURE:
Module 1 — [name] — Learning objective: [what student can do after] — Est. time: [x] — Early-win design: [what quick result this delivers]
Module 2 — [name] — Learning objective: [...] — Est. time: [x]
Module 3 — [name] — Learning objective: [...] — Est. time: [x]
(repeat per module)

FORMAT MIX (per module or overall): [video / text / live / exercises — reasoning]
TOTAL COURSE LENGTH: [x] — REALISTIC COMPLETION TIMELINE: [x]
PACING FLAG: [any concern that the course is too long/dense relative to Module 3's time-scarcity signal]
```

## Handoff

This structure is what Module 5 fills in with actual lesson-level content, and what Module 12's completion system is designed around (drip pacing should match the module structure here, not be decided independently). Module 6's launch handoff uses the module list as content previews in marketing.
