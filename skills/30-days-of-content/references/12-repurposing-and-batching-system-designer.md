# Module 12: Repurposing & Batching System Designer

**Purpose:** Design the system that turns one substantial "core" piece of content into several derivative pieces across formats and platforms — this is what makes a 30-day calendar actually sustainable to produce, rather than requiring 30 entirely separate ideation efforts.

## Process

1. **Identify the core pieces** flagged in Module 5's skeleton — typically the most substantial, idea-dense days (a detailed educational post, a strong case study).
2. **Design a repurposing map per core piece**: e.g. a long-form LinkedIn post becomes a 5-slide carousel on Instagram, a condensed thread on X, and a short-form video script hitting the same core point in 30-45 seconds. Each derivative should feel native to its new platform (per Module 9), not a copy-paste of the original.
3. **Design a batching schedule** — group content production by task type (write all hooks in one sitting, record all videos in one sitting, design all carousels in one sitting) rather than producing each day's content fully from start to finish in isolation; batching by task is typically far more time-efficient than context-switching between idea generation, writing, and design 30 separate times.
4. **Recommend a realistic production cadence** — e.g. one batching session per week covering that week's core pieces and derivatives, rather than daily from-scratch work.

## Output format

```
REPURPOSING MAP:
Core piece (Day [n]) → Derivative 1: [platform + format] → Derivative 2: [platform + format] → Derivative 3: [platform + format]
(repeat per core piece)

BATCHING SCHEDULE:
[Task type, e.g. "write all hooks/leads"] — batch together: [which days] — recommended session: [weekly/biweekly]
(repeat per task type)

RECOMMENDED PRODUCTION CADENCE: [e.g. one batching session per week, covering that week's core + derivative content]
```

## Handoff

This system feeds Module 13's assembly as an operational companion to the calendar itself — it's what the user actually follows week to week to produce the calendar sustainably, separate from the content ideas themselves.
