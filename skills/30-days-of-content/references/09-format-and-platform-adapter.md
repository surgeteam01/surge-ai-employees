# Module 9: Format & Platform Adapter

**Purpose:** Adapt each of the 30 ideas into the native format its platform actually rewards — a good idea delivered in the wrong format (a dense paragraph where a platform favors short-form video, a single image where a platform favors carousels) underperforms regardless of the idea's quality.

## Process

1. **For each platform in Module 1's brief, identify the native formats that actually perform**: LinkedIn (text post with line breaks, a carousel/document post, or a short native video), Instagram (a carousel, a single image with caption, or a Reel/short-form video script), X/Twitter (a single tweet or a thread), TikTok/Reels/Shorts (a short-form video script with a spoken hook), blog/newsletter (a longer written piece with subheads).
2. **Adapt each day's idea (from Module 8) into its platform's native format**, adjusting structure accordingly: a carousel needs a slide-by-slide breakdown, a short-form video needs a spoken script with an on-screen hook text overlay note, a thread needs a tweet-by-tweet breakdown, a text post needs paragraph/line-break formatting suited to that platform's reading pattern.
3. **If a piece of content is going out on multiple platforms** (a repurposing target from Module 12), adapt the same core idea into each platform's distinct native format rather than posting an identical format across all of them — a straight copy-paste across platforms usually underperforms compared to a format genuinely native to each.
4. **Keep the hook and lead from Modules 6-7 intact** as the anchor, adjusting only the surrounding format/structure to fit the platform.

## Output format

```
DAY [n] — [Platform]
Native format: [carousel / thread / short-form video script / text post / article]
Adapted structure: [slide-by-slide, tweet-by-tweet, or full copy, matching the format]

(repeat per platform this day's content is going out on)
```

## Handoff

This adapted content feeds Module 13's assembly directly — the finished calendar should show real, platform-native content per day, not a single generic version repeated everywhere.
