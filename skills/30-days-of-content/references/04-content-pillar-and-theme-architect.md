# Module 4: Content Pillar & Theme Architect

**Purpose:** Define the 3-5 recurring content pillars and the overall content-mix ratio the entire 30-day calendar will be built from — this is the strategic skeleton that keeps a month of content from becoming a random grab-bag of unrelated ideas.

## Process

1. **Define 3-5 content pillars** that each connect to Module 2's transformation and Module 3's top pains/desires — e.g. for a fitness coach: "mindset/motivation," "nutrition myths," "workout technique," "client transformations." Each pillar should be broad enough to generate many distinct posts, but specific enough to be recognizable as "this business's thing."
2. **Set a content-mix ratio across pillars and post types**, tied to Module 1's content goal: a common, adaptable starting split is roughly 40% educational (teaches something useful), 30% engagement/relatable (connects, entertains, invites interaction), 20% authority/proof (results, credibility, case studies), 10% promotional (direct pitch/offer). Adjust the ratio based on the stated goal — a sales-focused calendar skews more promotional/authority, an engagement-focused one skews more relatable.
3. **Assign awareness-stage weighting** — if Module 3 found the audience mostly unaware/problem-aware, weight pillars toward educational/problem-naming content; if more aware, weight more toward proof and direct offers.
4. **Name each pillar clearly** so it's easy to tag content against it later, and briefly state each pillar's specific job (what it's for) so Module 8's idea generation has a clear brief per pillar rather than a vague theme.

## Output format

```
CONTENT PILLARS:
1. [Pillar name] — job: [what this pillar does for the audience/business] — connects to: [transformation/pain/desire]
2. ...
(3-5 total)

CONTENT-MIX RATIO: Educational: [x%] Engagement/Relatable: [x%] Authority/Proof: [x%] Promotional: [x%]
AWARENESS-STAGE WEIGHTING NOTE: [how the ratio was adjusted based on Module 3's findings]
```

## Handoff

This structure is what Module 5's calendar slots days against, and what Module 8's idea generation is scoped by — every one of the 30 ideas should trace back to exactly one of these pillars, tagged clearly.
