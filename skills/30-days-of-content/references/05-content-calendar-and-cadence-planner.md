# Module 5: Content Calendar & Cadence Planner

**Purpose:** Build the 30-day skeleton — which pillar and post type lands on which day, per platform — before generating any specific content ideas. This is the scheduling and variety-control layer that keeps the month balanced rather than front-loading one pillar and neglecting others.

## Process

1. **Set posting cadence per platform** from Module 1's brief and realistic production capacity — daily, a few times a week, or a mixed cadence across platforms (e.g. daily on one platform, 2-3x/week on another). Don't default to daily-everywhere if that's not realistic or necessary for the stated goal.
2. **Distribute pillars across the 30 days** according to Module 4's content-mix ratio — e.g. if educational is 40%, roughly 12 of 30 days should be educational-pillar content. Avoid clustering the same pillar on consecutive days; spread each pillar's appearances across the month for variety.
3. **Plan for repurposing from the start** (feeding Module 12) — identify which days' content is substantial enough to serve as a "core" piece that gets repurposed into 2-3 other formats/platforms, rather than treating every single day as requiring entirely new ideation.
4. **Note any calendar-specific timing** — content tied to a real launch, seasonal moment, or promotional push (from Module 1) should land on the days that actually support that timing, not be distributed purely for pillar balance if a real deadline overrides it.
5. **Flag realistic production load** — if the cadence and format mix from this plan would require more production time than the user realistically has, say so and recommend a lighter cadence or more aggressive repurposing rather than silently setting up an unsustainable plan.

## Output format

```
CADENCE PER PLATFORM: [platform] — [frequency]

30-DAY SKELETON:
Day 1 — Pillar: [x] — Post type: [educational/engagement/authority/promotional] — Platform(s): [x] — Repurpose-source: [yes/no]
Day 2 — Pillar: [x] — Post type: [x] — Platform(s): [x] — Repurpose-source: [yes/no]
(repeat for all 30 days)

PRODUCTION LOAD FLAG: [any concern that this cadence/format mix exceeds realistic capacity]
```

## Handoff

This skeleton is what Module 8 fills in with specific ideas per day, and what Module 12's repurposing system builds from directly (using the "repurpose-source" flags set here). Present this skeleton to the user before generating all 30 specific ideas, since redirecting the whole month's balance is much easier here than after ideas exist.
