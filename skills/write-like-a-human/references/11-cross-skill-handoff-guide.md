# Module 11: Cross-Skill Handoff Guide

**Purpose:** Write explicit instructions for how every other Surge skill should receive and use this voice profile — this module exists because the entire point of building this profile once is to stop every other skill's Onboarding stage from re-asking "what's your brand voice?" and getting a fresh, inconsistent answer each time.

## Process

1. **Identify which field in every other skill's Onboarding module** this profile should feed — typically a "Voice" or "Brand voice" line in each skill's Brief block (e.g. `sales-page-that-converts`'s Offer Brief, `build-your-email-funnel`'s Funnel Brief, `find-your-niche`'s messaging stage).
2. **Write a short, standard instruction**: when starting any other skill's Onboarding stage for this business, check whether a Write Like a Human voice profile exists; if so, pass Module 12's quick-reference card (not the full 14-module output) into that skill's "voice" field instead of asking the user to describe their voice from scratch.
3. **Note when the full profile (rather than just the quick-reference card) is worth pulling in** — for a high-stakes, long-form piece (a full sales page, a course's worth of content) the fuller style guide (Module 6) and before/after samples (Module 8) are worth referencing directly; for a single email or quick piece, the quick-reference card is enough.
4. **Note that Module 10's rewrite engine can run as a final pass** on any other skill's finished output, independent of which skill produced it — this is the standard way to apply this profile to content this skill didn't originate.

## Output format

```
CROSS-SKILL HANDOFF INSTRUCTIONS

For any other Surge skill's Onboarding stage:
1. Check if a voice profile exists for this business.
2. If yes, pass Module 12's quick-reference card into that skill's "voice" field instead of asking the user to describe it again.
3. For high-stakes, long-form output, also reference the full style guide (Module 6) and before/after samples (Module 8).
4. After that skill's Full Assembler stage produces a finished draft, optionally run it through this skill's Module 10 (Rewrite & Voice-Matching Engine) as a final voice-consistency pass.
```

## Handoff

This guide is a standing instruction, not a one-time output — it should be referenced every time any other skill in this repo is run for a business that has a completed Write Like a Human profile. Module 13 includes this guide in the final assembled package so it's easy to find later.
