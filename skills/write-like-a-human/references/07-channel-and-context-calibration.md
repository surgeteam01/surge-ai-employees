# Module 7: Channel & Context Calibration

**Purpose:** Define how the core voice flexes across different channels and contexts without losing its identity — a real voice isn't monolithic; the same person sounds slightly different in a LinkedIn post, a sales email, and a formal proposal, while still being recognizably themselves throughout.

## Process

1. **For each channel/context from Module 1's brief**, note what stays constant (the core attributes from Module 3, the signature phrases from Module 4 where they still fit) and what flexes (formality level, sentence length, use of humor, directness of the ask).
2. **Set explicit boundaries for the flex** — e.g. "formality can increase for a formal proposal, but never past X point" or "playfulness can drop for compliance-heavy contexts, but directness should stay constant" — so context-switching doesn't accidentally become voice-abandonment.
3. **Flag any channel where the required register genuinely conflicts with the core voice** (e.g. a naturally casual, playful voice forced into a highly formal legal/compliance context) and recommend how to handle it honestly — usually by preserving directness and clarity even when formality has to increase, rather than pretending the tension doesn't exist.
4. **Note any constraint from Module 1** (required compliance language) that must override voice preferences in specific, narrow instances — and confirm this is scoped tightly, not used as an excuse to genericize the whole piece.

## Output format

```
CHANNEL CALIBRATION:

[Channel 1, e.g. "LinkedIn post"]
What stays constant: [core attributes/phrases that still apply]
What flexes: [formality/length/humor adjustments]
Boundary: [how far the flex can go before it stops being this voice]

(repeat per channel from Module 1's brief)

CONFLICT FLAGS: [any channel where required register genuinely tensions with the core voice, and how to handle it]
```

## Handoff

This calibration feeds Module 10 (the rewrite engine should ask which channel/context applies before rewriting) and Module 11 (other skills producing channel-specific content — email vs. social vs. sales page — should reference the matching calibration here rather than applying one flat voice description everywhere).
