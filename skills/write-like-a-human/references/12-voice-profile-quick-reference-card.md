# Module 12: Voice Profile Quick-Reference Card

**Purpose:** Condense the full voice profile into a single, fast-loading summary — the version other skills' Onboarding stages should actually use day-to-day, per Module 11's handoff guide, rather than loading the full 14-module output every time.

## Process

1. **Condense Module 3's spectrum map into a one-line-per-dimension summary** — brief enough to scan in seconds.
2. **Pull the 3-5 strongest signature elements from Module 4** — not the full bank, just the highest-value, most distinctive ones worth actively using in most contexts.
3. **Pull the 5-8 most important "do" and "don't" rules from Module 6** — the ones that would most change a generic draft if applied, not an exhaustive restatement of the full style guide.
4. **Include one representative before/after pair from Module 8** — the single clearest example, not the full bank.
5. **Keep the entire card short enough to fit in a single glance** — this is a working reference card, not a condensed essay; if it takes more than a minute to read, it's too long for its purpose.

## Output format

```
VOICE QUICK-REFERENCE CARD — [Business/person name]

VOICE IN ONE LINE: [from Module 3's summary]
KEY SPECTRUMS: [one line per dimension, e.g. "Casual, warm, concise, direct (not hedging), plain-spoken"]

TOP SIGNATURE ELEMENTS: [3-5 strongest, from Module 4]

TOP DO'S: [5-8 highest-value rules, from Module 6]
TOP DON'TS: [5-8 highest-value rules, from Module 6]

ONE REPRESENTATIVE EXAMPLE:
Before: "[generic]"
After: "[voice-matched]"
```

## Handoff

This card is what Module 11's handoff guide instructs every other skill to actually use in day-to-day Onboarding — it's also the fastest thing to paste into a fresh conversation to quickly recalibrate an AI session to this voice without re-running the full pipeline.
