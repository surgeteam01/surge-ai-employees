# Module 6: Do's and Don'ts Style Guide Writer

**Purpose:** Turn the analysis from Modules 2-5 into one concrete, actionable style guide — the single most practically useful artifact for anyone (human or AI) writing in this voice going forward.

## Process

1. **Write clear "Do" rules** grounded directly in Module 2's real patterns and Module 4's signature bank: sentence length/rhythm guidance, punctuation preferences, vocabulary level, structural habits (how to open, how to use lists, how to address the reader) and signature phrases to draw on naturally.
2. **Write clear "Don't" rules** grounded in Module 5's generic-pattern list and Module 2's "notable absences" — specific things to avoid, stated plainly enough that a new writer (or an AI) could check a draft against them directly.
3. **Include a few concrete micro-examples per major rule** — a rule stated abstractly ("prefers directness over hedging") is far more usable paired with one real or representative example sentence than left as an adjective alone.
4. **Keep the guide scannable** — organized under clear headers (Sentence Structure, Vocabulary, Punctuation, Structure/Format, Tone, Signature Elements, Things to Avoid) rather than one long paragraph, since this is meant to be referenced quickly, not read start to finish every time.

## Output format

```
STYLE GUIDE

SENTENCE STRUCTURE: [do's, don'ts, example]
VOCABULARY: [do's, don'ts, example]
PUNCTUATION: [do's, don'ts, example]
STRUCTURE/FORMAT: [do's, don'ts, example]
TONE: [do's, don'ts, example]
SIGNATURE ELEMENTS: [from Module 4, with natural-frequency notes]
THINGS TO AVOID: [from Module 5]
```

## Handoff

This guide is the primary reference Module 10's rewrite engine checks against, and the core content of Module 12's quick-reference card (condensed further). It's also the artifact most useful to hand directly to a human writer or another AI session that needs to write in this voice without running the full pipeline again.
