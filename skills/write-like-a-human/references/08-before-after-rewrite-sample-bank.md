# Module 8: Before/After Rewrite Sample Bank

**Purpose:** Produce concrete generic-to-voice-matched rewrite pairs — a living reference set that demonstrates the voice profile in action, which is often faster to calibrate against than reading the style guide's rules in the abstract.

## Process

1. **Take 3-5 generic or AI-sounding passages** (invented for this purpose, or drawn from the "felt inauthentic" example in Module 1 if one was provided) covering a few different contexts relevant to Module 1's brief (e.g. a sales email opener, a social post, a short bio paragraph).
2. **Rewrite each one applying the full profile so far**: Module 3's attribute map, Module 4's signature phrases (used naturally, not forced), Module 5's avoid-list, Module 6's style guide, and Module 7's channel calibration for the relevant context.
3. **Annotate each pair** with a brief note on what specifically changed and why — this is what makes the samples teachable rather than just "before/after," useful for a human writer trying to internalize the voice or for calibrating future AI rewrites.
4. **Choose passages that showcase different aspects of the voice** across the set — one demonstrating sentence-rhythm changes, one demonstrating signature phrase usage, one demonstrating tone/formality shifts — rather than five samples that all make the same point.

## Output format

```
SAMPLE 1 — Context: [e.g. sales email opener]
BEFORE (generic): "[generic passage]"
AFTER (voice-matched): "[rewritten passage]"
What changed and why: [brief annotation]

(repeat for 3-5 samples, each highlighting a different aspect of the voice)
```

## Handoff

This bank feeds Module 12's quick-reference card (a condensed version, often just 1-2 of the strongest pairs) and serves as the calibration set Module 14 uses to test whether the rewrite engine (Module 10) is actually working — a new rewrite should read as consistent with these established examples.
