# Module 13: Full Voice Profile Assembler

**Purpose:** Assemble every prior module's output into one cohesive voice profile document — the full analysis, the practical style guide, the quick-reference card, and the cross-skill handoff instructions — so the pipeline's output is a single reference the user and every other Surge skill can actually use.

## Process

1. **Lead with the quick-reference card (Module 12)** — this is what gets used most often, so it should be immediately visible, not buried at the end of a long document.
2. **Include the full style guide (Module 6)**, the signature phrase bank (Module 4), and the before/after samples (Module 8) as the detailed reference layer beneath the quick card.
3. **Include the channel calibration (Module 7)** as its own clearly labeled section, since different pieces of content will need to reference different channel guidance.
4. **Include the drift-detection checklist (Module 9)** and the cross-skill handoff guide (Module 11) as standing operational tools, clearly separated from the descriptive profile content.
5. **Check consistency** — the quick-reference card should accurately reflect the fuller style guide and spectrum map, not drift from it during condensation.

## Output format

```
=== QUICK-REFERENCE CARD ===
[from Module 12]

=== FULL VOICE PROFILE ===
Spectrum map: [from Module 3]
Signature phrases & devices: [from Module 4]
Style guide (do's/don'ts): [from Module 6]
Channel calibration: [from Module 7]
Before/after samples: [from Module 8]

=== OPERATIONAL TOOLS ===
Drift detector & self-audit checklist: [from Module 9]
Cross-skill handoff guide: [from Module 11]
```

## Handoff

This draft goes straight to Module 14 for a final test before being presented as finished. Once finalized, this document should be saved somewhere durable and referenced by every future Surge skill run for this business, per Module 11's instructions.
