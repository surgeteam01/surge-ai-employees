# Module 12: Prioritized Opportunity Matrix & Skill-Fix Mapper

**Purpose:** Turn every finding from Modules 2-11 into one ranked action list — the actual point of running an audit is knowing what to fix first, not accumulating a pile of disconnected observations.

## Process

1. **Pull every flagged finding forward** from Modules 2 through 11.
2. **Plot each finding on an impact x effort matrix**: "fix now" (high impact, low effort), "plan for" (high impact, high effort), "nice to have" (low impact, any effort) — and deprioritize genuinely low-impact findings rather than padding the list.
3. **Map each finding to the specific Surge skill that addresses it** — per the mappings noted in each module above — or note that it needs external expertise (e.g. an accountant for a Module 8 financial flag, a lawyer for a Module 11 compliance flag).
4. **Weight risk and capacity findings appropriately** — a severe Module 9 bottleneck or Module 11 risk can make an otherwise "nice to have" growth fix unactionable until it's addressed; don't rank purely by growth upside.

## Output format

```
OPPORTUNITY MATRIX

FIX NOW (high impact, low effort)
[Finding] — Source: Module [N] — Fix: [Surge skill name, or external resource]
(repeat)

PLAN FOR (high impact, high effort)
[Finding] — Source: Module [N] — Fix: [Surge skill name, or external resource]
(repeat)

NICE TO HAVE (lower impact)
[Finding] — Source: Module [N] — Fix: [Surge skill name, or external resource]
(repeat)
```

## Handoff

Feeds Module 13. If the user wants to act on a specific finding immediately, hand off directly to the mapped skill rather than waiting for the full report to be assembled.
