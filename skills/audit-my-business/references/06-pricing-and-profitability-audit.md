# Module 6: Pricing & Profitability Audit

**Purpose:** Check whether pricing is defensible and margins are healthy, building directly on Module 2's business-model assessment rather than evaluating price in isolation.

## Process

1. **State current price(s)** for each offer from Module 2's inventory.
2. **Check against market/competitor context**, adapted from `nail-your-pricing`'s Competitor & Market Pricing Scan, if that context is known or can be reasonably estimated.
3. **Do a lightweight margin gut-check** — price versus known cost/time inputs, flagged as directional given Module 1's data limits, not a precise calculation.
4. **Flag underpricing** — one of the most common findings in a first audit — and any inconsistent pricing across channels or client segments.

## Output format

```
CURRENT PRICING: [list, per offer]
MARKET CONTEXT: [where this sits relative to comparable offers, or "insufficient data to compare"]
MARGIN GUT-CHECK: [healthy / thin / unclear] — [basis]
FLAGS: [underpricing, inconsistency across channels, or "none apparent"]
```

## Handoff

Feeds Module 12. Pricing flags map directly to `nail-your-pricing`. If margin data is too thin to assess confidently, say so explicitly rather than guessing, and note it as a Module 14 confidence caveat.
