# Module 9: YouTube SEO & Discoverability Optimizer

**Purpose:** Optimize each video's metadata for YouTube and Google search discovery — a genuinely new mechanic in this repo, since no other skill deals with a platform-native search/recommendation algorithm this directly.

## Process

1. **Write a search-optimized description** — the first 1-2 sentences should naturally include the primary search phrase from Module 3's research (since YouTube weights the opening of the description most heavily), followed by a fuller summary, relevant links, and timestamps for longer videos (timestamps both help viewer navigation and give the algorithm additional topic signals per chapter).
2. **Select tags** — a mix of specific, exact-match phrases (matching Module 3's real search language) and broader category tags, without keyword-stuffing irrelevant terms purely for reach.
3. **Recommend end screen and card placement** — pointing to the most relevant related video or playlist (feeds Module 12), placed at a point in the video where retention naturally starts to dip rather than only at the very end.
4. **Note filename and closed-caption considerations** if relevant — accurate captions/subtitles also feed the algorithm's understanding of the video's content and improve accessibility and search indexing.
5. **Confirm the title (from Module 6) doubles appropriately as a primary keyword target** — flag if the strongest-converting title from Module 6 and the strongest-search-optimized title diverge significantly, and help the user weigh the trade-off rather than silently picking one.

## Output format

```
VIDEO: [from Module 6]

DESCRIPTION:
Opening 1-2 sentences (search-optimized): [...]
Full description: [...]
Timestamps (if applicable): [...]

TAGS: [list — mix of exact-match and category tags]

END SCREEN/CARD PLACEMENT: [timing + which related video/playlist to point to]

TITLE-VS-SEO TRADE-OFF FLAG: [if the best-converting title and best-search title diverge]
```

## Handoff

Feeds Module 13's assembly and Module 12's series/playlist strategy (end screens should point according to that module's structure).
