# Module 12: Series & Playlist Strategist

**Purpose:** Design how individual videos connect into playlists and series that drive session watch-time (a viewer watching several of the channel's videos back to back in one sitting) — a factor YouTube's algorithm rewards distinctly from any single video's own performance.

## Process

1. **Group videos from Module 4's calendar into playlists** by pillar/series, ordered in a way that makes sense to binge (e.g. beginner-to-advanced within a topic, or a narrative sequence for story-driven content).
2. **Design explicit connective tissue between videos** — each video's ending (from Module 7) and end screen (from Module 9) should point to a specific next video in the same playlist, not a generic "check out my other content."
3. **Identify a strong "entry point" video per playlist** — the video most likely to hook a new viewer into the series, which should be the one prioritized for external promotion or a pinned/featured spot on the channel.
4. **Plan for cross-pillar connections sparingly** — occasionally linking between different pillars/series when genuinely relevant expands a viewer's session across more of the channel's total content, but overdoing this dilutes each series' own coherence.

## Output format

```
PLAYLISTS:
[Playlist/series name] — pillar: [x] — order: [video sequence, entry-point video flagged]
(repeat per playlist)

CONNECTIVE TISSUE: [which video's ending points to which next video, per playlist]
CROSS-PILLAR LINKS (sparingly): [any deliberate cross-series connections]
```

## Handoff

Feeds Module 9 (end screen/card targets) and Module 13's full assembly — the finished plan should show explicit next-video pointers, not leave viewers to find related content on their own.
