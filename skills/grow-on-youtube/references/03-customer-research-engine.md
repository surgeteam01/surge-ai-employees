# Module 3: Customer Research Engine

**Purpose:** Build a Voice-of-Customer (VoC) profile — reused directly from `sales-page-that-converts`, adapted here toward what specifically drives a click and a watch on YouTube: the exact questions and searches the audience already has.

## Process

1. **Pull from real material first**: comments on the channel's own videos, comments on competitor/adjacent channels' videos, YouTube's own search suggestions for relevant topics, and support/community questions if any exist. Ask the user before generating from scratch.
2. **If no real material exists**, build a hypothesis-based profile and label it clearly as such, recommending validation against real comment/search data once the channel has some videos live.
3. **Identify search intent specifically** — what would this audience actually type into YouTube search or Google when looking for this content? This is distinct from a generic pain/desire list and feeds directly into Module 9's SEO work.
4. **Extract exact phrases and recurring questions** — these feed Module 5 (video ideas), Module 6 (titles should often mirror real search phrasing), and Module 9 (tags/description keywords).

## Output format

```
TOP PAINS (ranked): [...]
TOP DESIRES (ranked): [...]
RECURRING QUESTIONS/SEARCHES: [specific things the audience actually searches or asks]
EXACT-PHRASE BANK: [words the audience actually uses]

CONFIDENCE: [Real data / Hypothesis — recommend validation]
```

## Handoff

Feeds Module 5's idea generation directly, Module 6's title language, and Module 9's SEO targeting.
