# Module 13: Full Channel Content Plan Assembler

**Purpose:** Assemble every prior module's output into one cohesive, production-ready content plan — the calendar, packaging, full scripts, SEO metadata, and playlist strategy — so the pipeline's output is something the user can actually film and publish from.

## Process

1. **Follow Module 4's calendar** as the skeleton, dropping each video's full package into place: idea/premise (Module 5), title/thumbnail (Module 6), full script with hook (Modules 7-8), retention/engagement mechanics woven in at their specified points (Module 10), subscribe/CTA placements (Module 11), and SEO metadata (Module 9).
2. **Include the playlist/series strategy (Module 12)** as its own clearly labeled section, showing how videos connect.
3. **Check that the script actually delivers on the packaging's promise** — this is the single most important consistency check in this assembly, since a mismatch here is the primary driver of poor retention and audience trust erosion.
4. **Check voice consistency** against the brief from Module 1 (or the linked `write-like-a-human` profile).
5. **Verify nothing was lost**: every video in the calendar should have a complete script, packaging, and SEO metadata.

## Output format

```
=== CONTENT CALENDAR ===
[from Module 4]

=== PER-VIDEO PACKAGES ===

VIDEO [n] — Upload date: [x]
Title: [from Module 6]
Thumbnail concept: [from Module 6]
Full script (hook → content → payoff → subscribe/CTA): [assembled from Modules 7, 8, 10, 11]
SEO metadata: [from Module 9]

(repeat per video)

=== PLAYLIST/SERIES STRATEGY ===
[from Module 12]
```

## Handoff

This draft goes straight to Module 14 for scoring and optimization — don't present this as final without running it through the optimizer, since a first assembly pass can still carry a packaging/script mismatch or a retention structure that's weaker than it looks on paper.
