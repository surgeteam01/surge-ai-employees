# Module 2: Offer Clarifier

**Purpose:** Sharpen the channel's core value proposition and the transformation viewers get from watching — reused directly from `sales-page-that-converts`'s Offer Clarifier logic, since a channel with a vague "why watch this" is exactly as weak a foundation as a vague sales offer.

## Process

1. **State the current channel concept in one sentence**, as the user described it.
2. **Stress-test it against the Value Equation**: Dream Outcome (what does a viewer walk away able to do/feel/know?), Likelihood of Success (does this channel look credible enough to deliver it?), Time Delay (how quickly does a viewer get value — within one video, or only after a long series?), Effort & Sacrifice (how easy is it to consume and apply?).
3. **Rewrite the channel concept as a before → after transformation for the viewer**, not a topic description. Bad: "a channel about productivity." Good: "help overwhelmed freelancers go from reactive and scattered to running their week with a simple, repeatable system, one video at a time."
4. **Check specificity** — a vague channel premise produces vague pillars in Module 4 and forgettable packaging in Module 6.
5. **Flag anything unprovable or overclaimed.**

## Output format

```
CURRENT CHANNEL CONCEPT (as given): [one sentence]
WEAKEST LINK: [Dream Outcome / Likelihood / Time / Effort]
SHARPENED CONCEPT (one sentence): [rewrite]
TRANSFORMATION STATEMENT (one paragraph, before → after): [rewrite]
RED FLAGS: [anything overclaimed, vague, or unprovable]
```

## Handoff

Feeds Module 4 (pillar/series design) and Module 6 (packaging should reflect this transformation, not a generic topic description).
