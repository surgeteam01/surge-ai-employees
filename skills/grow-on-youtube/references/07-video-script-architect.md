# Module 7: Video Script Architect

**Purpose:** Structure the full script for retention — YouTube's algorithm weighs watch-time and average-view-duration heavily, which means a script's structure (not just its content quality) directly determines how far the video travels, independent of the packaging that got the click in the first place.

## Process

1. **Confirm the premise the packaging (Module 6) promised** — the script's entire structure should build toward genuinely delivering on that specific promise, not wander into tangential territory the title/thumbnail didn't set up.
2. **Structure for retention using a clear arc**: hook (see Module 8 — the first 15-30 seconds for long-form, 1-3 seconds for Shorts), a quick preview of what's coming (reduces early drop-off by showing the payoff is real and worth staying for), the main content delivered in clearly sequenced steps or beats, periodic pattern interrupts (a visual change, a story beat, a question posed to camera) roughly every 30-90 seconds to counter natural attention decay, and a payoff that clearly delivers what was promised.
3. **Avoid long, unbroken stretches of a single format** (e.g. five minutes of straight talking-head with no visual or pacing change) — retention graphs consistently drop during monotone stretches regardless of how good the information is; note where a visual change, b-roll, or a pacing shift should occur even if the exact production detail is left to the user.
4. **Plan the ending deliberately** — a strong video ending points to a specific next video or playlist (feeds Module 12) rather than trailing off, since what happens in the last 10-15 seconds affects session watch-time, which the algorithm also rewards.
5. **Time-box each section roughly** against a realistic total length for the format (Module 1) — flag if the structure as planned would run unrealistically long or short for what the topic needs.

## Output format

```
SCRIPT STRUCTURE (target length: [x]):

HOOK (0:00-0:[x]) — see Module 8

PREVIEW/PROMISE (immediately after hook): [what's coming, briefly]

MAIN CONTENT:
Beat 1 [~x min]: [content] — pacing note: [any visual/format change point]
Beat 2 [~x min]: [content] — pacing note: [...]
(repeat per beat)

PAYOFF: [delivers on the packaging's promise explicitly]

ENDING: [specific next-video/playlist pointer — feeds Module 12]

LENGTH FLAG: [any concern that the structure runs unrealistically long/short]
```

## Handoff

This structure is what Module 8 fills in with the actual hook script, Module 10 layers pattern-interrupt/engagement mechanics onto, and Module 13 assembles into the full production-ready script.
