# Module 5: Video Idea Generator

**Purpose:** Generate specific, non-repetitive video ideas mapped to Module 4's calendar — adapted directly from `30-days-of-content`'s Content Idea Generator, using the same logic (draw from real audience questions, check for repetition, tag each idea to a pillar) with one YouTube-specific addition: checking each idea against real search intent.

## Process

1. **For each upload slot in Module 4's calendar, generate one specific, concrete video idea** within the assigned pillar — not a vague topic but a specific angle, ideally phrased close to how the audience would actually search for it (per Module 3's recurring questions/searches).
2. **Check each idea against search intent** — does this idea answer a real, specific search a viewer would actually type in? An idea with clear search intent behind it has a built-in discovery advantage a purely "interesting to us" topic doesn't.
3. **Check for repetition across the calendar** — flag any two ideas too similar in angle, even across different pillars.
4. **Note a rough "premise" for each idea** — the one-sentence hook of what makes this specific video worth watching over any other video on a similar topic, since this premise directly feeds Module 6's packaging.

## Output format

```
VIDEO IDEAS:

UPLOAD [n] — Pillar: [x]
Idea: [specific, concrete one-line summary]
Search intent match: [the real search/question this answers]
Premise (why watch this one): [one line]

(repeat per upload slot in Module 4's calendar)

REPETITION CHECK: [any two ideas flagged as too similar, and how revised]
```

## Handoff

Feeds Module 6 (packaging is built directly from each idea's premise) and Module 7 (script architecture starts from the idea + premise).
