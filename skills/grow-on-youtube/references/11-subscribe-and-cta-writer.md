# Module 11: Subscribe & CTA Writer

**Purpose:** Write the subscribe ask and any conversion-oriented CTA (to a lead magnet, offer, or another channel asset) — adapted from `sales-page-that-converts`'s CTA & Close Writer, sized for YouTube's specific tolerance for interruption.

## Process

1. **Write a specific subscribe ask** tied to a reason, not a bare request — "subscribe if you want the rest of this series" beats a generic "don't forget to subscribe," since it gives the viewer an actual reason tied to value they've already experienced in this video.
2. **Place the subscribe ask at a natural high-value moment** (often right after delivering a strong payoff), not at the very start (before value has been demonstrated) or stacked awkwardly with multiple other asks.
3. **Write any conversion CTA** (pointing to an offer, lead magnet, or the business's other assets) if relevant to Module 1's goals — kept brief and placed so it doesn't undercut retention right when the algorithm is weighing whether to keep recommending the video.
4. **Keep total CTA load light** — a video that's constantly asking for something reads as more interested in extraction than in delivering value, which damages both trust and retention.

## Output format

```
SUBSCRIBE ASK: [specific, reason-tied copy] — placement: [timing in the script]
CONVERSION CTA (if applicable): [copy] — placement: [timing]
```

## Handoff

Feeds Module 13's final assembly at the specified placements.
