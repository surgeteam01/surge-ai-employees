# Module 13: Full Build Plan Assembler

**Purpose:** Assemble every prior module's output into one cohesive build plan — the scope, stack, sequence, and every supporting guide the user needs to actually go build, ship, and iterate on the project.

## Process

1. **Lead with the concrete scope and MVP definition (Modules 2, 4)** — this is the plan's anchor.
2. **Include the stack/architecture (Modules 3, 5)** as the technical foundation.
3. **Include the prompting technique (Module 6) and build sequence (Module 7) together**, since they're meant to be used in tandem during actual building.
4. **Include the testing checkpoints (Module 8) inline with each build step**, not as a separate disconnected list.
5. **Include the debugging guide (Module 9), deployment guide (Module 10), documentation (Module 11), and feedback loop (Module 12)** as standing reference sections for after initial building begins.

## Output format

```
=== SCOPE & MVP ===
[from Modules 2, 4]

=== TECH STACK & ARCHITECTURE ===
[from Modules 3, 5]

=== BUILD SEQUENCE (with prompting technique + testing checkpoints inline) ===
[from Modules 6, 7, 8, combined per step]

=== DEBUGGING GUIDE (standing reference) ===
[from Module 9]

=== DEPLOYMENT & SHARING ===
[from Module 10]

=== DOCUMENTATION ===
[from Module 11]

=== ITERATION & FEEDBACK LOOP ===
[from Module 12]
```

## Handoff

This draft goes straight to Module 14 for scoring before being presented as final.
