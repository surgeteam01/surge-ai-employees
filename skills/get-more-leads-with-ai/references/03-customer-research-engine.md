# Module 3: Customer Research Engine

**Purpose:** Build a Voice-of-Customer profile — reused directly from `sales-page-that-converts`.

## Process

1. **Pull from real material first**: past lead conversations, support questions, chatbot transcripts if any exist. Ask before generating from scratch.
2. **If none exists**, build a hypothesis-based profile, labeled as such.
3. **Identify the buyer awareness stage** — shapes Module 4's lead magnet choice and Module 5's chatbot qualification questions.
4. **Extract exact phrases and recurring questions** — feeds Module 5's chatbot script and Module 6's scoring criteria.

## Output format

```
AWARENESS STAGE: [...]
TOP PAINS (ranked): [...]
TOP DESIRES (ranked): [...]
RECURRING QUESTIONS: [...]
EXACT-PHRASE BANK: [...]
CONFIDENCE: [Real data / Hypothesis]
```

## Handoff

Feeds Module 4, 5, and 6 directly.
