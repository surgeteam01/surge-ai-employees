# Module 10: Appointment/Booking Automation Designer

**Purpose:** Design frictionless scheduling automation for hot leads (per Module 6's routing) — a genuinely new mechanic in this repo, since no other skill deals with the mechanics of automated calendar booking specifically.

## Process

1. **Design the booking flow** — from the moment a lead is scored hot (via the chatbot, Module 5, or a scoring trigger from Module 6/9) to a booked call, minimizing steps: a direct scheduling link with real-time availability beats a "someone will reach out to schedule" manual process.
2. **Design confirmation and reminder automation** — an immediate booking confirmation, and reminder touches (per typical no-show-reduction cadence: 24 hours before, 1 hour before) similar in spirit to `run-webinars-that-sell`'s reminder sequence logic but for a 1:1 call rather than a group event.
3. **Design a pre-call brief automation** — if the lead has provided qualification info (Module 5/6), automatically surface a summary to whoever's taking the call so they walk in prepared, rather than starting the call cold.
4. **Design a no-show recovery flow** — an automated, non-judgmental follow-up offering an easy re-book path if a lead misses their scheduled call.

## Output format

```
BOOKING FLOW: [from hot-lead trigger to booked call, minimal-friction steps]
CONFIRMATION/REMINDER AUTOMATION: [immediate confirmation + reminder cadence]
PRE-CALL BRIEF AUTOMATION: [what qualification info gets surfaced to whoever takes the call]
NO-SHOW RECOVERY FLOW: [automated, non-judgmental re-book offer]
```

## Handoff

Feeds Module 13's assembly as the hot-lead automation track, and Module 11's tool recommendation should confirm a specific scheduling tool that can support this flow.
