# Module 4: Lead Magnet & Capture Mechanism Designer

**Purpose:** Design the specific asset or mechanism that actually captures a lead's contact information in exchange for value — the entry point every other module in this pipeline builds around.

## Process

1. **Choose a capture mechanism type** matched to Module 2's offer and Module 3's awareness stage: a downloadable resource (checklist, template, guide) for straightforward value exchange, an interactive quiz/assessment (higher engagement, naturally produces qualification data usable in Module 6), a calculator/tool (strong for offers with a quantifiable outcome), or a free consultation/audit offer (works well for high-ticket, considered-purchase offers).
2. **Design the specific lead magnet content** — concrete and narrow enough to deliver real value in a single sitting, directly tied to Module 2's transformation, not a generic "free guide" with no specific promise.
3. **Design the capture form** — minimal required fields (more fields reduce conversion; only ask for what's genuinely needed for qualification per Module 6 or immediate follow-up per Module 8), and a clear value restatement right at the point of asking for contact info.
4. **Decide placement** — where this mechanism will actually appear (website, ads, social bio, chatbot handoff from Module 5) consistent with Module 1's existing traffic sources.

## Output format

```
CAPTURE MECHANISM TYPE: [downloadable / quiz / calculator / consultation offer] — reason: [offer + awareness fit]
LEAD MAGNET CONTENT: [specific, concrete description of what's delivered]
CAPTURE FORM: [fields requested, value restatement copy]
PLACEMENT: [where this appears]
```

## Handoff

Feeds Module 5 (the chatbot may deliver or lead into this mechanism) and Module 6 (any quiz/qualification data collected here feeds scoring directly).
