# Module 11: Tool & Workflow Stack Recommender

**Purpose:** Recommend a realistic, budget-appropriate stack of AI/automation tools that can actually implement everything designed in the prior modules — this module exists because a lead-gen automation plan is only as good as its actual implementability, and the biggest risk in this whole skill is designing a system too sophisticated for the user's real budget and technical capacity.

## Process

1. **Map each prior module's requirement to a tool category**: chatbot platform (for Module 5), CRM/scoring automation (for Module 6), enrichment/research tooling (for Module 7, if beyond manual research), email/outreach automation (for Modules 8-9), and scheduling tooling (for Module 10).
2. **Recommend specific tool categories and tiers** matched to Module 1's budget and existing stack — favor tools that integrate with what's already in place over recommending a full stack replacement, and favor simpler, cheaper tools that cover 80% of the need over expensive, complex ones the user won't actually configure and maintain.
3. **Flag any module's design that exceeds realistic budget/capacity** — if Module 5's chatbot flow, for instance, requires a tier of tool beyond Module 1's stated budget, say so directly and offer a simplified version that fits the real constraint rather than silently keeping an unaffordable design.
4. **Note integration/setup complexity honestly** — some automations are genuinely simple to set up; others require real technical work or a paid implementation service, and the user should know which is which before committing to the plan.

## Output format

```
TOOL STACK RECOMMENDATION (by category):
Chatbot platform: [tool category/tier] — fits budget: [yes/no, reasoning]
CRM/scoring automation: [tool category/tier] — fits budget: [yes/no]
Enrichment/research tooling: [tool category/tier, or "manual — no tool needed at this volume"]
Outreach automation: [tool category/tier]
Scheduling tooling: [tool category/tier]

BUDGET/CAPACITY FLAGS: [any module's design that exceeds Module 1's constraints, and the simplified alternative]
SETUP COMPLEXITY NOTES: [what's simple DIY setup vs. what needs real technical work]
```

## Handoff

Feeds Module 13's assembly as the implementation layer, and any flagged mismatch here should trigger a revisit of the over-scoped module rather than being silently ignored.
