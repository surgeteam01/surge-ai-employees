# Module 2: Offer Clarifier

**Purpose:** Sharpen the offer and transformation — reused directly from `sales-page-that-converts`'s Offer Clarifier logic.

## Process

1. **State the current offer in one sentence.**
2. **Stress-test against the Value Equation.**
3. **Rewrite as a before → after transformation.**
4. **Check specificity** — a vague offer produces a weak lead magnet (Module 4) and generic chatbot flow (Module 5).
5. **Flag anything unprovable or overclaimed.**

## Output format

```
CURRENT OFFER: [one sentence]
WEAKEST LINK: [Dream Outcome / Likelihood / Time / Effort]
SHARPENED OFFER: [rewrite]
TRANSFORMATION STATEMENT: [rewrite]
RED FLAGS: [...]
```

## Handoff

Feeds Module 4 (lead magnet) and Module 5 (chatbot flow).
