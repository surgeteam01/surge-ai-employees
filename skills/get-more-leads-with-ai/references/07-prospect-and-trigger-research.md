# Module 7: Prospect & Trigger Research

**Purpose:** Find personalization signals for warm/hot leads before automated outreach — reused directly from `land-clients-with-cold-outreach`'s Prospect & Trigger Research module, since the underlying logic (personalization depth vs. list size, trigger events, segment-level variables) applies identically here.

## Process

Follow `land-clients-with-cold-outreach`'s Module 4 process exactly: distinguish 1:1 vs. segment-level personalization based on realistic volume and tooling, identify detectable trigger events, build personalization variables per segment, and flag any gap between desired personalization depth and what's realistic.

## Output format

Same as `land-clients-with-cold-outreach`'s Module 4 output format — personalization level, trigger events, personalization variables per segment, and a feasibility flag.

## Handoff

Feeds Module 8's automated outreach directly — messages should reference these variables/triggers, not invent research that wasn't actually gathered.
