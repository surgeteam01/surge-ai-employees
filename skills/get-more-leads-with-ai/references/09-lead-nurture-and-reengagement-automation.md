# Module 9: Lead Nurture & Re-engagement Automation

**Purpose:** Design automated nurture for leads scored as "not yet ready" (per Module 6) — adapted from `build-your-email-funnel`'s Nurture Sequence Writer, since the underlying value-first logic is identical.

## Process

1. **Follow `build-your-email-funnel`'s Nurture Sequence Writer process**: pick value themes per touch tied to the transformation (Module 2), weave in light proof/objection-handling, end each touch with a soft CTA, and build toward a bridge that eventually re-offers a path to Module 6's scoring (e.g. a re-engagement touch that re-invites the lead to the chatbot or a fresh qualification question).
2. **Design automated re-scoring triggers** — specific engagement signals (opening several nurture emails, clicking through to a pricing page, returning to the site) that should automatically bump a lead's score and re-route them into Module 8's warmer outreach track rather than leaving them in nurture indefinitely.
3. **Set a realistic nurture duration and cadence** — long enough to build genuine trust, but with a defined re-evaluation point rather than an indefinite drip that never re-assesses fit.

## Output format

```
NURTURE SEQUENCE ([count] touches, cadence: [x]):
TOUCH 1 — [value theme]: [body]
(repeat)

RE-SCORING TRIGGERS: [specific engagement signals that bump a lead back toward Module 8's warmer track]
NURTURE DURATION/RE-EVALUATION POINT: [x weeks, then re-assess]
```

## Handoff

Feeds Module 13's assembly as the cold-lead automation track, with explicit re-routing logic back into Module 6/8.
