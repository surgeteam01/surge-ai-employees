# Module 13: Full Analysis Report Assembler

**Purpose:** Assemble every prior module's output into one cohesive, decision-ready report — following Module 10's structure, with every section grounded in the actual analysis rather than restated separately.

## Process

1. **Follow Module 10's report structure** as the skeleton: executive summary, key findings, supporting visuals, methodology/caveats, recommendations.
2. **Lead the executive summary with Module 9's direct answer** to the sharpened question (Module 3).
3. **Weave Module 11's pre-empted alternative explanations into the findings or caveats section**, not as a separate defensive appendix.
4. **Include Module 12's prioritized recommendations** as the closing, action-oriented section.
5. **Check consistency**: every metric referenced should match Module 4's definitions exactly, and every chart (Module 8) should support a specific finding rather than existing decoratively.

```

[Direct answer + top insights, from Module 9]

=== KEY FINDINGS ===
[from Module 6, 7, 9 — with confidence levels stated honestly]

=== SUPPORTING VISUALS ===
[from Module 8, built via the dataviz skill]

=== METHODOLOGY & CAVEATS ===

[from Module 12, prioritized]
```
