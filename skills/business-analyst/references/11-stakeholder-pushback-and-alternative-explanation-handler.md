# Module 11: Stakeholder Pushback & Alternative-Explanation Handler

**Purpose:** Anticipate the pushback and alternative explanations a stakeholder will raise, and address them before presenting — adapted in spirit from `sales-page-that-converts`'s Objection Handler, applied here to ruling out alternative explanations rather than selling. This is what separates a rigorous analysis from one that merely looks persuasive until someone asks the obvious follow-up question.

## Process

1. **Generate the likely pushback questions** a skeptical, informed stakeholder would ask: "couldn't this just be seasonality?", "did you control for [an obvious confounding factor]?", "is this sample size big enough to trust?", "what about [a specific event] that happened during this period?"
2. **Answer each honestly using Module 6/7's actual analysis** — if a pushback question was already addressed during root-cause analysis, reference that finding directly; if it wasn't considered, go back and check it now rather than presenting a report with an obvious, un-addressed hole.
3. **Identify the single strongest alternative explanation** for the main finding and address it head-on in the report itself, not just in a defensive answer if asked — pre-empting the most likely challenge is more credible than waiting to be caught by it.
4. **Be willing to revise the conclusion** if a pushback question reveals a genuine weakness in the analysis — this module's job is to strengthen the analysis by stress-testing it, not to produce talking points that paper over a real gap.

## Output format

```
ANTICIPATED PUSHBACK:
Q: [likely stakeholder question] → A: [honest answer, tied to actual analysis, or "addressed by re-checking Module 6/7"]
(repeat per likely question)

STRONGEST ALTERNATIVE EXPLANATION (addressed directly in the report): [...]

REVISIONS MADE (if any pushback revealed a genuine gap): [...]
```

## Handoff

The strongest alternative explanation and its rebuttal should be woven directly into Module 10's report structure (often within the findings or caveats section), not held back as a defensive reserve.
