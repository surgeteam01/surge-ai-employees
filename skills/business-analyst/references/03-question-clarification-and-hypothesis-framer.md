# Module 3: Question Clarification & Hypothesis Framer

**Purpose:** Sharpen the actual business question being asked — adapted from the Offer Clarifier pattern used throughout this repo, applied here to an analytical question instead of a sales offer. A vague question ("how are we doing?" or "why did this happen?") produces an unfocused analysis that can't be judged as having actually answered anything.

## Process

1. **State the question as given** in Module 1's brief.
2. **Push for specificity**: what exact metric, over what exact time period, compared to what baseline (last month? last year? a target? a competitor?)? "Why did revenue drop" becomes "why did monthly recurring revenue drop 8% in March compared to February, and was it driven by churn, lower new-customer volume, or lower average deal size?"
3. **Generate candidate hypotheses** for what could explain the pattern, drawing on business context (Module 1) — a starting set of plausible explanations to test against, not a predetermined conclusion.
4. **Confirm the sharpened question is actually answerable** given Module 2's data inventory — if it isn't, say so and either adjust the question to what's answerable or flag what additional data would be needed.

## Output format

```
QUESTION AS GIVEN: [original]
SHARPENED QUESTION: [specific metric, time period, baseline]

CANDIDATE HYPOTHESES: [list of plausible explanations to test, not a predetermined answer]

ANSWERABILITY CHECK: [confirmed answerable with Module 2's data / needs adjustment or additional data]
```

## Handoff

The sharpened question and hypotheses drive Module 5's exploratory analysis plan directly — every analysis step should trace back to testing one of these hypotheses, not wandering into unrelated exploration.
