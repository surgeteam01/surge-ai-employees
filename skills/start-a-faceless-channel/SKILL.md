# Start a Faceless Channel

A 14-stage pipeline that takes a raw channel concept through to a finished, CTR- and retention-scored faceless channel system — pillars, packaging, narration scripts built for voiceover-only delivery, visual pacing, voice selection, and a brand identity that builds recognition without a personal face. Each stage is a focused reference module in `references/`. Run them in order — each one's output becomes the next one's input.

This skill reuses most of `grow-on-youtube`'s pipeline directly — packaging, retention/engagement mechanics, SEO, and the optimizer are identical mechanics regardless of whether a presenter appears on camera. What's genuinely different is the script (written for narration rather than spoken-to-camera delivery, since there's no facial expression or body language doing persuasive work), the reliance on visual pacing and voice selection to substitute for a live presenter's dynamism, and a brand identity strategy built around consistent visual/audio signatures instead of a recognizable face.

## How to run this skill

1. **Check for an existing Channel Brief, `find-your-niche` profile, or `30-days-of-content`/`grow-on-youtube` calendar** before re-asking anything.
2. **Work through stages 1–14 in order.**
3. **Treat Module 12 (branding without a face) as seriously as Module 6 (packaging)** — without a recognizable presenter, a consistent visual/audio signature is what turns one-time viewers into subscribers who recognize the channel on sight.
4. **Always end with Module 14.**

## Inputs this skill needs (collected in Stage 1)

Channel niche, existing stats, target audience, visual production approach (stock footage, licensed clips, animation, AI-generated visuals), voice source (AI-generated or hired voiceover artist), production budget/capacity, upload cadence goal, and any constraints (copyright/licensing limits on footage, platform monetization policy considerations for faceless content specifically).
