# Module 4: Content Pillar & Calendar Planner

**Purpose:** Define recurring content pillars/series and an upload calendar — reused directly from `grow-on-youtube`'s equivalent module (itself adapted from `30-days-of-content`).

## Process

1. **Define 3-5 content pillars/series** connecting to Module 2's transformation and Module 3's search intents.
2. **Set a realistic upload cadence** from Module 1's production capacity — faceless channels often scale cadence more aggressively than personality channels since production doesn't depend on one person's on-camera availability, but should still stay within real editing/voiceover/visual-sourcing capacity.
3. **Distribute pillars across the calendar** for variety.
4. **Favor a recognizable recurring format per pillar** (a consistent intro pattern, a consistent narration style per series) since format consistency substitutes partly for the recognition a face would normally provide.

## Output format

```
CONTENT PILLARS/SERIES: [1-5, with job + connection to transformation/search intent]
UPLOAD CADENCE: [frequency]
CALENDAR: [pillar assignment per upload]
```
