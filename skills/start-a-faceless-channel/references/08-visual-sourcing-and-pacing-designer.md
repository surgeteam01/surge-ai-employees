# Module 8: Visual Sourcing & Pacing Designer

**Purpose:** Design the visual track that syncs to Module 7's narration and substitutes for the dynamism a live presenter would otherwise provide — a genuinely new mechanic in this repo, since no on-camera skill needs to solve this problem.

## Process

1. **Match visual type to Module 1's production approach**: stock/licensed footage (identify specific search terms/sources per beat), animation (describe what should be animated per beat, at a level a motion designer or AI animation tool could act on), or AI-generated visuals (describe the specific prompt/scene per beat).
2. **Sync visuals to Module 7's visual-cut markers** — assign a specific visual to each marked interval, ensuring genuine variety rather than looping the same clip repeatedly, which reads as low-effort and hurts retention.
3. **Design for visual variety types**, not just cut frequency: wide shots vs. close-ups, motion vs. static, on-screen text call-outs reinforcing key narration points, and occasional graphics/data visualizations for factual/statistical content.
4. **Flag any copyright/licensing concern** given Module 1's constraints — confirm the visual sourcing plan only uses properly licensed or original material, since this is a real risk area for faceless channels relying on external footage.
5. **Recommend on-screen text overlays for key statements** — reinforcing the narration's most important lines in text on screen both aids retention (visually stimulating) and improves accessibility/watch-without-sound viewing, which faceless content often benefits from more than personality content since factual/list-style content translates well to silent viewing.

## Output format

```
VISUAL PLAN (synced to Module 7's markers):

Beat 1: [visual description/source/prompt] — variety type: [wide/close-up/motion/static/text overlay]
Beat 2: [...]
(repeat per beat)

ON-SCREEN TEXT OVERLAYS: [key narration lines to reinforce visually]
LICENSING/COPYRIGHT CHECK: [confirm all sourcing fits Module 1's constraints]
```

## Handoff

Feeds Module 13's full assembly as the production-ready visual brief alongside the narration script.
