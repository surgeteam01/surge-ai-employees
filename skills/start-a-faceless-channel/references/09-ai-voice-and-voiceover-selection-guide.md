# Module 9: AI Voice / Voiceover Selection Guide

**Purpose:** Choose and direct the voice that delivers the narration — a genuinely new mechanic in this repo, since the voice itself substitutes for much of what a presenter's on-camera personality would otherwise establish (tone, trustworthiness, energy, brand feel).

## Process

1. **Match voice characteristics to the channel's brand and content type** (from Module 1/2): tone (warm/authoritative/energetic/calm), pacing (a documentary/explainer channel typically wants a measured, clear pace; a high-energy list/compilation channel wants faster, punchier delivery), and accent/register appropriate to the target audience.
2. **If using an AI voice**, recommend a small number of specific candidate voices/tools to test against a sample of Module 7's script, and specify direction notes (emphasis, pacing, pause length) that the chosen tool can actually apply, rather than assuming a generic default setting will correctly interpret Module 7's emphasis markers.
3. **If using a hired human voiceover artist**, write a clear direction brief: tone, pacing, specific words/phrases to emphasize (pulled directly from Module 7's emphasis notes), and reference examples of similar channels' voice style if helpful for calibration.
4. **Confirm voice consistency across videos** — the same voice (or a small consistent set of voices for different content types) should be used across the channel, since voice consistency functions as part of the brand identity a face would normally provide (feeds Module 12 directly).

## Output format

```
VOICE CHARACTERISTICS NEEDED: [tone, pacing, register] — reason: [channel brand + content type fit]

IF AI VOICE: candidate tools/voices to test: [list] — direction notes for emphasis/pacing: [from Module 7]
IF HUMAN VOICEOVER: direction brief: [tone, pacing, emphasis words, reference examples]

CONSISTENCY PLAN: [confirm same voice/voice set used across all videos]
```

## Handoff

Feeds Module 12 (voice consistency is part of the brand identity) and Module 13's production assembly.
