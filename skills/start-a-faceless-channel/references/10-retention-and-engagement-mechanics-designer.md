# Module 10: Retention & Engagement Mechanics Designer

**Purpose:** Design pattern interrupts, open loops, and engagement prompts — reused directly from `grow-on-youtube`'s equivalent module, with visual/narration cut points (Module 7/8) serving as the primary pattern-interrupt mechanic in place of a presenter's live energy shifts.

## Process

1. **Design pattern interrupts using the visual variety from Module 8** — a cut to a new visual type, an on-screen text callout, or a shift in narration pacing all function as pattern interrupts in a faceless format.
2. **Design at least one open loop** planted early in Module 7's narration and resolved later.
3. **Design engagement prompts placed for minimal retention cost** — a comment prompt or subscribe ask delivered in narration at a natural pause point, phrased specifically.
4. **Avoid over-stacking engagement asks.**

## Output format

```
PATTERN INTERRUPTS: [tied to Module 8's visual variety and Module 7's pacing]
OPEN LOOP: [planted early] → [resolved later]
ENGAGEMENT PROMPT: [specific ask] — placement: [natural pause point in narration]
```

## Handoff

Woven into Module 13's final assembled script and visual plan at the specified points.
