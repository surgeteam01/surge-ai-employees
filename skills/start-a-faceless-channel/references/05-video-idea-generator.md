# Module 5: Video Idea Generator

**Purpose:** Generate specific, non-repetitive video ideas mapped to Module 4's calendar — reused directly from `grow-on-youtube`'s equivalent module.

## Process

1. **For each upload slot, generate one specific, concrete idea** within the assigned pillar, checked against real search intent (Module 3).
2. **Favor ideas that work well without a presenter** — narrative/documentary structure, list/ranking formats, mystery/explainer structure, and compilation formats all translate naturally to faceless production; ideas that depend on visible personal reaction or physical demonstration translate poorly and should be flagged as a weaker fit for this format.
3. **Check for repetition across the calendar.**
4. **Note each idea's premise** — feeds Module 6's packaging directly.

## Output format

```
VIDEO IDEAS:
UPLOAD [n] — Pillar: [x]
Idea: [specific, concrete summary]
Faceless-format fit: [strong / requires adaptation — note if the idea leans on something a presenter would normally carry]
Premise: [one line]

REPETITION CHECK: [...]
```

## Handoff

Feeds Module 6 (packaging) and Module 7 (script).
