# Module 7: Narration Script Architect

**Purpose:** Structure the full script for narration-only delivery — this is the single most important adaptation this skill makes to `grow-on-youtube`'s Video Script Architect, since without a face or body language doing persuasive and emotional work, the script's words, pacing, and the visuals synced to it have to carry all of that load themselves.

## Process

1. **Confirm the premise the packaging (Module 6) promised**, same as `grow-on-youtube`.
2. **Structure for retention with narration-specific pacing**: a hook delivered in confident, clear narration within the first 10-15 seconds, a preview of what's coming, main content delivered in clearly sequenced narrated beats, and a payoff.
3. **Write for the ear, not the eye** — narration scripts should use shorter sentences and simpler clause structures than a page of prose would, since a listener can't re-read a confusing sentence; read every line aloud (or imagine it read aloud) as part of writing it.
4. **Mark emotional/emphasis beats explicitly in the script** — since there's no face or gesture to carry emphasis, the narration itself (word choice, sentence rhythm, deliberate short punchy sentences at key moments) has to signal what a presenter's tone or expression normally would; note where the pacing should slow down, speed up, or pause for effect.
5. **Plan visual-cut points directly into the script** — since the visual track (Module 8) has to substitute for a live presenter's dynamism, mark roughly where the visual should change (every 3-8 seconds is common for narration-driven content, considerably tighter than a talking-head video's natural cut rate) so Module 8 has clear sync points rather than needing to invent them independently.

## Output format

```
NARRATION SCRIPT (target length: [x]):

HOOK (0:00-0:[x]): [narration text] — emphasis notes: [pacing/tone cues]
PREVIEW/PROMISE: [narration text]

MAIN CONTENT:
Beat 1 [~x min]: [narration text] — emphasis notes: [...] — visual-cut markers: [roughly every x seconds]
Beat 2 [~x min]: [narration text] — emphasis notes: [...] — visual-cut markers: [...]
(repeat per beat)

PAYOFF: [narration text, delivers on packaging's promise]
ENDING: [narration text, points to next video — feeds Module 12's branding and Module 11's SEO end-screen strategy]
```

## Handoff

This script, with its visual-cut markers, is the direct input to Module 8 (visual sourcing/pacing) and Module 9 (voice selection needs to know the emphasis/tone cues to direct the delivery correctly).
