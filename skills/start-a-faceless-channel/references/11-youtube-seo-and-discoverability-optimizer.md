# Module 11: YouTube SEO & Discoverability Optimizer

**Purpose:** Optimize each video's metadata for search — reused directly from `grow-on-youtube`'s equivalent module, with added weight given that faceless channels often rely on search discovery more heavily than subscriber loyalty to a recognizable person.

## Process

1. **Write a search-optimized description**, opening 1-2 sentences using Module 3's primary search phrase, followed by a fuller summary and timestamps.
2. **Select tags** — exact-match phrases from Module 3 plus broader category tags.
3. **Recommend end screen and card placement** pointing to the most relevant related video.
4. **Confirm the title (Module 6) doubles as a strong search-keyword target**, flagging any divergence between the best-converting and best-search-optimized title.

## Output format

```
DESCRIPTION: [opening sentences, full description, timestamps]
TAGS: [list]
END SCREEN/CARD PLACEMENT: [timing + target]
TITLE-VS-SEO TRADE-OFF FLAG: [if applicable]
```

## Handoff

Feeds Module 13's assembly.
