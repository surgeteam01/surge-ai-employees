# Module 2: Offer Clarifier

**Purpose:** Sharpen the channel's core value proposition — reused directly from `sales-page-that-converts`'s Offer Clarifier logic, identical to `grow-on-youtube`'s adaptation.

## Process

1. **State the current channel concept in one sentence.**
2. **Stress-test against the Value Equation**: Dream Outcome, Likelihood of Success, Time Delay, Effort & Sacrifice.
3. **Rewrite as a before → after transformation for the viewer.**
4. **Check specificity** — faceless channels in particular succeed on a sharp, specific content premise since there's no personality pulling viewers through a vague one.
5. **Flag anything unprovable or overclaimed.**

## Output format

```
CURRENT CHANNEL CONCEPT: [one sentence]
WEAKEST LINK: [Dream Outcome / Likelihood / Time / Effort]
SHARPENED CONCEPT: [rewrite]
TRANSFORMATION STATEMENT: [rewrite]
RED FLAGS: [...]
```
