**Purpose:** Capture the channel concept, production approach, and constraints once, so every later module works from the same facts.

## When to run this

First thing, every time — but skip re-asking anything already known. Check whether a `find-your-niche` profile or an existing `grow-on-youtube`/`30-days-of-content` calendar exists.

## What to collect (the Faceless Channel Brief)

- **Channel niche** — what is the channel about?
- **Existing stats, if any** — subscribers, average views, top-performing videos.
- **Target audience** — pull from `find-your-niche` if it exists.
- **Visual production approach** — stock footage/licensed clips, animation, AI-generated visuals, or a mix? This shapes Module 8 significantly.
- **Voice source** — an AI-generated voice, a hired human voiceover artist, or the user's own voice recorded without appearing on camera? Shapes Module 9.
- **Production budget/capacity** — what's realistic per video in terms of time and cost?
- **Upload cadence goal.**
- **Constraints** — copyright/licensing limits on footage sources, and any platform monetization policy considerations specific to faceless/reused-content channels (YouTube has specific policies on "repetitious" or purely reused content that a faceless channel needs to stay clearly on the right side of through genuine added value and original narration/editing).

## Output format

```
FACELESS CHANNEL BRIEF
Channel: [niche]
Existing stats: [detail, or "new channel"]
Audience: [segment, or "see find-your-niche profile"]
Visual approach: [stock/licensed / animation / AI-generated / mix]
Voice source: [AI voice / hired voiceover / user's own voice, off-camera]
Production budget/capacity: [detail]
Upload cadence goal: [detail]
Constraints: [licensing limits, monetization policy considerations]
```

## Handoff

Pass this brief forward unchanged to every subsequent module.
