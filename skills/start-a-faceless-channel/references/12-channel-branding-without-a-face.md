# Module 12: Channel Branding Without a Face

**Purpose:** Design the visual and audio identity system that builds channel recognition in place of a presenter's face — a genuinely new mechanic in this repo, since every other content-brand skill has a real person to anchor recognition around.

## Process

1. **Design a consistent visual signature**: a recurring intro/outro treatment, a consistent color grade or visual style across videos, a consistent thumbnail template/composition style, and a channel logo/watermark that appears in every video — the goal is that a viewer scrolling their subscription feed recognizes this channel's content at a glance, the same job a familiar face would otherwise do.
2. **Confirm voice consistency** (from Module 9) as a core brand element — a consistent, recognizable narration voice across videos functions similarly to a recognizable presenter's voice.
3. **Design a consistent narration "personality" in the writing itself** — even without a face, Module 7's scripts can carry a consistent point of view, sense of humor, or perspective that gives the channel a felt identity beyond just visual consistency.
4. **Recommend a channel name and description that reinforce this identity** — clear enough that a new viewer immediately understands the channel's recurring value, consistent with Module 2's sharpened concept.

## Output format

```
VISUAL SIGNATURE: [intro/outro treatment, color grade/style, thumbnail template, logo/watermark]
VOICE CONSISTENCY: [confirmed from Module 9]
NARRATION PERSONALITY: [consistent point of view/tone in the writing itself]
CHANNEL NAME/DESCRIPTION: [reinforcing the core identity]
```

## Handoff

This identity system feeds Module 13's assembly as a standing brand reference, and every future video produced for this channel should be checked against it for consistency, the same way `write-like-a-human`'s drift detector works for written voice.
