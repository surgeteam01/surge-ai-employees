# Module 3: Customer Research Engine

**Purpose:** Build a Voice-of-Customer profile — reused directly from `sales-page-that-converts`, identical to `grow-on-youtube`'s adaptation toward search intent.

## Process

1. **Pull from real material first**: comments on similar faceless channels in the niche, YouTube search suggestions, community/forum discussion. Ask before generating from scratch.
2. **If none exists**, build a hypothesis-based profile, labeled as such.
3. **Identify search intent specifically** — faceless channels in categories like explainer/educational/documentary/compilation content are often built almost entirely around search-driven discovery rather than subscriber loyalty to a person, making this the single most important research output for this particular skill.
4. **Extract exact phrases and recurring questions.**

## Output format

```
TOP PAINS (ranked): [...]
TOP DESIRES (ranked): [...]
RECURRING QUESTIONS/SEARCHES: [...]
EXACT-PHRASE BANK: [...]
CONFIDENCE: [Real data / Hypothesis]
```

## Handoff

Feeds Module 5 (ideas), Module 6 (titles), and Module 11 (SEO) — search intent weighs even more heavily here than in a personality-driven channel.
