# Module 3: Customer Research Engine

**Purpose:** Build a Voice-of-Customer profile — reused directly from `sales-page-that-converts`, since ads live or die on speaking the audience's actual language within the first half-second of attention.

## Process

1. **Pull from real material first**: comments on past ads, reviews, competitor ad comment sections. Ask before generating from scratch.
2. **If none exists**, build a hypothesis-based profile, labeled as such.
3. **Identify the buyer awareness stage** — this determines whether an ad needs to educate (unaware/problem-aware) or can pitch directly (product-aware/most-aware), which shapes Module 5's angle selection heavily.
4. **Extract exact phrases** — these feed Module 6's headlines and Module 7's opening lines directly, since mirroring the audience's own words is one of the strongest scroll-stopping techniques available.

## Output format

```
AWARENESS STAGE: [one of the five, with justification]
TOP PAINS (ranked): [...]
TOP DESIRES (ranked): [...]
LIKELY OBJECTIONS: [...]
EXACT-PHRASE BANK: [...]
CONFIDENCE: [Real data / Hypothesis]
```

## Handoff

Feeds Module 5 (angle selection), Module 6 (headlines), and Module 7 (opening lines) directly.
