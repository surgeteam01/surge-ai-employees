# Module 13: Full Ad Campaign Assembler

**Purpose:** Assemble every prior module's output into one cohesive, ready-to-launch ad campaign — every angle, in every platform format, with visual direction and CTAs attached, plus the comment-reply reference.

## Process

1. **Organize by angle first, then by platform** — since Module 5's angles are the primary creative hypothesis being tested, each angle should read as one complete concept across whichever platforms it's running on, not scattered across a platform-first structure.
2. **Pair each angle's copy (Modules 6-8, 12) with its visual direction (Module 9)** and any proof/objection content used (Modules 10-11).
3. **Include the comment-reply reference (Module 11)** as a standing operational document, separate from the ad copy itself.
4. **Check voice consistency** against Module 1 (or the linked `write-like-a-human` profile).
5. **Verify nothing was lost** — every angle should have copy for every platform in scope, visual direction, and a CTA.

## Output format

```
=== AD CAMPAIGN ===

ANGLE 1: [name/type]
Visual direction: [from Module 9]
Meta ad: [from Module 8]
Google ad (if in scope): [from Module 8]
TikTok ad (if in scope): [from Module 8]
LinkedIn ad (if in scope): [from Module 8]
CTA: [from Module 12]

(repeat per angle)

=== COMMENT-REPLY REFERENCE ===
[from Module 11]
```

## Handoff

This draft goes straight to Module 14 for scoring and A/B variant generation before being presented as final.
