# Module 11: Objection Handler

**Purpose:** Surface real objections and prepare rebuttals — reused directly from `sales-page-that-converts`, adapted here for two distinct uses: objections woven briefly into ad copy itself, and a rebuttal reference for handling comment-section pushback on the live ad.

## Process

1. **Start from Module 3's objection list.**
2. **Write a direct rebuttal for each.**
3. **Decide placement**: the single strongest objection can be pre-empted briefly within an ad's body copy (especially for colder-audience angles); the rest become a ready reference for responding to comments on the live ad, which is a real and public part of running paid ads that most other content formats don't have to account for.
4. **Write comment-reply versions** — short, direct, non-defensive responses usable if the exact objection appears in the comments of a live ad.

## Output format

```
OBJECTIONS HANDLED:
1. [Objection] → [Rebuttal] → placement: [in-ad copy / comment-reply reference]
2. ...

COMMENT-REPLY VERSIONS: [short, ready-to-post responses for live ad comment sections]
```

## Handoff

The in-ad rebuttal feeds Module 8's copy; the comment-reply versions are a standing reference included in Module 13's assembly, separate from the ad copy itself.
