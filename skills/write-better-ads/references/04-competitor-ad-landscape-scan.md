# Module 4: Competitor Ad Landscape Scan

**Purpose:** Understand what competitors are already running and where the creative gap is — adapted from `nail-your-pricing`'s Competitor & Market Pricing Scan and `find-your-niche`'s Market Landscape Scan logic, applied to ad creative instead of pricing or brand positioning.

## Process

1. **Identify what competitors' ads look like** (ask the user if they have access to a competitor's ad library/page, or reason from general category knowledge if not): common angles used, common visual styles, common offers/hooks.
2. **Categorize the competitive creative landscape** — is everyone running the same handful of angles (a common failure mode — e.g. every competitor leading with a discount), or is there real variety?
3. **Identify the creative gap** — an angle, a proof type, or a visual style nobody in the category is using well, that Module 5 should consider as a candidate direction.
4. **Flag saturated angles** — if every competitor already runs a specific angle heavily, note that as a harder path to stand out with the same angle, not a reason to avoid it outright if it's genuinely the strongest fit.

## Output format

```
COMPETITOR AD LANDSCAPE: [common angles, visual styles, offers observed]
CREATIVE GAP IDENTIFIED: [angle/proof-type/visual style underused in the category]
SATURATED ANGLES FLAGGED: [what's overused, and the implication for standing out]
```

## Handoff

Feeds Module 5's angle generation directly — angles should be checked against this landscape, not invented blind to it.
