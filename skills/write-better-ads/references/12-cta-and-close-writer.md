# Module 12: CTA & Close Writer

**Purpose:** Write the CTA button copy and closing lines for each ad — reused directly from `sales-page-that-converts`'s CTA & Close Writer, matched to each platform's actual CTA button options.

## Process

1. **Match CTA to Module 1's campaign goal**: awareness campaigns often use a softer CTA ("Learn More"), lead campaigns use a specific ask ("Sign Up," "Get the Guide"), sales campaigns use a direct purchase CTA ("Shop Now," "Buy Now").
2. **Write the closing line of the ad copy** to reinforce the specific angle's hook one more time before the CTA, not a generic sign-off.
3. **Match to each platform's actual available CTA button options** (Module 8) rather than writing a custom CTA phrase that doesn't correspond to a real button choice on that platform.
4. **Vary CTA framing slightly across angles** so A/B tests (Module 14) aren't confounded by using the identical CTA everywhere, which would make it harder to isolate what's actually driving performance differences.

## Output format

```
ANGLE: [from Module 5]
CTA BUTTON (platform-native option): [x]
CLOSING LINE: [reinforces the angle's hook]

(repeat per angle)
```

## Handoff

Feeds Module 13's assembly at the end of each angle's ad copy.
