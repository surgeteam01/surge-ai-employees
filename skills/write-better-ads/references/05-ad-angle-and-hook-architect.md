# Module 5: Ad Angle & Hook Architect

**Purpose:** Generate multiple genuinely distinct creative angles — the single most important module in this pipeline, since ad performance is driven more by which underlying angle resonates than by how well any one angle is executed. This is the module with no direct equivalent anywhere else in this repo: other skills produce one well-optimized asset, ads need several genuinely different hypotheses tested against each other.

## Process

1. **Generate 4-6 distinct angles** on Module 2's transformation, each a genuinely different framing, not a reworded version of the same idea:
   - **Problem-agitate**: opens on the pain, makes it vivid, then introduces the solution.
   - **Curiosity/pattern-interrupt**: an unexpected statement or visual that breaks the scroll before the pitch is even clear.
   - **Social proof-led**: opens with a result, a number, or "people like you are already doing X."
   - **Direct offer**: states the offer and price plainly — works best for most-aware audiences (per Module 3).
   - **Contrarian/myth-busting**: challenges a common belief the audience holds, using the resulting tension to open the door to the real answer.
   - **Founder/origin story**: personal, narrative-driven, building trust through authenticity rather than a direct pitch.
2. **Match angle selection to Module 3's awareness stage** — unaware/problem-aware audiences need more educational/agitate angles; most-aware audiences can go direct-offer.
3. **Check each angle against Module 4's competitor scan** — favor angles in the identified gap over angles already saturated in the category, all else equal.
4. **Write each angle as a one-paragraph creative brief**, not full copy yet — the core idea, the emotional hook, and why it should work for this audience, so Modules 6-12 have a clear brief per angle to write against.

## Output format

```
AD ANGLES (4-6, genuinely distinct):

ANGLE 1 — [type, e.g. Problem-Agitate]
Creative brief: [core idea + emotional hook + why it fits this audience]
Competitive fit: [gap-filling / saturated but strong / novel]

ANGLE 2 — [type]
Creative brief: [...]

(repeat per angle)
```

## Handoff

Each angle becomes its own thread through the rest of the pipeline — Modules 6-12 should produce copy and creative for every angle, not just the one that seems strongest on paper, since Module 14's whole premise is testing them against each other.
