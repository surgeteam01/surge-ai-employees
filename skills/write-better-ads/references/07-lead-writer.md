# Module 7: Lead Writer

**Purpose:** Write the opening line/first sentence of each ad's body copy — reused directly from `sales-page-that-converts`'s Lead Writer, sized for an ad's much shorter attention window than a sales page's lead.

## Process

1. **Pick a lead style matched to each angle** (Module 5): PAS for problem-agitate angles, story/scene opener for founder/origin-story angles, bold-claim-plus-proof-tease for social-proof-led angles, direct address for direct-offer angles.
2. **Use the exact-phrase bank from Module 3** — an ad's opening line is often the single highest-leverage sentence for stopping the scroll, even more than the headline in some formats.
3. **Keep it extremely short** — 1-2 sentences maximum for most ad formats; an ad lead that takes several sentences to get going has already lost most of the audience.

## Output format

```
ANGLE: [from Module 5]
LEAD (style: [PAS/story/bold-claim/direct-address]): [1-2 sentences]

(repeat per angle)
```
