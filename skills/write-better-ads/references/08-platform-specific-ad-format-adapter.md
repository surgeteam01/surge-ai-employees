# Module 8: Platform-Specific Ad Format Adapter

**Purpose:** Adapt each angle's copy into the native format and constraints of each platform in scope — a genuinely new mechanic in this repo, since ad platforms have real character limits, tone conventions, and structural requirements that a generic piece of copy ignores at its own cost.

## Process

1. **Adapt to Meta (Facebook/Instagram)**: primary text (the main copy, front-loaded since it truncates behind "see more"), a short, punchy headline field, and description field if used; native tone tends toward conversational and less formal than Google Search ads.
2. **Adapt to Google Search ads**: multiple short headline variations (within Google's character limits) and description lines, written to match actual search intent/keywords rather than a broad brand pitch, since Search ads compete directly against organic search-intent-matched results.
3. **Adapt to TikTok**: copy that supports a native, unpolished, in-feed-content feel rather than reading as a traditional ad — shorter, punchier, and often paired with a hook meant to be spoken/shown on screen in the first 1-3 seconds of the video.
4. **Adapt to LinkedIn**: a more professional register, often longer-form than Meta/TikTok, since LinkedIn's audience tolerates (and often expects) more substantive copy for B2B offers.
5. **For each platform, confirm exact character/format limits** (ask the user to verify current platform specs if precision matters, since these change) and adapt Module 6/7's headline and lead to fit within them without losing the angle's core hook.

## Output format

```
ANGLE: [from Module 5]

META AD: Primary text: [...] Headline: [...] Description: [...]
GOOGLE SEARCH AD (if in scope): Headlines: [multiple, within limits] Descriptions: [...]
TIKTOK AD (if in scope): [native-feeling short copy + on-screen hook note]
LINKEDIN AD (if in scope): [longer-form, professional register]

(repeat per angle, per platform in Module 1's scope)
```
