# Module 6: Headline Lab

**Purpose:** Write and score the headline/primary text for each ad angle — reused directly from `sales-page-that-converts`'s Headline Lab, since the underlying formulas apply identically to an ad headline as to a sales page headline.

## Process

1. **For each angle from Module 5**, generate 3-5 headline options using the formulas: 4 U's (Urgent, Unique, Ultra-specific, Useful), benefit + timeframe + objection-handle, direct promise, curiosity/question, and customer-language mirror (from Module 3's phrase bank).
2. **Score each option** on Clarity, Specificity, Believability, and Relevance — an ad headline has less room than a sales page headline to earn its keep, so weight Clarity and scroll-stopping power even more heavily.
3. **Keep each angle's headline options consistent with that angle's creative brief** from Module 5 — a curiosity angle's headline should create a genuine curiosity gap; a direct-offer angle's headline should state the offer plainly.
4. **Pick the top headline per angle.**

## Output format

```
ANGLE: [from Module 5]
HEADLINE OPTIONS (scored 1-5 on Clarity/Specificity/Believability/Relevance):
1. [headline] — C:_ S:_ B:_ R:_
2. ...
TOP PICK: [headline]

(repeat per angle)
```

## Handoff

Feeds Module 7 (opening line should echo the headline's language) and Module 8 (platform adaptation).
