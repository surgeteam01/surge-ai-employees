# Module 14: Ad Optimizer

**Purpose:** Score the finished campaign on hook strength, platform fit, and creative variety, and produce ready-to-run A/B variants — testing is the actual point of ad creative more than any other content type in this repo, so this module's variant output matters as much as its scoring.

## Process

1. **Score the assembled campaign** on a simple rubric, 1-5 each:
   - **Hook strength** — does each angle's headline/opening genuinely stop the scroll, or read as generic?
   - **Angle diversity** — are the angles genuinely different hypotheses, or variations on the same idea dressed up differently?
   - **Platform-native fit** — does each platform's version actually follow that platform's real conventions, or read as a copy-paste across platforms?
   - **Proof credibility** — is proof specific and (where used) genuinely UGC-feeling, or generic?
   - **Objection coverage** — is the single strongest objection pre-empted where relevant?
   - **Visual-copy alignment** — does the creative direction (Module 9) genuinely match and reinforce each angle's copy?
2. **Flag the lowest-scoring 1-2 dimensions** and revise those specific angles/modules.
3. **Produce ready-to-run A/B variants** — for the strongest 2-3 angles, generate an alternate headline or an alternate visual direction, explicitly labeled as a testable pair with a stated hypothesis, since the whole value of running multiple angles is measuring which actually wins, not just producing more options.
4. **Recommend a realistic test structure** given Module 1's budget — how many angles to test simultaneously, and what a meaningful sample size/timeframe looks like before drawing conclusions.

## Output format

```
SCORES (1-5): Hook Strength:_ Angle Diversity:_ Platform-Native Fit:_ Proof Credibility:_ Objection Coverage:_ Visual-Copy Alignment:_

TOP FIXES MADE: [list, tied to lowest scores]

A/B VARIANTS (for top 2-3 angles):
Angle: [x] — Variant A: [original] vs. Variant B: [alternate headline/visual] — Hypothesis: [one line]
(repeat)

TEST STRUCTURE RECOMMENDATION: [how many angles to run at once given budget, sample size/timeframe before concluding]
```

## Handoff

This is the last stage — present the final scored campaign, all angles, and the A/B test plan to the user as the finished deliverable, ready to launch. Flag any score of 3 or below plainly rather than presenting the campaign as "done."
