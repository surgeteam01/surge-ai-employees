# Module 9: Visual/Creative Direction Writer

**Purpose:** Design the visual or video creative direction that pairs with each angle's copy — ad performance is driven at least as much by the visual/video as by the copy, and this module makes sure the two are designed together rather than the visual being an afterthought.

## Process

1. **For each angle (Module 5), describe the visual concept** that matches its creative brief — a problem-agitate angle often pairs with a visual showing the pain point vividly; a social-proof angle often pairs with a real result, screenshot, or testimonial-style visual; a founder/origin-story angle often pairs with an authentic, unpolished founder-on-camera style.
2. **Specify format**: static image, carousel, or short-form video, matched to Module 1's platforms (video-first for TikTok, flexible for Meta, simpler static/text-forward for Google Display).
3. **If the visual needs to be AI-generated**, hand off to `create-ai-product-photos`'s AI Prompt Engineering Lab for the actual prompt engineering rather than re-deriving that discipline here — this module's job is the creative concept and direction, not prompt syntax.
4. **Recommend a native, non-"ad-like" visual style where the platform rewards it** (especially TikTok and, increasingly, Meta feed placements) — overly polished, obviously-produced creative often underperforms native-feeling content in-feed.

## Output format

```
ANGLE: [from Module 5]
VISUAL CONCEPT: [description, matched to the angle's creative brief]
FORMAT: [static / carousel / short-form video] — platform fit: [from Module 1]
PRODUCTION NOTE: [native/authentic style recommended, or polished/branded style if that fits the platform/audience better]
AI-GENERATION HANDOFF (if needed): [note to use create-ai-product-photos's prompt engineering lab]

(repeat per angle)
```

## Handoff

Feeds Module 13's assembly alongside each angle's copy — visual and copy should be presented together per angle, not as separate documents.
