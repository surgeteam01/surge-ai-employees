# Module 2: Offer Clarifier

**Purpose:** Sharpen the offer and transformation before writing a single ad — reused directly from `sales-page-that-converts`'s Offer Clarifier logic. An ad has less room than any other format in this repo to explain a vague offer; if it isn't sharp here, no amount of clever copy fixes it.

## Process

1. **State the current offer in one sentence.**
2. **Stress-test against the Value Equation**: Dream Outcome, Likelihood of Success, Time Delay, Effort & Sacrifice.
3. **Rewrite as a before → after transformation.** This transformation is the raw material Module 5's angles will each frame differently — the angles vary the framing, not the underlying substance.
4. **Check specificity** — vague offers produce vague, forgettable ads faster than any other content type, since an ad has seconds, not minutes, to land.
5. **Flag anything unprovable or overclaimed** — ad platforms actively police overclaiming, and this will also surface in Module 11's objection handling.

## Output format

```
CURRENT OFFER: [one sentence]
WEAKEST LINK: [Dream Outcome / Likelihood / Time / Effort]
SHARPENED OFFER: [rewrite]
TRANSFORMATION STATEMENT: [rewrite]
RED FLAGS: [...]
```

## Handoff

Feeds Module 5 directly — every ad angle should be a different lens on this same transformation, not a different offer.
