# Module 7: Message Sequence Writer

**Purpose:** Write the full multi-touch sequence body copy — from the initial outreach through the value-add follow-ups — using the opening lines from Module 6 and the map from Module 5. This is the persuasive core of the outreach system.

## Process

1. **Confirm touch count and channel from Module 5's map** before writing; write each touch to the job that module assigned it rather than a generic template.
2. **Touch 1 (initial outreach)** — open with the winning line from Module 6, state the reason for reaching out and the specific relevance to this prospect/segment in 2-3 sentences total, and end with a low-friction ask (see Module 11 — not a hard pitch). Keep this touch especially short; cold opens are read on a phone between meetings.
3. **Touches 2-N (value-add follow-ups)** — each follow-up should add something new, never just "just following up" or "bumping this to the top of your inbox," which reads as pressure without value. Options per touch: share a relevant insight, a short case study or result (from Module 8 once available), a specific question that's easy to answer, or a different angle on the same core pain. Reference the earlier touch briefly so the sequence reads as one continuous thread, not disconnected messages.
5. **Keep the ratio of value to ask heavily weighted toward value** in the middle touches — the ask should feel like a natural next step by the final touches, not a repeated demand from touch one.
6. **Write in the voice from Module 1**, and keep sentences short and skimmable throughout — cold messages compete with a full inbox, not a captive reader.

## Output format

```
MESSAGE SEQUENCE ([count] touches):

TOUCH 1 — Initial Outreach (Channel: [x])
Body: [full message copy, opening line included]

TOUCH 2 — Value-Add Follow-Up (Channel: [x])
Body: [full message copy]

TOUCH 3 — Value-Add Follow-Up (Channel: [x])
Body: [full message copy]

(repeat per touch, excluding the final breakup touch — see Module 12)
```

## Handoff

This sequence feeds directly into Module 10 (Multi-Channel Adapter) for channel-specific formatting, and Module 13 (Assembler) for final placement with triggers. The proof points and objection-handling referenced lightly here should point to Module 8 and Module 9's fuller output rather than duplicating it in full within every touch — cold messages stay short.
