# Module 11: CTA & Meeting-Booking Writer

**Purpose:** Write the specific ask in every touch — in cold outreach the call to action has to be lower-friction than a sales page's or email funnel's, since the reader hasn't opted into anything yet and trust is still being built one message at a time.

## Process

1. **Match ask size to trust built so far.** Touch 1 should ask for the smallest reasonable thing — a reply, a yes/no answer to a specific question, or "worth a quick chat?" — never a 30-minute meeting request cold. Later touches can graduate to a more direct meeting ask once some value/proof has landed.
2. **Write CTA copy that's specific and easy to say yes to**, not vague ("let me know if you're interested" invites nothing) — e.g. "worth a 15-minute call next week to see if it's a fit?" beats "happy to chat if you want."
3. **Offer an easy path to yes**: a scheduling link, 2-3 concrete time options, or simply "reply with a good day/time" — remove friction wherever possible rather than making the prospect do the scheduling work.
4. **Vary CTA phrasing across touches** so the sequence doesn't read as the same request copy-pasted repeatedly — each touch's ask should feel like a natural next step given what's been said so far.
5. **Never manufacture urgency in outreach CTAs** the way a cart-close sequence might — cold outreach urgency reads as pressure from a stranger and damages trust before it's been earned; keep the ask warm and low-pressure throughout.

## Output format

```
CTA BY TOUCH:
Touch 1 (lowest friction): [copy]
Touch 2: [copy]
Touch 3: [copy]
(repeat per touch)

MEETING-BOOKING MECHANISM: [scheduling link / concrete time options / "reply with a time"]
```

## Handoff

Feeds directly into Module 13 for placement inside each touch, and Module 14 will test whether the asks are appropriately low-friction and well-sequenced or need an A/B variant.
