# Module 9: Objection Handler

**Purpose:** Prepare direct, ready-to-send replies for the objections a prospect will actually raise once they respond — cold outreach objections arrive live, in a reply, so this module produces a reply playbook rather than in-body copy or an FAQ page.

## Process

1. **Start from Module 3's objection list**, then add categories common to cold outreach specifically: price ("what does this cost?"), timing ("not right now / check back later"), trust ("how did you get my info? / is this a mass email?"), fit ("we already have someone for this / not a priority"), and skepticism ("this looks like spam / not interested").
2. **Write a direct, short reply for each** — acknowledge the objection honestly (including, where true, that this is outreach — pretending otherwise if directly asked erodes trust fast) before answering it. Keep replies conversational, not scripted-sounding; a reply that reads like a canned rebuttal undermines the trust the sequence has been building.
3. **Decide which objections warrant a follow-up question vs. a direct answer** — sometimes the better move is a short clarifying question ("totally understand — is timing the main blocker, or is it more about fit?") rather than immediately arguing the point.
4. **Write the "not interested" / soft-no reply** carefully — always offer a graceful exit (respecting an opt-out) and, only if genuinely appropriate, a low-pressure door left open ("no worries — if that changes, feel free to reach out") rather than pushing further.

## Output format

```
OBJECTION REPLY PLAYBOOK:
1. [Objection, as the prospect would actually phrase it] → [Reply]
2. ...

SOFT-NO / NOT INTERESTED REPLY:
[Reply — graceful exit, door left open only if appropriate]

CLARIFYING QUESTION VARIANTS (for ambiguous pushback):
- ...
```

## Handoff

This playbook is used live once a prospect replies — it isn't assembled into the outbound sequence itself (Module 13), but should be handed to the user (or a sales rep) as a companion reference alongside the assembled sequence, ready to use the moment a reply comes in.
