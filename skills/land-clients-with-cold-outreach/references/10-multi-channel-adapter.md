# Module 10: Multi-Channel Adapter

**Purpose:** Take the core message sequence (Module 7) and adapt each touch into the actual format required by whichever channels Module 5 put in scope — email, LinkedIn connection request/DM, cold call script, and voicemail script each have different length limits, norms, and delivery mechanics.

## Process

1. **Email** — full length as written in Module 7 is usually fine; add a subject line (short, lowercase-casual or plainly descriptive tends to outperform salesy subject lines in cold contexts) and ensure a working opt-out/unsubscribe mechanism is present per Module 1's compliance constraints.
2. **LinkedIn connection request note** — extremely short (typically under 300 characters); compress Touch 1's opening line and relevance statement only, cut the ask entirely or reduce it to a soft one-liner, since the goal here is just to get accepted.
3. **LinkedIn DM (post-connection)** — slightly more room than a connection note but still shorter than email; keep the conversational, one-to-one tone even more strictly than email, since LinkedIn readers expect a human voice, not a broadcast.
4. **Cold call script** — convert the written touch into a spoken opener: a short self-introduction, the same relevance/trigger hook from Module 6 spoken naturally (not read verbatim), a pattern-interrupt permission-based question ("did I catch you at a bad time?" or similar, only if it fits the brand voice), and a single clear ask for a short amount of time. Write it as talking points, not a word-for-word script to be read robotically.
5. **Voicemail script** — very short (under 20-25 seconds spoken): name, one-line reason for calling tied to the prospect's specific relevance, and a clear callback ask or note that a follow-up email is coming.
6. **Keep the core message and proof point identical across channels** — only the length, formality, and delivery mechanics should change; a prospect who sees the outreach on both LinkedIn and email should recognize it as the same coherent outreach, not two different pitches.

## Output format

```
CHANNEL ADAPTATIONS (per touch, for each channel in scope):

EMAIL — Touch [n]
Subject: [subject line]
Body: [as adapted, if different from Module 7's base version]

LINKEDIN CONNECTION NOTE (if in scope)
[under character limit, compressed]

LINKEDIN DM — Touch [n] (if in scope)
[body]

COLD CALL SCRIPT — Touch [n] (if in scope)
Talking points: [opener, hook, ask]

VOICEMAIL SCRIPT (if in scope)
[under 25 seconds spoken]
```

## Handoff

These channel-specific versions feed into Module 13's assembly at the touch/channel position defined by Module 5's map. If a channel was scoped out in Module 5, skip it here rather than producing unused variants.
