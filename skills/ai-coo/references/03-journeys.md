# Module 3: Journeys

**Purpose:** Pre-mapped sequences for the goals that cross skills — and usually cross employees. Each step is tagged with the employee that holds it, so a founder sees exactly where a journey leaves the pack they have, and you never route them into a skill that is not there without saying so.

Tags: **[S]** The Business Strategist · **[C]** The Content Marketer · **[G]** The Growth & Sales Rep · **[B]** The Brand & Product Builder.

Every journey assumes `find-your-niche` runs first **only** if `BUSINESS-BRAIN.md` does not already answer who the business serves. Check the brain before recommending it.

## "I want to start selling something new"

1. **[S]** `find-your-niche` — if audience and positioning are not already in the brain
2. **[S]** `nail-your-pricing` — if the price is not set with confidence
3. The build skill for the offer: **[G]** `sales-page-that-converts` (a straightforward offer) · **[B]** `course-creator` (teaching) · **[B]** `write-your-book` (a book) · **[B]** `launch-a-digital-product` (a built product) · **[S]** `productize-your-service` (packaging bespoke work)
4. **[G]** `build-your-email-funnel` — to nurture the ones who do not buy at once

A Strategist-only founder reaches step 3 and stops: say that the build lives with the Growth & Sales Rep or the Brand & Product Builder, and what they will have ready by then.

## "I want more customers" (the offer exists)

1. **[S]** `find-your-niche` — only if audience clarity is genuinely missing
2. By how they want to acquire:
   - Outbound: **[G]** `land-clients-with-cold-outreach`
   - Paid: **[G]** `write-better-ads` → needs **[G]** `sales-page-that-converts` as the landing page if none exists
   - Organic content: the audience journey below
   - Automated capture and follow-up: **[G]** `get-more-leads-with-ai`
3. **[G]** `build-your-email-funnel` — almost always, whichever route

## "I want to grow an audience"

1. **[S]** `find-your-niche` — if not in the brain
2. **[C]** `write-like-a-human` — early, because it feeds every piece that follows
3. **[C]** `30-days-of-content` — the cross-platform system
4. The channel they are serious about: **[C]** `grow-on-youtube` · `start-a-faceless-channel` · `build-your-personal-brand-on-linkedin` · `launch-a-podcast`
5. **[C]** `rank-on-google` — if any of it is written and search matters

## "I want to run a webinar"

1. **[S]** `find-your-niche` — if not in the brain
2. **[S]** `nail-your-pricing` — if the pitched offer's price is not set
3. **[G]** `run-webinars-that-sell` — handles registration, reminders, the pitch and follow-up itself

## "I have a business and no visual identity"

1. **[S]** `find-your-niche` — identity work is stronger with positioning behind it
2. **[B]** `build-your-own-brand-identity`
3. **[C]** `write-like-a-human` — its voice stage checks visual and verbal alignment together
4. **[B]** `create-ai-product-photos` — only for a physical product

## "I want to stop sounding like AI"

1. **[C]** `write-like-a-human` — usually the whole answer; add **[S]** `find-your-niche` first only if there is no defined audience to calibrate against

## "I want to write a book"

1. **[S]** `find-your-niche` — a book without a clear reader tries to be everything
2. **[C]** `write-like-a-human` — if it should sound like them
3. **[B]** `write-your-book` — hands off internally to `launch-a-digital-product` (paid) or `build-your-email-funnel` (a lead magnet)

## "I don't know what's wrong"

1. **[S]** `audit-my-business` — the entry point for a whole-business goal; its last stage maps every finding to the skill that fixes it
2. Whatever the audit's matrix says to fix first — do not guess the chain up front

## Requests that need no journey

A single sales page, a single price, one email sequence, one data question, one coding project, one prompting question: one skill, from Module 1. Over-chaining a simple request adds steps nobody asked for.

## When nothing fits

Say so. Name the closest skill and call it an approximate fit, rather than forcing a journey that does not apply.

## Handoff

Module 4 — and for a journey, hand off one step at a time, pausing between steps to check the route still holds.
