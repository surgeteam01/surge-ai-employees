# Module 8: Post Format & Structure Designer

**Purpose:** Structure each post in LinkedIn's native format — this platform has distinct formatting conventions (short lines, generous white space, no external links inline) that meaningfully affect reach and readability independent of the writing quality itself.

## Process

1. **Format with short lines and generous line breaks** — LinkedIn's feed rewards scannable, airy formatting; dense unbroken paragraphs get skipped even with strong content.
2. **Choose a structure matched to the post type**: a story arc (setup → tension/mistake → lesson/resolution) for personal/narrative posts, a numbered breakdown for advice/framework posts, a before-after-bridge structure for transformation-focused posts.
3. **Keep total length appropriate to the idea** — LinkedIn tolerates longer posts than most platforms if the content earns it, but padding a thin idea to look substantial reads as filler; match length to genuine content, not a target word count.
4. **Never place an external link directly in the post body** — LinkedIn's algorithm measurably suppresses reach on posts with outbound links; recommend placing any link in the first comment instead (feeds Module 10) and note this in the post itself ("link in the comments").
5. **Recommend format type** (plain text, a document/carousel, native video, an image) based on the idea from Module 6 — some ideas are inherently more visual (a framework, a before-after) and benefit from a carousel; others work better as plain text.

## Output format

```
POST [n]:
Format type: [plain text / carousel-document / native video / image]
Structure: [story arc / numbered breakdown / before-after-bridge]
Full formatted post (with line breaks): [...]
External link handling: [none needed / "link in comments" noted in post]
```
