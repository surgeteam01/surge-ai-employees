# Module 5: Content Pillar & Calendar Planner

**Purpose:** Define recurring content pillars and a posting calendar — adapted directly from `30-days-of-content`'s equivalent modules.

## Process

1. **Define 3-5 content pillars** connecting to Module 2's transformation and Module 3's pains/desires and "what this audience scrolls for."
2. **Set a realistic posting cadence** from Module 1's capacity — LinkedIn rewards consistency; 3-4x/week sustained usually outperforms daily posting that burns out after two weeks.
3. **Distribute pillars across the calendar** for variety.
4. **Weight the mix toward the stated goal** (Module 1) — thought-leadership goals skew toward insight/opinion pillars; lead-gen goals include more proof/case-study and soft-offer pillars.

## Output format

```
CONTENT PILLARS:
1. [name] — job: [...] — connects to: [...]
(3-5 total)

POSTING CADENCE: [frequency]
CALENDAR: [pillar assignment per post, across the planning horizon]
```
