# Module 4: Profile & Headline Optimizer

**Purpose:** Optimize the actual LinkedIn profile — headline, About section, and Featured section — since this is where every post's traffic eventually lands, and a strong post followed by a weak profile wastes most of the attention it earned.

## Process

1. **Write the headline** (the line shown under the name everywhere on LinkedIn, not just the profile page) using Module 2's sharpened value proposition — specific and outcome-focused, not just a job title. If a `find-your-niche` positioning statement exists, adapt its one-sentence variant directly rather than writing a new one from scratch.
2. **Write the About section** in three parts: an opening hook (1-2 sentences that mirror Module 3's top pain/desire, written in first person, not a resume summary), a middle section establishing credibility and the transformation delivered (concrete results, not just a list of skills), and a closing CTA (what should someone do after reading this — connect, book a call, follow for content).
3. **Recommend Featured section content** — pin the 2-3 strongest proof pieces or most representative posts, so a profile visitor immediately sees evidence, not just a description.
4. **Check the headline and About section against Module 3's exact-phrase bank** — profile copy in the audience's own language outperforms generic professional-speak.

## Output format

```
HEADLINE: [specific, outcome-focused, under LinkedIn's character limit]

ABOUT SECTION:
Opening hook: [1-2 sentences, first person]
Credibility/transformation: [concrete results]
Closing CTA: [specific next step]

FEATURED SECTION RECOMMENDATIONS: [2-3 pieces to pin, and why]
```

## Handoff

This profile copy is a standing asset, not a one-time post — Module 13 includes it in the final assembly as the "home base" every post ultimately drives traffic toward.
