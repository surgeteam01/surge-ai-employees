# Module 13: Full LinkedIn Brand Plan Assembler

**Purpose:** Assemble every prior module's output into one cohesive plan — profile, calendar, posts, and standing operational practices — so the pipeline's output is something the user can actually publish and operate from.

## Process

1. **Lead with the optimized profile (Module 4)** — this is the standing asset every post ultimately drives traffic toward.
2. **Follow Module 5's calendar**, dropping each post's full content (hook from Module 7, format from Module 8, proof from Module 9 where applicable, CTA from Module 12) into place.
3. **Include the standing operational practices** — engagement/algorithm mechanics (Module 10) and networking/engagement-out strategy (Module 11) — as clearly separated sections.
4. **Check voice consistency** against Module 1 (or the linked `write-like-a-human` profile).
5. **Verify nothing was lost.**

## Output format

```
=== OPTIMIZED PROFILE ===
[from Module 4]

=== CONTENT CALENDAR & POSTS ===
POST [n] — Pillar: [x] — Date: [x]
[full post: hook + body + CTA]
(repeat)

=== STANDING PRACTICES ===
Engagement/algorithm mechanics: [from Module 10]
Networking/engagement-out strategy: [from Module 11]
```

## Handoff

Goes straight to Module 14 for scoring before being presented as final.
