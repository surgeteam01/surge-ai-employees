# Module 2: Offer Clarifier

**Purpose:** Sharpen the value proposition and transformation before writing profile copy or content — reused directly from `sales-page-that-converts`'s Offer Clarifier logic.

## Process

1. **State the current value proposition in one sentence.**
2. **Stress-test against the Value Equation**: Dream Outcome, Likelihood of Success, Time Delay, Effort & Sacrifice.
3. **Rewrite as a before → after transformation** for the person's audience (a client, an employer, a peer network — whichever fits the stated goal).
4. **Check specificity** — a vague value proposition produces a generic headline and generic content.
5. **Flag anything unprovable or overclaimed.**

## Output format

```
CURRENT VALUE PROP (as given): [one sentence]
WEAKEST LINK: [Dream Outcome / Likelihood / Time / Effort]
SHARPENED VALUE PROP (one sentence): [rewrite]
TRANSFORMATION STATEMENT: [rewrite]
RED FLAGS: [anything overclaimed, vague, unprovable]
```

## Handoff

Feeds Module 4 (headline/About section) and Module 5 (content pillars).
