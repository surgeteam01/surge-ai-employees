# Module 6: Post Idea Generator

**Purpose:** Generate specific, non-repetitive post ideas mapped to Module 5's calendar — adapted directly from `30-days-of-content`'s Content Idea Generator.

## Process

1. **For each slot, generate one specific, concrete post idea** within the assigned pillar, drawing on Module 3's recurring pains/desires and real professional experiences (a lesson learned, a mistake made, a client result, a contrarian take on industry convention).
2. **Favor personal, specific stories over generic advice** — LinkedIn rewards posts that feel like they came from one real person's actual experience over generic listicle-style advice, which is abundant and easily skimmed past.
3. **Check for repetition** across the calendar.

## Output format

```
POST IDEAS:
POST [n] — Pillar: [x]
Idea: [specific, concrete summary — favor real experience/story over generic advice]

(repeat per slot)

REPETITION CHECK: [...]
```
