# Module 3: Customer Research Engine

**Purpose:** Build a Voice-of-Customer profile — reused directly from `sales-page-that-converts`, driving both profile copy and content topics.

## Process

1. **Pull from real material first**: comments on past posts, DMs received, conversations at events, or reviews. Ask before generating from scratch.
2. **If none exists**, build a hypothesis-based profile, labeled as such.
3. **Identify what this audience is actually scrolling LinkedIn looking for** — career advice, industry insight, hiring signals, potential vendors — since this shapes Module 5's pillar mix distinctly from a generic social platform.
4. **Extract exact phrases** the audience uses — feeds Module 4's headline and Module 7's hooks.

## Output format

```
TOP PAINS (ranked): [...]
TOP DESIRES (ranked): [...]
WHAT THIS AUDIENCE SCROLLS LINKEDIN FOR: [career advice / insight / hiring signals / vendor research / other]
EXACT-PHRASE BANK: [...]
CONFIDENCE: [Real data / Hypothesis]
```

## Handoff

Feeds Module 4, Module 5, and Module 7 directly.
