# Module 12: CTA & Close Writer

**Purpose:** Write engagement and conversion CTAs per post — reused directly from `sales-page-that-converts`, sized for LinkedIn's tolerance for a soft ask.

## Process

1. **Match CTA weight to post type and pillar** (Module 5) — most posts should carry a soft engagement CTA (a specific comment prompt, an invitation to share a related experience); only the smaller promotional share should carry a direct conversion ask (a link to book a call, a lead magnet).
2. **Write specific, not generic, CTAs** — "comment your biggest challenge with X" beats "thoughts?"
3. **Vary CTA type across the calendar.**

## Output format

```
POST [n] — Type: [x]
CTA: [specific engagement or conversion prompt]
```

## Handoff

Feeds Module 13's assembly, appended to each post's end.
