# Build Your Personal Brand on LinkedIn

A 14-stage pipeline that takes a raw professional identity through to a finished, engagement-scored LinkedIn brand system — an optimized profile, content pillars, a posting calendar, format-correct posts built around LinkedIn's specific truncation and algorithm mechanics, and a networking strategy that builds relationships, not just an audience. Each stage is a focused reference module in `references/`. Run them in order — each one's output becomes the next one's input. Do not skip stages even for "quick" requests; a post written without the profile-optimization stage behind it can go viral and still convert nobody, since a visitor who clicks through to a weak profile bounces immediately. If the user only wants one piece (e.g. just a headline rewrite), still run the lightweight stages that feed it so that piece is grounded in a real positioning, not written in a vacuum.

## How to run this skill

1. **Check for an existing LinkedIn Brand Brief first**, and check whether a `find-your-niche` positioning statement or a `write-like-a-human` voice profile already exists — pull both in directly.
2. **Work through stages 1–14 in order**, reading each reference file only when you get to that stage.
3. **Treat Stage 4 (Profile) as equally important as the content stages** — many personal-brand efforts pour all their energy into posts and neglect the profile a viral post actually sends people to.
4. **Stage 13 requires every prior stage's output.** If any stage was skipped, produce a minimal version rather than leaving a gap.
5. **Always end with Stage 14.**

## Inputs this skill needs (collected in Stage 1)

Name/business, professional role and core value proposition, target audience (or a link to an existing `find-your-niche` profile), current LinkedIn presence (follower count, posting history, top-performing posts), posting capacity, brand voice (or a link to an existing `write-like-a-human` profile), the goal (thought leadership, lead generation, job/opportunity attraction), and any constraints.
