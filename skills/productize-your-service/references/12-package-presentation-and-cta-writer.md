# Module 12: Package Presentation & CTA Writer

**Purpose:** Write the actual copy that presents the packages and drives the booking/purchase — adapting `nail-your-pricing`'s Presentation Writer and `sales-page-that-converts`'s CTA & Close Writer into a single module sized for what a productized service page actually needs: a clear packages comparison, not a long-form narrative sales page.

## Process

1. **Open with the sharpened transformation** (Module 2) in a short, clear statement — a productized service page should get to "here's what you get and what it costs" much faster than a long-form sales page would, since the pitch is clarity and predictability, not an extended persuasion arc.
2. **Present the tier comparison clearly** (from Module 6 and Module 7): a scannable table or side-by-side layout showing scope, turnaround, and price per tier, with the recommended tier visually emphasized and a one-line reason it's the best fit for most clients.
3. **Weave in proof** (Module 9) near the top (quick credibility) and near the tier comparison (reduces purchase risk right at the decision point).
4. **Pre-empt the 1-2 strongest objections** (Module 10) briefly and directly, especially the fit/flexibility objection, since that's the one most specific to a productized offer.
5. **Place the guarantee** (Module 11) directly beside the tier comparison.
6. **Write the CTA per tier** — specific and low-friction ("Book the [tier name] package" beats "Get Started"), and write a short closing line reinforcing the transformation and the predictability/speed benefit of choosing the productized path over a custom quote.

## Output format

```
PACKAGE PRESENTATION:

OPENING: [short transformation statement]

TIER COMPARISON:
[Tier 1 name] — $[price] — Scope: [summary] — Turnaround: [x] — CTA: [copy]
[Tier 2 name — recommended] — $[price] — Scope: [summary] — Turnaround: [x] — CTA: [copy]
[Tier 3 name] — $[price] — Scope: [summary] — Turnaround: [x] — CTA: [copy]

PROOF: [placed near top and near comparison]
OBJECTION PRE-EMPT: [strongest 1-2, addressed briefly]
GUARANTEE: [from Module 11]
CLOSING LINE: [reinforces transformation + predictability benefit]
```

## Handoff

This is the client-facing copy Module 13 assembles into the final deliverable. Module 14 will test whether this presentation is clear and persuasive enough or needs an A/B variant.
