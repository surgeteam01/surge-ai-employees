# Module 4: Shot List & Photo Type Planner

**Purpose:** Define every specific shot needed, mapped to what each platform requires and what the research (Modules 2-3) identified as necessary to sell and answer objections — the master list everything else in this pipeline produces content against.

## Process

1. **Identify standard shot types relevant to this product** (from Module 1): hero/main shot (the primary listing image, usually on a clean/white background per most marketplace requirements), lifestyle/in-use shot (the product in a real context, demonstrating Module 2's transformation), detail/macro shot (close-up on texture, materials, or a specific feature from Module 2's emphasis list), scale-reference shot (resolves a common visual objection about size, per Module 3), flat-lay or multi-angle shots (for products where full-shape understanding matters, like apparel or multi-component products), and packaging shot (if packaging is part of the purchase experience).
2. **Map each shot type to platform requirements** (a preliminary pass — full detail comes in Module 10) — e.g. Amazon's main image typically requires a pure white background with no lifestyle context, while secondary images can include lifestyle shots.
3. **Prioritize the shot list** — which shots are essential for a minimum viable listing versus which add incremental value, given realistic production/generation time.
4. **Note which shots resolve a specific research finding** (Module 2's feature emphasis, Module 3's visual objections) so nothing in the shot list is arbitrary.

## Output format

```
SHOT LIST:
1. [Shot type] — platform requirement: [x] — resolves: [specific feature/objection from Module 2/3] — priority: [essential/nice-to-have]
2. ...
(repeat per shot)
```

## Handoff

Feeds Module 6 (feature translation per shot), Module 7 (prompts per shot), and Module 10 (final platform-spec check).
