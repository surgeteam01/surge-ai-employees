# Module 2: Offer Clarifier

**Purpose:** Sharpen the value proposition the photos need to visually sell — reused directly from `sales-page-that-converts`'s Offer Clarifier logic. Product photography's job is to make the value proposition visually obvious in the fraction of a second before a shopper reads any copy.

## Process

1. **State the product's core value proposition in one sentence.**
2. **Stress-test against the Value Equation**: Dream Outcome, Likelihood of Success, Time Delay, Effort & Sacrifice.
3. **Rewrite as a before → after transformation** — this is what Module 6 will translate into specific visual elements (a "before" state implied through context, an "after" state shown through the product in use).
4. **Check specificity** — a vague value proposition produces generic-looking product photos with nothing specific to visually emphasize.

## Output format

```
CORE VALUE PROPOSITION: [one sentence]
TRANSFORMATION STATEMENT: [before → after]
KEY FEATURES TO VISUALLY EMPHASIZE: [list — feeds Module 6 directly]
```

## Handoff

Feeds Module 4 (shot list should capture this transformation) and Module 6 (feature-to-visual translation).
