# Module 10: Platform-Specific Formatting Requirements

**Purpose:** Specify the exact technical requirements per target platform — this is non-negotiable compliance work, since an image that violates a platform's actual rules gets rejected or downranked regardless of how good it looks.

## Process

1. **For each platform in Module 1's brief, specify known requirements**: image dimensions/aspect ratio, minimum resolution, file format, background rules (e.g. many marketplaces require a pure white background for the main image with no text/watermarks/props), and any image-count minimums/maximums.
2. **Flag platform-specific content policy considerations** relevant to AI-generated images specifically — some platforms have disclosure requirements or restrictions on AI-generated visual content; recommend the user verify current policy directly, since these rules change and this module's knowledge may not reflect the platform's latest policy.
3. **Cross-check Module 4's shot list and Module 8's composition choices** against these requirements, flagging any shot that would need adjustment to comply.
4. **Recommend the user always verify current requirements directly on the platform** before finalizing, since exact specs (pixel dimensions especially) change over time and this module's guidance should be treated as a strong starting point, not a guaranteed-current spec sheet.

## Output format

```
PLATFORM REQUIREMENTS:
[Platform] — dimensions/aspect ratio: [x] — resolution: [x] — format: [x] — background rules: [x] — image count: [x]
(repeat per platform)

AI-CONTENT POLICY FLAG: [recommend verifying current policy directly]
COMPLIANCE CHECK: [any shot from Module 4/8 needing adjustment to meet these requirements]
VERIFICATION REMINDER: [confirm current specs directly on the platform before finalizing]
```
