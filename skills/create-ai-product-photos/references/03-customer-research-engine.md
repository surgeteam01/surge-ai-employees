# Module 3: Customer Research Engine

**Purpose:** Build a Voice-of-Customer profile — reused directly from `sales-page-that-converts`, adapted toward what visual style and context resonates with this specific buyer.

## Process

1. **Pull from real material first**: reviews of this or similar products (what customers say they cared about seeing before buying), competitor listing images that appear to perform well. Ask before generating from scratch.
2. **If none exists**, build a hypothesis-based profile, labeled as such.
3. **Identify what visual context this buyer needs to see** — a product shown in genuine use/lifestyle context often matters more for some categories (home goods, apparel) than others (a technical/functional product might sell better on clean detail shots showing build quality).
4. **Identify likely visual objections** — a buyer's hesitation that a specific photo could resolve (e.g. "is this actually the size I think it is?" resolved by a scale-reference shot).

## Output format

```
VISUAL CONTEXT THIS BUYER NEEDS: [lifestyle/in-use vs. clean detail/technical — reasoning]
LIKELY VISUAL OBJECTIONS: [what a specific shot type could resolve]
CONFIDENCE: [Real data / Hypothesis]
```

## Handoff

Feeds Module 4's shot list directly — every visual objection identified here should map to a specific shot type.
