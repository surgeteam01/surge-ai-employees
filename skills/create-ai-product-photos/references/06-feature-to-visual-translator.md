# Module 6: Feature-to-Visual Translator

**Purpose:** Translate the product's key selling features (from Module 2) into specific visual elements a photo can actually show — a genuinely new mechanic in this repo, since it bridges written value-proposition work and visual composition directly.

## Process

1. **For each key feature from Module 2**, identify a concrete visual way to demonstrate it rather than just showing the product neutrally: "waterproof" → water droplets beading on the surface or the product partially submerged; "compact/portable" → shown next to a familiar object for scale, or in a bag/pocket; "durable" → shown in a rugged context or mid-impact/stress; "premium materials" → close-up macro shot emphasizing texture and material quality.
2. **Match each visual translation to a specific shot in Module 4's list** — the detail/macro shot is often where material quality gets shown; the lifestyle shot is often where in-use benefits get demonstrated.
3. **Flag features that are difficult to show visually** (e.g. a software feature, an ingredient purity claim) and recommend a supporting approach (an infographic-style overlay, an icon, or accepting that written copy elsewhere carries this specific claim rather than the photo).

## Output format

```
FEATURE-TO-VISUAL TRANSLATIONS:
[Feature, from Module 2] → Visual element: [specific, concrete] → Maps to shot: [from Module 4's list]
(repeat per key feature)

DIFFICULT-TO-VISUALIZE FEATURES FLAGGED: [features needing a different approach — infographic overlay, or handled in copy instead]
```

## Handoff

Feeds Module 7 directly — each shot's prompt should incorporate its mapped visual element.
