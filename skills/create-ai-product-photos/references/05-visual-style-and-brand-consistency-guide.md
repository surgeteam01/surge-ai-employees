# Module 5: Visual Style & Brand Consistency Guide

**Purpose:** Establish the style reference every generated shot must match — pulled directly from `build-your-own-brand-identity`'s Visual Mood & Imagery Style Guide if it exists, since re-deriving a visual style independently risks producing product photos that look inconsistent with the rest of the brand's marketing.

## Process

1. **Check for an existing brand identity guidelines document** and pull its color palette, lighting mood, and imagery style directly.
2. **If none exists**, define a lightweight style now: lighting mood (bright/airy vs. moody/dramatic), color grading tendency, and background treatment preference — consistent with Module 2/3's research, and flag that running `build-your-own-brand-identity` properly would strengthen consistency across everything else the business produces, not just these photos.
3. **Translate the style into AI-prompt-usable language** — specific lighting/color/mood descriptors that can be inserted directly into Module 7's prompts, not just abstract style adjectives.

## Output format

```
STYLE SOURCE: [existing build-your-own-brand-identity guidelines / defined fresh here]
LIGHTING MOOD: [...]
COLOR GRADING: [...]
BACKGROUND TREATMENT PREFERENCE: [...]
PROMPT-READY STYLE DESCRIPTORS: [specific language to insert into every shot's prompt]
```

## Handoff

Feeds Module 7 directly — every prompt should include these style descriptors for consistency, and Module 9's batch-consistency system builds on this baseline.
