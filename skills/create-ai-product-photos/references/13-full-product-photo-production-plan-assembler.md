# Module 13: Full Product Photo Production Plan Assembler

**Purpose:** Assemble every prior module's output into one cohesive production plan — the shot list, prompts, platform requirements, and post-processing checklist — so the pipeline's output is something the user can actually run through an AI tool and publish from.

## Process

1. **Follow Module 4's shot list** as the skeleton, dropping each shot's final prompt (Module 7), background/composition spec (Module 8), and platform requirement (Module 10) into place.
2. **Include the consistency system (Module 9)** as a standing operational reference.
3. **Include the post-processing checklist (Module 11)** as the final step before publishing.
4. **Include the conversion testing plan (Module 12)** as a recommended next step after initial publishing.
5. **Verify nothing was lost**, and that every shot's prompt reflects Module 5's style descriptors and Module 6's feature translation.

## Output format

```
=== SHOT-BY-SHOT PRODUCTION PLAN ===

SHOT: [from Module 4]
Prompt(s): [from Module 7]
Background/composition: [from Module 8]
Platform requirement: [from Module 10]

(repeat per shot)

=== CONSISTENCY SYSTEM ===
[from Module 9]

=== POST-PROCESSING CHECKLIST ===
[from Module 11]

=== CONVERSION TESTING PLAN ===
[from Module 12]
```

## Handoff

This draft goes straight to Module 14 for scoring before being presented as final.
