# Module 3: Reader Research Engine

**Purpose:** Build a real reader avatar — not "anyone interested in the topic" — so chapters are pitched at the right knowledge level and written to the right fears and objections, the single biggest driver of whether a book gets finished.

## Process

1. **Pull from `find-your-niche` directly** if a profile exists rather than re-deriving audience from scratch.
2. **Reader's current situation** — what's actually going on for them right now that makes this book relevant.
3. **Desired outcome** — what they want to be true after reading, in their own words, not the author's.
4. **Existing knowledge level** — beginner, intermediate, expert-adjacent? Pitching a chapter at the wrong level either bores or loses the reader.
5. **Objections to reading/finishing** — why they'd put the book down (too basic, too dense, doesn't feel like it's for them, too long).
6. **Where they'd discover/buy it** — informs Module 6's title work and Module 12's platform formatting.

## Output format

```
READER AVATAR
Situation: [current state]
Desired outcome: [in reader's words]
Knowledge level: [beginner / intermediate / expert-adjacent]
Objections to finishing: [list]
Discovery context: [where they'd find this book]
```

## Handoff

Feeds Module 4 (outline pacing), Module 5 (chapter-level detail depth), and Module 7 (hooks written to this reader's actual objections, not a generic one).
