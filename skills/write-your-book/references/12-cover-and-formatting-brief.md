# Module 12: Cover & Formatting Brief

**Purpose:** Produce a creative brief and format-compliance checklist for the cover and interior — direction and specs a designer or AI image tool can execute, not final rendered artwork — plus the practical formatting requirements for whichever platforms Module 1 specified.

## Process

1. **Pull visual direction from a `build-your-own-brand-identity` profile** if one exists; otherwise draft direction from scratch: genre-appropriate cover conventions (per Module 1's category), mood, color, and typography direction tied to Module 6's recommended title/subtitle.
2. **Write the cover creative brief** — title/subtitle placement, imagery direction, and 1-2 comparable covers in the same category to calibrate against.
3. **List format-specific requirements** for each intended platform from Module 1 — e.g. trim size and cover pixel dimensions for print/KDP, EPUB formatting conventions, PDF specs for a lead-magnet delivery.
4. **Flag if final cover art needs AI generation** rather than a hired designer.

## Output format

```
COVER CREATIVE BRIEF
Visual direction: [mood/color/type, tied to title]
Comparable covers: [1-2 examples + what to take/avoid from each]
Title/subtitle placement: [direction]

FORMAT CHECKLIST (per platform)
[Platform]: [trim size / file format / dimensions / other requirements]
(repeat per platform in scope)
```

## Handoff

Feeds Module 13. If the cover needs AI-generated artwork, hand this brief to `create-ai-product-photos`'s AI Prompt Engineering Lab rather than re-deriving prompt-engineering guidance here.
