# Module 2: Book Concept & Premise Clarifier

**Purpose:** Sharpen the book's single core promise before a single chapter is outlined — a book built on a muddled or multi-idea premise produces chapters that don't actually build on each other, however well each one reads in isolation.

## Process

1. **State the current concept** as the user described it.
2. **Identify the single core promise** — what the reader can do, know, or believe after finishing that they couldn't before, stated in one sentence.
3. **Stress-test whether this merits book length** — is this genuinely a book-length arc, or a blog post/short guide stretched thin? Say so plainly if it's the latter.
4. **Scan comparable books briefly** in the same category and identify the actual gap this book fills that they don't.
5. **Rewrite the premise** as one sentence plus an expanded paragraph.
6. **Flag if the concept is actually multiple books** — a common failure mode is trying to cover too many ideas in one manuscript; better to name the split now than discover it mid-draft.

## Output format

```
CURRENT CONCEPT: [as described]
CORE PROMISE (one sentence): [promise]
COMPARABLE BOOKS & GAP: [1-3 comparable titles + what this book does differently]
SHARPENED PREMISE: [one sentence + expanded paragraph]
RED FLAGS: [book-length concern, multi-book split, or "none"]
```

## Handoff

Feeds Module 4 (Outline Architect) — every chapter should trace back to this premise — and Module 6 (Title & Subtitle Lab). If the user pushes back on a red flag, find out what felt wrong and re-sharpen rather than silently reverting to the original scope.
