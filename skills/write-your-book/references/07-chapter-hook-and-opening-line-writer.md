# Module 7: Chapter Hook & Opening Line Writer

**Purpose:** Write a strong opening line for the book's introduction and for every chapter — readers decide whether to keep reading within the first few lines, the same mechanic as a sales page lead or an ad hook, applied to prose.

## Process

1. **For the introduction and each chapter**, draft an opening that earns the next paragraph: a cold-open story beat, a provocative question, a sharp stat, or a scene — matched to Module 3's reader avatar and what would actually catch their attention.
2. **Avoid throat-clearing** — "In this chapter, we will discuss..." is the default a real hook has to beat, not a acceptable fallback.
3. **Vary the hook type chapter to chapter** — an entire book of stat-opens or an entire book of stories-opens reads as formulaic; mix types across the table of contents.
4. **Check each hook sets up that chapter's specific promise** from Module 5, not a generic teaser.

## Output format

```
INTRODUCTION HOOK: [opening line/lines]

CHAPTER [N] HOOK: [opening line/lines] — Type: [story/question/stat/scene]
(repeat per chapter)
```

## Handoff

Feeds Module 8 — each chapter's draft opens with this line. If a hook feels generic once the full chapter is drafted, revise it in Module 10's pass rather than treating it as locked.
