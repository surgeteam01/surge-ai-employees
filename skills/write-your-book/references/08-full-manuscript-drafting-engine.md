# Module 8: Full Manuscript Drafting Engine

**Purpose:** Draft actual chapter prose, one chapter at a time, from that chapter's outline and hook — the stage where the book actually gets written.

## Process

1. **Draft one chapter at a time**, never the whole manuscript in a single pass — a book-length draft written in one continuous pass reliably drifts off Module 2's premise and loses the pacing control Module 4's arc was built to give it.
2. **Follow that chapter's outline (Module 5)** point by point, and open with that chapter's hook (Module 7).
3. **Maintain a consistent voice** — pull from the `write-like-a-human` profile if one exists; otherwise hold to Module 1's stated voice across every chapter.
4. **Write to Module 3's reader avatar** — language, examples, and pacing matched to their actual knowledge level, not a generic reader.
5. **End each chapter with a bridge** into the next one, using the transition noted in Module 5, rather than a hard stop.
6. **Check the draft roughly matches the chapter's target word count** before moving to the next chapter — a chapter running 3x its target is usually covering more than one idea.

## Output format

```
CHAPTER [N]: [title]
[full chapter draft in prose]

(repeat per chapter, drafted and reviewed one at a time)
```

## Handoff

Each finished chapter draft goes to Module 9 for proof integration, then accumulates toward Module 10's structural edit pass once every chapter is drafted. Don't move on to the next chapter until the current one's draft actually reads as finished, not a placeholder.
