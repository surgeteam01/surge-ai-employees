# Module 11: Front & Back Matter Writer

**Purpose:** Write the material that frames the book — the parts skipped during chapter drafting but that actually convert a reader into a next action (an email subscriber, a repeat customer, a referral).

## Process

1. **Draft the introduction** — why this book, who it's for, how to use it — using Module 6's recommended title and Module 3's reader avatar.
2. **Draft the conclusion** — recap the core promise from Module 2, and give one clear next action, not a vague "keep going" close.
3. **Write the author bio** matched to the credibility the premise actually needs (results, experience, or expertise relevant to the book's claims, not a generic biography).
4. **Draft acknowledgments** if applicable.
5. **Write the back-matter CTA** — adapted from CTA & Close Writer — matched to Module 1's stated purpose: an email list signup for a lead magnet, a next paid product for a book that's part of a funnel, or a review request for a standalone paid book.

## Output format

```
INTRODUCTION: [full text]
CONCLUSION: [full text]
AUTHOR BIO: [full text]
ACKNOWLEDGMENTS: [full text, or "skip"]
BACK-MATTER CTA: [full text, matched to Module 1's purpose]
```

## Handoff

Feeds Module 13. If the book is a lead magnet, hand the CTA's captured audience forward to `build-your-email-funnel`'s welcome sequence at Module 14; if it's a paid book, the CTA should point toward what `launch-a-digital-product` will use as the next offer.
