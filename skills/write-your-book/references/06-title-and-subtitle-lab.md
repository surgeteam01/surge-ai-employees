# Module 6: Title & Subtitle Lab

**Purpose:** Generate and score multiple title/subtitle options — the single highest-leverage piece of book marketing copy, since it decides the browse-to-open decision before anything inside the book matters.

## Process

1. **Generate several title angles** against Module 2's sharpened premise: benefit-led, curiosity-led, direct/how-to, and category-signaling (making clear at a glance what shelf this book belongs on).
2. **Pair each title with a clarifying subtitle** that removes ambiguity a title alone can't carry.
3. **Score each option** for clarity (would a stranger immediately understand what the book delivers), category fit, searchability (if this will be sold on a platform with search, per Module 1's purpose), and distinctiveness against Module 2's comparable-books scan.
4. **Pick a top choice plus one or two backups**, and state why the top choice wins.

## Output format

```
TITLE OPTIONS
1. [Title] — [Subtitle] — Clarity:_ Category Fit:_ Searchability:_ Distinctiveness:_
2. [Title] — [Subtitle] — scores
3. [Title] — [Subtitle] — scores

RECOMMENDED: [title + subtitle] — [why it wins]
```

## Handoff

Feeds Module 11 (the title page) and Module 12 (the cover brief is built around the recommended title/subtitle). If the user has a strong personal attachment to a lower-scoring title, note the tradeoff honestly rather than silently overriding their preference.
