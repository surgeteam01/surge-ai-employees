# Module 5: Chapter Content Outline Writer

**Purpose:** Turn each chapter title into an actual working outline before drafting, so Module 8 isn't starting from a blank page per chapter.

## Process

1. **For each chapter**, draft 3-6 key points or sections in the order they'll appear.
2. **State the chapter's promise** — what the reader can do or know specifically after this chapter, distinct from every other chapter's promise.
3. **Slot in a story/example placeholder** where Module 9's proof will eventually attach.
4. **Set a target word count** per chapter, proportional to the book's overall target from Module 1.
5. **Note the transition** into the next chapter, so Module 8's drafts connect rather than reading as isolated pieces.

## Output format

```
CHAPTER [N]: [title]
Chapter promise: [what reader can do/know after]
Key points: [3-6 bullets, in order]
Proof/example slot: [placeholder — type of proof needed]
Target word count: [number]
Transition to next chapter: [one line]

(repeat per chapter)
```

## Handoff

Feeds Module 7 (each chapter's opening hook is written against this outline) and Module 8 (the actual draft). Keep this outline as the reference Module 10's edit pass checks chapters against.
