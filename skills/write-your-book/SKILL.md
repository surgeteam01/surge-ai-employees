# Write Your Book

A 14-stage pipeline that takes raw expertise through to a finished, readability- and completion-scored manuscript — a sharpened premise, a reader-tested outline, chapter-by-chapter drafts in the author's own voice, real proof woven throughout, a structural edit pass, and front/back matter ready to publish. Each stage is a focused reference module in `references/`. Run them in order — a manuscript drafted without Module 4's outline architecture behind it is usually a pile of related chapters rather than a book with a throughline, the same way a rushed sales page under-converts without the stages behind it. If the user only wants one piece (e.g. just an outline, or just chapter 1), still run the lightweight stages that feed it (onboarding + concept clarifier + reader research) so that piece is grounded rather than written in a vacuum.

## How to run this skill

1. **Check for an existing `find-your-niche` profile or `write-like-a-human` voice profile** before re-asking anything.
2. **Work through stages 1–14 in order**, reading each reference file only when you get to that stage.
3. **Never draft the whole manuscript in one pass.** Module 8 exists specifically to draft one chapter at a time against that chapter's own outline (Module 5) and hook (Module 7) — a book written in a single continuous pass tends to drift off its premise and lose pacing control the way a sales page written without its Architect stage loses structure.
4. **Never skip Module 2 (Premise Clarifier).** A book with a muddled or multi-idea premise produces chapters that don't actually build on each other, however well each one reads individually.
5. **Always end with Module 14**, which should route the finished manuscript to its actual next step — `launch-a-digital-product` if it's a paid book, `build-your-email-funnel`'s welcome sequence if it's a lead magnet — not just hand back a score.

## Inputs this skill needs (collected in Stage 1)

Working title/topic, purpose (free lead magnet, low-ticket paid ebook, or a full nonfiction book), target reader (or a link to an existing `find-your-niche` profile), genre/category, target length (word/chapter count), any existing material to draw from (blog posts, transcripts, notes), timeline, and brand voice (or a link to an existing `write-like-a-human` profile).
