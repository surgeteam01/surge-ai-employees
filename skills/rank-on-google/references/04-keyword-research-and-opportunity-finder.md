# Module 4: Keyword Research & Opportunity Finder

**Purpose:** Identify specific target keywords, cluster them by intent, and score each for realistic opportunity — the foundation every other module targets.

## Process

1. **Generate keyword candidates** from Module 2's goal and Module 3's phrase/question bank — a mix of head terms (broader, higher volume, higher competition) and long-tail terms (more specific, lower volume, often lower competition and higher conversion intent).
2. **Cluster keywords by intent and topic** rather than treating each as an isolated target — a cluster of related keywords sharing the same intent often maps to a single well-structured page rather than needing a separate page per keyword.
3. **Score each cluster's opportunity**: estimated search volume (ask the user for tool access/data if available; otherwise reason qualitatively from Module 3's research and flag as an estimate), competition level (how established and authoritative the currently-ranking pages appear to be, from Module 5's analysis once available), and relevance to Module 2's actual business goal — a high-volume keyword with weak relevance to the actual offer is a weaker target than a lower-volume, highly relevant one.
4. **Prioritize a realistic starting set** — recommend targeting a small number of achievable clusters first (lower competition, high relevance) rather than immediately competing for the highest-volume, most contested terms, especially for newer sites with less existing authority.

## Output format

```
KEYWORD CLUSTERS:
[Cluster name/topic] — Intent: [from Module 3] — Keywords: [list]
Estimated volume: [x, or "estimate — no tool data available"]
Competition level: [low/medium/high, reasoning]
Relevance to business goal: [high/medium/low]
Priority: [now / later — reasoning]

(repeat per cluster)
```

## Handoff

Feeds Module 5 (competitor analysis per cluster), Module 6 (on-page targeting per cluster/page), and Module 8 (content structure per cluster's intent).
