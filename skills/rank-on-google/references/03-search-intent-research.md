# Module 3: Search Intent Research

**Purpose:** Classify search intent and build a Voice-of-Searcher profile — adapted from `sales-page-that-converts`'s Customer Research Engine, focused specifically on what a searcher expects to find, since matching intent is the single highest-leverage SEO factor.

## Process

1. **Classify intent for each target topic** into one of four types: **informational** (searcher wants to learn something — "how does X work"), **navigational** (searcher wants a specific site/page — brand or product name searches), **commercial investigation** (searcher is comparing options — "best X for Y," "X vs Y"), or **transactional** (searcher is ready to act — "buy X," "X pricing").
2. **Research what searchers actually expect to see** for each intent by examining the type of content currently ranking (feeds directly into Module 5, but note the pattern here too): informational intent often rewards clear, comprehensive explainer content; commercial investigation rewards comparison structures; transactional intent rewards a clear, fast path to action.
3. **Extract the exact phrases and questions** searchers use — these feed Module 4's keyword research and Module 8's content structure (e.g. "People Also Ask" style questions should often become actual subheadings).
4. **Flag any topic where the target intent is unclear or mixed** — content trying to satisfy multiple different intents at once often satisfies none of them well; recommend splitting into separate pages if intents genuinely diverge.

## Output format

```
TARGET TOPICS WITH INTENT CLASSIFICATION:
[Topic] — Intent: [informational / navigational / commercial / transactional]
(repeat per topic)

WHAT SEARCHERS EXPECT (per intent type): [pattern observed]
EXACT-PHRASE/QUESTION BANK: [real searcher language and questions]
MIXED-INTENT FLAGS: [any topic that should be split into separate pages]
```

## Handoff

Intent classification drives Module 8's structural decisions directly, and the phrase/question bank feeds Module 4 and Module 12 (SERP features often map directly to real questions).
