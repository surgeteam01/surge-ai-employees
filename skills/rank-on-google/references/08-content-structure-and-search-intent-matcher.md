# Module 8: Content Structure & Search-Intent Matcher

**Purpose:** Structure the actual page content to match what the specific search intent (from Module 3) expects — this is the single most important module for actually ranking, since Google's algorithm and real searchers both reward content that satisfies intent completely, and no amount of title/meta optimization compensates for a structural mismatch here.

## Process

1. **Match structure to intent type** (from Module 3): informational intent rewards clear, comprehensive explanation with a logical flow (definition → how it works → examples → common questions); commercial investigation intent rewards comparison structures (a table, pros/cons, clear criteria); transactional intent rewards a fast, clear path to the action with minimal friction; navigational intent needs the specific thing being searched for to be immediately, unambiguously findable.
2. **Fill in Module 6's header outline with real, comprehensive content** — addressing every gap identified in Module 5's competitor analysis, and directly answering every question in Module 3's phrase/question bank relevant to this page.
3. **Write for genuine comprehensiveness without padding** — comprehensive means covering what a searcher actually needs, not artificially lengthening content with filler to hit a word count; a shorter page that fully satisfies intent outranks a longer page that pads around a thin core.
4. **Include structural elements search engines and searchers both favor**: a clear introduction stating what the page covers, scannable formatting (short paragraphs, bullet points, bolded key terms), and a logical progression that answers the searcher's likely follow-up questions in order.
5. **Weave in E-E-A-T signals naturally** (full treatment in Module 10) — original examples, specific expertise, and genuine authority markers throughout the content, not just in an author bio.

## Output format

```
PAGE: [from Module 6]
INTENT-MATCHED STRUCTURE:
Introduction: [what the page covers, stated clearly]
[H2 section 1]: [full content, addressing Module 5's gaps and Module 3's questions]
[H2 section 2]: [full content]
(repeat per H2 from Module 6's outline)

COMPREHENSIVENESS CHECK: [confirm every gap from Module 5 and every relevant question from Module 3 is addressed]
```

## Handoff

This is the actual page content, feeding Module 9 (internal links placed within it), Module 10 (E-E-A-T signals layered on), and Module 13's assembly.
