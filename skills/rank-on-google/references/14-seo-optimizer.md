# Module 14: SEO Optimizer

**Purpose:** Score the finished SEO plan on rankability, intent-match, and completeness, and produce test variants — the final quality gate before publishing/optimizing pages.

## Process

1. **Score the assembled plan per page** on a simple rubric, 1-5 each:
   - **Intent match** — does the content structure genuinely match what Module 3 classified as the searcher's intent?
   - **Comprehensiveness** — does the content address every gap identified in Module 5 and every relevant question from Module 3?
   - **On-page technical completeness** — title, meta, headers, URL all properly structured?
   - **E-E-A-T strength** — are experience/expertise/authority/trust signals genuinely present and woven into the content, not just claimed superficially?
   - **Internal linking** — is this page properly connected within the site architecture, or isolated?
   - **Realistic opportunity** — given Module 5's competitive difficulty assessment, is ranking for this cluster genuinely achievable in a reasonable timeframe, or was an overly ambitious target chosen?
2. **Flag the lowest-scoring 1-2 dimensions** per page and revisit those specific modules.
3. **Check for keyword-stuffing or unnatural phrasing** that might have crept in during on-page optimization — content should always read naturally to a human first, search-optimized second.
4. **Produce at least one test variant** — typically an alternate title tag or an alternate content angle for the highest-opportunity page, to be tested once real ranking/click data comes in.

## Output format

```
SCORES (1-5, per page): Intent Match:_ Comprehensiveness:_ On-Page Technical Completeness:_ E-E-A-T Strength:_ Internal Linking:_ Realistic Opportunity:_

TOP FIXES MADE: [list, tied to lowest scores]

TEST VARIANT (on highest-opportunity page):
- Alternate title tag or content angle: [detail]
- Hypothesis being tested: [one line]
```

## Handoff

This is the last stage — present the final scored SEO plan to the user as the finished deliverable, ready to implement. If any score is 3 or below, flag it plainly rather than presenting the plan as "done" — and note that SEO results take real time to materialize even with a strong plan, so recommend a realistic review cadence (e.g. checking rankings/traffic after 6-12 weeks, not days) rather than expecting immediate results.
