# Module 7: Title & Meta Description Lab

**Purpose:** Write the title tag and meta description — adapted from `sales-page-that-converts`'s Headline Lab, balancing the same click-worthiness principles against the specific constraint of search-keyword targeting, similar to the title-vs-SEO trade-off `grow-on-youtube` navigates for video titles.

## Process

1. **Write the title tag** to include the primary keyword (from Module 6) naturally, ideally near the front, while still reading as a genuine, click-worthy statement — a title that's purely keyword-stuffed with no human appeal underperforms on click-through even if it ranks.
2. **Keep the title tag within typical display-length limits** (roughly 50-60 characters) so it doesn't get truncated in search results.
3. **Write the meta description** to summarize the page's actual value and include the primary keyword naturally — meta descriptions don't directly affect ranking but strongly affect click-through rate from the SERP, which is itself an indirect ranking signal over time.
4. **Score title options** on the same Clarity/Specificity/Believability/Relevance rubric used elsewhere in this repo, adding a Keyword-fit dimension specific to SEO.

## Output format

```
PAGE: [from Module 6]

TITLE TAG OPTIONS (scored 1-5 on Clarity/Specificity/Believability/Relevance/Keyword-fit):
1. [title] — under 60 characters
2. ...
TOP TITLE: [...]

META DESCRIPTION: [under ~155-160 characters, includes primary keyword naturally, summarizes real value]
```

## Handoff

Feeds Module 13's assembly directly as the page's SERP-facing metadata.
