# Module 5: Content Gap & Competitor SERP Analysis

**Purpose:** Analyze what's currently ranking for each target keyword cluster and identify gaps — adapted from `nail-your-pricing`'s Competitor & Market Pricing Scan logic, applied to search results instead of market pricing.

## Process

1. **Identify what's currently ranking** for each priority cluster from Module 4 — the top-ranking pages' apparent content depth, structure, and the specific sub-topics/questions they cover.
2. **Categorize each competitor's content**: comprehensive-and-strong (a genuinely thorough, well-structured page that will be hard to outrank without a meaningfully better resource), thin-or-outdated (an opportunity — a page that's ranking on domain authority alone despite weak content), or differently-angled (covers the topic but from a different angle, leaving room for a differentiated approach rather than a head-on copy).
3. **Identify content gaps** — sub-topics or questions from Module 3's research that no current top-ranking page addresses well, which represent a genuine opportunity to be more comprehensive or more useful than what's currently ranking.
4. **Flag realistically difficult clusters** — where every top result is comprehensive, authoritative, and backed by strong domain authority; recommend deprioritizing these in favor of Module 4's lower-competition opportunities, at least initially.

## Output format

```
COMPETITOR SERP ANALYSIS (per priority cluster):
[Cluster]
Top-ranking pages: [list, with category: comprehensive-and-strong / thin-or-outdated / differently-angled]
Content gaps identified: [sub-topics/questions no current page addresses well]
Difficulty flag: [realistic assessment of how hard this cluster is to break into]

(repeat per cluster)
```

## Handoff

Feeds Module 6 (on-page architecture should address the identified gaps) and Module 8 (content structure should be more comprehensive/useful than the thin-or-outdated competitors, and differentiated from the differently-angled ones).
