# Module 13: Full Niche Brief Assembler

**Purpose:** Assemble every prior module's output into one cohesive niche brief — the chosen segment, positioning, differentiation, beachhead, validation plan, and messaging — so the pipeline's output is a single reference document, and directly reusable as the "audience/offer" input to every other Surge skill.

## Process

1. **Lead with the decision**: the chosen segment and positioning statement, stated plainly and confidently, not buried under the analysis that led there.
2. **Include the supporting reasoning** — viability scores (Module 6), differentiation/mechanism (Module 8), and beachhead (Module 9) — as backup for the decision, not as the headline.
3. **Include the validation plan (Module 11) as an explicit action list**, not just a strategic note, since this is the concrete next step the user should act on immediately after this pipeline finishes.
4. **Include the ready-to-use messaging (Module 12)** as a clearly separated, copy-paste-ready section.
5. **Check consistency** — the positioning statement, differentiation, and messaging should all describe the same segment in compatible language, not drift into slightly different framings across modules.

## Output format

```
=== NICHE DECISION ===
Chosen segment: [from Module 6]
Positioning statement: [from Module 7]
Beachhead: [from Module 9]

=== WHY THIS NICHE ===
Viability scores: [from Module 6]
Differentiation/unique mechanism: [from Module 8]

=== VALIDATION PLAN (next steps) ===
[from Module 11]

=== READY-TO-USE MESSAGING ===
[from Module 12]
```

## Handoff

This draft goes straight to Module 14 for scoring before being presented as final. Once finalized, this brief's segment and positioning statement should be handed forward as the "audience" and "offer" inputs whenever the user runs any other Surge skill for this business going forward — flag this explicitly to the user so they know to reuse it rather than re-describing their audience from scratch each time.
