# Module 14: Niche Optimizer

**Purpose:** Score the finished niche brief on clarity, viability, and differentiation, and surface an alternate angle worth considering — the final quality gate before the user commits time and identity to this positioning.

## Process

1. **Score the assembled brief** on a simple rubric, 1-5 each:
   - **Clarity** — would a stranger, reading the positioning statement once, immediately understand who it's for and what it promises?
   - **Viability** — carry forward the chosen segment's total score from Module 6, in context against the other candidates.
   - **Differentiation** — is the unique mechanism genuinely distinct from Module 3's existing players, or does it still sound like a generic version of what's already out there?
   - **Personal fit/sustainability** — does this niche connect to work the person actually wants to keep doing (from Module 1), or does it optimize for market opportunity at the expense of long-term motivation?
   - **Actionability of validation plan** — is Module 11's plan concrete and immediately executable, or still vague?
2. **Flag the lowest-scoring 1-2 dimensions** and revisit those specific modules rather than a generic pass over the whole brief.
3. **Surface one genuine alternate niche angle** — either the second-ranked candidate from Module 6, or a meaningfully different beachhead/mechanism combination within the same chosen segment — so the user sees the decision was made among real alternatives, not presented as the only possible answer.
4. **Recommend a specific revisit trigger**, tied to Module 11's validation plan — a specific outcome (or its absence) that should prompt reconsidering the alternate angle, so the door back to option B stays practically open rather than requiring the user to restart this whole pipeline from scratch if things don't validate.

## Output format

```
SCORES (1-5): Clarity:_ Viability:_ Differentiation:_ Personal Fit/Sustainability:_ Validation Plan Actionability:_

TOP FIXES MADE: [list, tied to lowest scores]

ALTERNATE ANGLE TO KEEP IN MIND: [second candidate or alternate mechanism/beachhead] — worth revisiting if: [specific validation outcome]
```

## Handoff

This is the last stage — present the final scored niche brief and the noted alternate angle to the user as the finished deliverable. If any score is 3 or below, say so plainly rather than presenting the niche as "done" — flag it as a known weak point (e.g. "Differentiation scored low because the unique mechanism still overlaps heavily with an established competitor's approach — recommend sharpening this before investing heavily in messaging built on it").
