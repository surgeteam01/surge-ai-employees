# Module 12: Messaging & Bio Writer

**Purpose:** Turn the chosen positioning statement into ready-to-use bios and an elevator pitch — the first pieces of actual public-facing copy this pipeline produces, and the pieces most likely to be used immediately (social profiles, website, introductions).

## Process

1. **Write a short social bio** (typically under 160 characters, matching common social platform constraints) built directly from Module 7's one-sentence positioning variant.
2. **Write a longer website/LinkedIn-style bio** (2-4 sentences) expanding with a touch of the differentiation/mechanism from Module 8 and, if available, a specific proof point.
3. **Write the spoken elevator pitch** — a natural-sounding 10-15 second answer to "so what do you do?", based on Module 7's conversational variant, adjusted so it sounds like something an actual person would say out loud, not a written statement read aloud.
4. **Write one version aimed at the broader niche and, if meaningfully different, one tighter version aimed specifically at the beachhead** (Module 9) for use in beachhead-specific contexts (a niche community, a specific outreach context).
5. **Use the exact-phrase bank from Module 5** where it fits naturally, so the bio sounds like it understands the audience's own language rather than generic positioning-speak.

## Output format

```
SOCIAL BIO (short): [under ~160 characters]

WEBSITE/LINKEDIN BIO (longer): [2-4 sentences, with differentiation/proof woven in]

ELEVATOR PITCH (spoken): [natural, conversational, 10-15 seconds]

BEACHHEAD-SPECIFIC VARIANT (if meaningfully different): [tighter bio/pitch for the specific micro-segment]
```

## Handoff

This copy feeds Module 13's final assembly and is typically the first thing the user actually goes and updates (social profiles, website) once this pipeline finishes — flag it as ready-to-use rather than a draft requiring further work, unless a specific weakness was noted.
