# Module 7: Positioning Statement Writer

**Purpose:** Write the core positioning statement for the chosen segment — the single sentence (and a few supporting variants) that will anchor every future piece of marketing, and the direct input to every other Surge skill's Onboarding "offer/audience" fields.

## Process

1. **Use the classic structure as a starting scaffold**: "I help [specific segment] achieve [specific outcome] through/without [mechanism/differentiator]" — then push past the template until it reads like a real sentence, not a mad-lib.
2. **Pull the specific segment description directly from Module 4/6** (not a generalized version of it) and the specific outcome from Module 5's top desire — genericizing either one at this stage undoes the narrowing work every prior module did.
3. **Write 3-4 variants** at different lengths/tones: a one-sentence version (for a bio or elevator pitch), a two-sentence expanded version (adds a touch of mechanism or proof), and a conversational spoken version (how the person would actually say this out loud when asked "so what do you do?" — often looser and warmer than the written version).
4. **Test the statement against a simple bar**: would a member of the actual target segment, hearing this, think "that's for me" within a few seconds? If the statement is so broad it could apply to many different businesses, it hasn't done its job yet.

## Output format

```
POSITIONING STATEMENT (core): "I help [segment] achieve [outcome] through/without [mechanism]."

VARIANTS:
One-sentence (bio/elevator pitch): [...]
Two-sentence (expanded, with light proof/mechanism): [...]
Conversational (spoken, "so what do you do?"): [...]

CLARITY TEST: [would the target segment immediately recognize themselves in this? yes/no + why]
```

## Handoff

This statement feeds Module 8 (differentiation builds on top of it), Module 9 (the beachhead segment gets its own tighter variant), and Module 12 (bios and messaging expand directly from this core line). It also becomes the direct input to the "audience" and "offer" fields in every other Surge skill's Onboarding module going forward.
