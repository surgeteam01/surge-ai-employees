# Module 2: Offer Clarifier

**Purpose:** Sharpen the offer and the transformation it delivers before a word of the webinar gets scripted. A webinar built around a vague offer wastes 45-60 minutes of a live audience's attention arriving at a pitch that still doesn't land.

## Process

1. **State the current offer in one sentence**, as the user described it.
2. **Stress-test it against the Value Equation**: Dream Outcome (how big/specific is the result?), Likelihood of Success (how believable is it?), Time Delay (how fast do they get there?), Effort & Sacrifice (how easy is it?). Flag whichever of these four is weakest or missing.
3. **Rewrite the offer as a before → after transformation**, not a feature list. Bad: "a course on running Facebook ads." Good: "go from guessing at ad spend to a repeatable process that turns $1 into $3 in trackable sales within 90 days."
4. **Check specificity.** Vague promises get forgiven in a 45-minute presentation less than anywhere else in this pipeline — a live audience has time to notice hand-waving. Push for numbers, timeframes, and named outcomes wherever honestly possible.
5. **Flag anything unprovable or overclaimed** — don't let an inflated promise go forward; it will surface again live during Q&A (Module 9) as a credibility problem in front of the whole audience at once, which is a much more public failure mode than a single reader silently distrusting a page.

## Output format

```
CURRENT OFFER (as given): [one sentence]
WEAKEST LINK: [Dream Outcome / Likelihood / Time / Effort]
SHARPENED OFFER (one sentence): [rewrite]
TRANSFORMATION STATEMENT (one paragraph, before → after): [rewrite]
RED FLAGS: [anything overclaimed, vague, or unprovable]
```

## Handoff

The sharpened offer and transformation statement become the backbone of Module 4 (Webinar Architect), Module 5 (Registration Page), Module 7 (Content & Script), and Module 11 (Pitch & Close). If the user pushes back on the sharpened version, don't just default back to their original wording — ask which specific part felt wrong and refine, since a vague offer weakens the entire spoken arc, not just one section.
