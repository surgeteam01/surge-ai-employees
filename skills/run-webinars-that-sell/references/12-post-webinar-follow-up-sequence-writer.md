# Module 12: Post-Webinar Follow-Up Sequence Writer

**Purpose:** Write two distinct follow-up sequences after the event — one for attendees who watched but didn't buy, and one for registrants who didn't show up at all. These two audiences are in very different places and need different messages, not one generic "thanks for registering" blast.

## Process

1. **Attendee-no-buy sequence** — this audience has already seen the full pitch, so the sequence's job is closing an open loop, not re-selling from scratch: a replay/recap email (if a replay is offered) restating the core offer and stack, a proof-reinforcement email, a dedicated objection email addressing the most common live hesitation (from Module 9), and a real-urgency close if a genuine cart-close/bonus-expiry deadline applies (use the same honest-urgency standard as everywhere else in this pipeline — never fabricate one). Typically 3-5 emails over the days following the live event.
2. **No-show sequence** — this audience registered but never saw the pitch, so this sequence needs to do more work: an empathetic "sorry you missed it" opener (no guilt), a replay link if offered (this is the highest-priority element for this audience — getting them to actually watch matters more than anything else), a condensed teaser of the core teaching content if no replay is offered, and only then a lighter version of the offer/pitch. Typically 2-4 emails.
3. **Use Module 4's map for timing** — both sequences should start within a day of the live event while it's still fresh, and respect whatever real deadline (if any) governs the offer's availability.
4. **Keep both sequences honest about attendance** — never imply a no-show attended, and never guilt either audience for their behavior; the tone should stay consistent with the webinar's own voice (Module 1).

## Output format

```
ATTENDEE-NO-BUY SEQUENCE ([count] emails):
EMAIL 1 — Replay/Recap
Body: [full email copy]
EMAIL 2 — Proof Reinforcement
Body: [full email copy]
EMAIL 3 — Objection Email
Body: [full email copy]
FINAL EMAIL — Real Urgency Close (if applicable)
Body: [full email copy, or "no real deadline available — recommend a value-based close instead"]

NO-SHOW SEQUENCE ([count] emails):
EMAIL 1 — Sorry You Missed It + Replay Link
Body: [full email copy]
EMAIL 2 — Condensed Teaching Teaser (if no replay offered)
Body: [full email copy]
EMAIL 3 — Lighter Offer Introduction
Body: [full email copy]
```

## Handoff

Both sequences feed into Module 13's assembly at the timing defined by Module 4's map. If the webinar is evergreen/on-demand, this module may need to run continuously rather than as a one-time post-event push — note that explicitly rather than assuming a single live-event follow-up window.
