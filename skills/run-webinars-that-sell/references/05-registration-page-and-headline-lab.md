# Module 5: Registration Page & Headline Lab

**Purpose:** Write and score the webinar's title/headline and the registration page copy that gets it — this is the sales page equivalent for the webinar funnel's first, and highest-leverage, conversion point: getting the register-click at all.

## Process

1. **Generate at least 6-8 title/headline options**, drawing on the sharpened offer (Module 2), the top desire/pain (Module 3), and multiple formulas so options are genuinely different:
   - **How-to + specific outcome**: "How to [specific result] in [timeframe] without [common objection]."
   - **Number + method**: "The [n]-step system for [outcome]."
   - **Curiosity/reveal**: "The [surprising element] that [audience] use to [outcome]" — riskier, use only if it's genuinely true and provable live, not clickbait relative to the actual content.
   - **Customer-language mirror**: built directly from the exact-phrase bank in Module 3.
2. **Score each option** on: Clarity (is it obvious what they'll learn?), Specificity (numbers/timeframes beat vague claims), Believability (does it feel deliverable in a single session?), and Relevance (does it speak to the actual audience segment?).
3. **Write the registration page** around the top-picked title: a short promise (what they'll walk away knowing/able to do), 3-4 bullet points previewing specific content (not the pitch — these should be genuinely valuable teaching points, since overselling the content and underdelivering live is one of the fastest ways to burn a list), presenter credibility (brief, concrete, not a full bio), date/time or on-demand access, and a single clear registration CTA.
4. **Avoid pitching the paid offer on the registration page at all** — the registration page's only job is to sell attendance, not the product; a registration page that reads like a sales page for the paid offer suppresses registrations from exactly the audience who'd benefit most from the teaching first.

## Output format

```
TITLE/HEADLINE OPTIONS (scored 1-5 on Clarity / Specificity / Believability / Relevance):
1. [title] — C:_ S:_ B:_ R:_
2. ...

TOP PICK: [title]

REGISTRATION PAGE COPY:
Promise line: [one sentence]
What you'll learn: [3-4 bullets, genuine content previews]
Presenter credibility: [1-2 sentences]
Date/time or access: [detail]
CTA: [registration button copy]
```

## Handoff

The top-picked title and promise line should echo forward into Module 7's opening hook, so the webinar delivers on exactly what the registration page promised — a mismatch between registration promise and delivered content is the single biggest driver of early drop-off once the webinar starts.
