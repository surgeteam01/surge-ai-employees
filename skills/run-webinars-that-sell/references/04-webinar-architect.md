# Module 4: Webinar Architect

**Purpose:** Produce the full funnel map — registration, reminder cadence, webinar structure, and follow-up — before any actual copy or script gets written. This is the webinar equivalent of a sales page outline and an email funnel map combined, since a webinar funnel needs both.

## Process

1. **Choose webinar length and content depth by awareness stage** (from Module 3): *unaware/problem-aware* audiences need more teaching time to build belief before the pitch can land (typically 45-60 minutes, weighted toward content); *solution-aware/product-aware* audiences need less (30-45 minutes); *most-aware* audiences can run shorter and pitch sooner.
2. **Map the pre-webinar funnel**: registration page → confirmation → reminder sequence (Module 6) → the live/scheduled event itself. Decide reminder touchpoints and timing based on format (from Module 1): a live webinar scheduled days out needs a longer reminder cadence (immediate confirmation, 1-day-out, hour-before, minutes-before) than an evergreen webinar triggered on-demand (which mostly needs an immediate confirmation and a start-now link).
3. **Map the webinar's internal structure**: open/hook → content/teaching → transition to pitch → pitch/offer → close → live Q&A (if applicable). Note the approximate time allocation for each section so Module 7 and Module 11 know how much room they have.
4. **Map the post-webinar funnel**: what happens immediately after (replay email, if offered), the follow-up sequence for attendees who didn't buy (Module 12), and a separate sequence for registrants who didn't show up at all (also Module 12) — these two audiences need different messaging, since a no-show hasn't seen the pitch yet and an attendee has.
5. **Note which modules feed which piece**, so nothing gets built twice.

## Output format

```
CONTENT DEPTH: [teaching-heavy / balanced / pitch-forward] — reason: [awareness stage]
WEBINAR LENGTH: [target duration]

PRE-WEBINAR FUNNEL MAP:
Registration page → fed by: Module 5
Confirmation → [immediate content]
Reminder sequence → fed by: Module 6 — touchpoints: [list, with timing]

WEBINAR INTERNAL STRUCTURE (with time allocation):
1. Open/Hook — [x min] — fed by: Module 7
2. Content/Teaching — [x min] — fed by: Module 7
3. Transition to Pitch — [x min] — fed by: Module 7 → Module 11
4. Pitch/Offer — [x min] — fed by: Module 11
5. Close — [x min] — fed by: Module 11
6. Live Q&A (if applicable) — [x min] — supported by: Module 9

POST-WEBINAR FUNNEL MAP:
Replay email (if offered) → [immediate content]
Attendee-no-buy follow-up → fed by: Module 12
No-show follow-up → fed by: Module 12
```

## Handoff

This map is the skeleton Module 13 (Assembler) will fill in. Every piece in the map must map to exactly one upstream module's output — if a piece doesn't have a clear source, flag it now rather than discovering the gap at assembly time.
