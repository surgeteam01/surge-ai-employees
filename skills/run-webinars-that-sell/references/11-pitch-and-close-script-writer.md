# Module 11: Pitch & Close Script Writer

**Purpose:** Write the full spoken pitch — from the transition handoff (Module 7) through the offer reveal, guarantee, price, urgency, and close. This is the webinar's equivalent of a sales page's offer-stack-through-CTA sections, but delivered live, which means pacing and tone matter as much as the words themselves.

## Process

1. **Open the pitch by picking up the transition** from Module 7 — restate in one line that there's a faster, more complete path for those who want it, then move directly into introducing the offer by name.
2. **Reveal the offer stack** using Module 10's progressive reveal order and spoken lines — build the total value visibly before showing the price.
3. **Weave in the strongest proof** (from Module 8, placed for the pitch) right before or right after the stack reveal, reinforcing that this works for people like the attendee.
4. **Pre-empt the 1-2 strongest objections** (from Module 9) at the position that module specified — typically right before the price reveal, so the price lands on an audience whose main doubts have already been addressed.
5. **Present the guarantee** clearly and confidently — write it in spoken, plain language (not legalistic), positioned to directly reduce the risk of the price about to be shown. If a guarantee hasn't been designed yet, flag this and recommend running the guarantee-writing portion of `nail-your-pricing` or `sales-page-that-converts` first, since a webinar pitch without risk-reversal is unusually exposed at the price-reveal moment.
6. **Reveal the price**, anchored against the total stack value, with a spoken justification line tying it to the transformation, not just the deliverables.
7. **Use only real urgency/scarcity** — a genuine cart-close time, a genuine cohort start date, a genuine bonus that expires with the webinar's replay window. Never fabricate a fake countdown or fake limited seats; a live audience discovering fabricated urgency (e.g. by comparing notes with someone who registered for "the same one-time event" weeks later) is a fast, public way to lose trust with an entire list at once.
8. **Write the close**: a clear, single, specific instruction for what to do right now (the link, the button, the QR code), followed by a short, sincere final statement of the transformation — end on conviction, not a trailing "so yeah, that's it."
9. **Write the transition into live Q&A** if applicable, framed to keep momentum toward buying rather than treating Q&A as a separate, disconnected segment.

## Output format

```
PITCH SCRIPT (target: [x min]):

Transition pickup: [one line, from Module 7]
Offer introduction: [naming the offer]
Stack reveal: [from Module 10, with pacing notes — "pause here," "show slide here"]
Proof placement: [from Module 8]
Objection pre-empt(s): [from Module 9]
Guarantee: [spoken, plain-language version]
Price reveal + justification: [spoken lines]
Urgency element: [real element used, or "none available — recommend not fabricating one"]
Close: [specific instruction + final transformation statement]
Transition to Q&A (if applicable): [one line]
```

## Handoff

This script is the persuasive core of the live event — Module 13 assembles it as the centerpiece of the funnel package, and Module 14 will specifically test whether the transition (from Module 7), the objection pre-empts, and the close are strong enough or need an A/B variant.
