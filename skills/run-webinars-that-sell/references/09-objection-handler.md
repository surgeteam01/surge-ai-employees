# Module 9: Objection Handler

**Purpose:** Surface the real objections a buyer will have and prepare answers for both the pitch script and live Q&A. A webinar has an advantage no page or email has — real-time audience questions — but that's also a live-fire moment where an unprepared answer is far more visible than a weak page section.

## Process

1. **Start from Module 3's objection list**, then add category-specific objections: price ("is this worth it?"), time ("I don't have time for this"), fit ("will this work for someone like me / at my stage?"), trust ("why should I believe this from a stranger on a webinar?"), and past-failure ("I've tried things like this before and it didn't work").
2. **Write a direct rebuttal for each** — acknowledge it's a real concern before answering it; dismissive answers read as defensive, and live audiences notice defensiveness faster than a page's readers would.
3. **Decide placement**: the 1-2 strongest objections should be pre-empted directly inside the pitch script itself (Module 11), addressed before the attendee even has to ask — this is one of the biggest advantages a spoken pitch has over a page, since timing the pre-empt well can eliminate the objection before it fully forms. The rest should be prepared as live Q&A answers.
4. **Prepare Q&A handling guidance**: how to bridge a hostile or off-topic question back to the offer gracefully, how to handle "will you cover X" questions that arise during content (deferring cleanly to Q&A or the paid offer without breaking pacing), and how to close Q&A on a high note rather than ending on a skeptical question.

## Output format

```
OBJECTIONS PRE-EMPTED IN THE PITCH:
1. [Objection] → [Rebuttal] → placement: [where in Module 11's pitch]
2. ...

LIVE Q&A PREPARED ANSWERS:
Q: [anticipated question, in customer phrasing]
A: [direct, honest answer]
(repeat)

Q&A HANDLING GUIDANCE: [bridging hostile/off-topic questions, closing Q&A well]
```

## Handoff

The pre-empted objections get woven into Module 11's pitch script at the position noted. The live Q&A answers and handling guidance become a companion reference the presenter uses during the actual live session, alongside the assembled script from Module 13.
