# Module 10: Offer Stack Builder

**Purpose:** Present the offer as a value-anchored stack — every component named, valued, and justified — for the moment in the webinar pitch when it's revealed. Stacking makes the price feel small relative to what's included, and a live reveal (building the stack piece by piece rather than showing it all at once) is one of the strongest tools a spoken pitch has that a static page doesn't.

## Process

1. **List every component** of the offer: the core deliverable, plus any bonuses, templates, community access, support, guarantees-as-value, etc.
2. **Assign an honest perceived value to each component.** This should be defensible (what would this cost or sell for on its own?), not inflated to the point of being unbelievable — an implausible stack undermines trust rather than building it, and a live audience can sense an inflated claim in real time.
3. **Order components for a progressive live reveal** — the core offer first, then each bonus revealed one at a time with a brief reason it's included, building the total value visibly rather than showing the whole stack at once (which a static page does, but a spoken pitch can do better by building anticipation).
4. **Total the stack** and set it against the actual price (from Module 1, or run `nail-your-pricing` first if the price itself still needs to be set), so the gap does the persuading.
5. **Write one spoken line of justification per component** — what it does for the buyer, not just what it is, written to be said naturally rather than read off a slide.

## Output format

```
OFFER STACK (in reveal order):
- [Core offer] — Value: $[x] — spoken line: "[what it delivers, said naturally]"
- [Bonus 1] — Value: $[x] — spoken line: "[...]"
- [Bonus 2] — Value: $[x] — spoken line: "[...]"
...
TOTAL VALUE: $[sum]
ACTUAL PRICE: $[price]
FRAMING LINE: [one sentence tying the gap to the offer's core promise, said right before the price reveal]
```

## Handoff

This stack feeds directly into Module 11's pitch script, which decides the exact live pacing of the reveal (how long to pause between bonuses, when to show a slide vs. speak it) and into the guarantee/price/close sequence that follows it.
