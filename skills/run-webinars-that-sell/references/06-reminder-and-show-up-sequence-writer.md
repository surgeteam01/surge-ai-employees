# Module 6: Reminder & Show-Up Sequence Writer

**Purpose:** Write the sequence between registration and the live event whose entire job is maximizing how many registrants actually show up — registration is a soft commitment, and most registrants need several nudges to convert that into an attended session.

## Process

1. **Confirm touchpoints and timing from Module 4's map.** A typical live webinar reminder sequence: immediate confirmation (with the promise recapped and, if relevant, a calendar-add link), a value-add reminder 1-2 days out (a piece of useful content or a teaser related to the topic, not just "don't forget"), a day-of reminder, and an hour-before/minutes-before final reminder. Evergreen/on-demand formats mostly need the immediate confirmation with a clear start-now link, since there's no fixed date to remind toward.
2. **Make every reminder do more than remind.** Each touchpoint should reinforce why attending live (or now, for evergreen) matters — a specific teaser of what's covered, a reason it's worth the calendar time, or addressing the most common reason people miss webinars they registered for ("something came up" — consider explicitly encouraging registrants to block the calendar time now).
3. **Use the exact-phrase bank and promise from Module 3 and Module 5** so the reminder sequence feels continuous with why they registered in the first place, not a generic "see you there!" template.
4. **Write the final reminder (hour-before/minutes-before) to be short and action-focused** — just the join link, the time, and one line reinforcing the promise; this isn't the place for new persuasion, just frictionless access.
5. **For evergreen formats**, write a short "why now" element into the confirmation, since there's no live-event scarcity naturally reinforcing urgency to actually click through.

## Output format

```
REMINDER SEQUENCE ([count] touchpoints):

CONFIRMATION (immediate)
Body: [full message copy — promise recap, calendar-add or start-now link]

REMINDER 1-2 DAYS OUT (if live)
Body: [full message copy — value-add teaser]

DAY-OF REMINDER (if live)
Body: [full message copy]

HOUR-BEFORE / MINUTES-BEFORE REMINDER
Body: [short, action-focused — join link + time + one-line promise recap]
```

## Handoff

These messages feed Module 13's assembly at the timing/trigger noted in Module 4's map. If the funnel is evergreen, most of this module collapses to the confirmation message alone — say so plainly rather than padding out reminders that don't apply to an on-demand format.
