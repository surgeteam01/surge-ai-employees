# Module 10: Common Prompting Mistakes & Fixes

**Purpose:** Catalog the recurring input mistakes that produce weak AI output — the input-side counterpart to `write-like-a-human`'s AI-Tell Detector, which addresses the output side; this module is about what the user types, not what the AI produces.

## Process

1. **Catalog common mistakes**: vagueness ("make this better" with no specifics), contradictory instructions (asking for both "concise" and "comprehensive" without reconciling the tension), missing context (assuming the AI knows something it has no way to know), format left unspecified (then being frustrated the output isn't in the format silently expected), and over-stuffing a single prompt with too many unrelated asks at once.
2. **Write a direct fix for each mistake**, tied to the relevant technique module (Modules 4-9).
3. **Cross-check Module 1's stated frustrations against this list** — most real frustrations map cleanly onto one or more of these common mistakes, which is itself a useful diagnostic to show the user directly.
4. **Note that this is diagnostic, not exhaustive** — the goal is recognizing the pattern in their own prompting, not memorizing an exhaustive list.

## Output format

```
COMMON MISTAKES & FIXES:
1. Vagueness → Fix: [tied to Module 3]
2. Contradictory instructions → Fix: [reconcile before sending]
3. Missing context → Fix: [tied to Module 4]
4. Unspecified format → Fix: [tied to Module 6]
5. Overstuffed single prompt → Fix: [split into sequential asks, tied to Module 9]

USER'S FRUSTRATIONS MAPPED (from Module 1): [which of these mistakes explains their specific complaint]
```

## Handoff

Feeds Module 14's diagnosis of the user's real sample prompt directly.
