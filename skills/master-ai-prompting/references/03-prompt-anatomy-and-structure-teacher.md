# Module 3: Prompt Anatomy & Structure Teacher

**Purpose:** Teach the core components of an effective prompt — the foundational structure every later, more specific module (context, role, format, examples) builds on.

## Process

1. **Teach the core components**: the task itself (what you actually want done, stated directly and specifically), context (relevant background the AI needs but doesn't have — see Module 4), constraints/format (how the output should be structured — see Module 6), and, where useful, a role or examples (see Modules 5 and 7).
2. **Show, using Module 2's real gap**, how a prompt missing one of these components produces exactly the kind of generic or off-target output the user described — connecting the abstract anatomy to their actual frustration, not a hypothetical one.
3. **Teach the "specificity beats length" principle** — a short, specific prompt usually outperforms a long, vague one; more words aren't the fix for vague output, more specific words are.
4. **Explain that not every component is needed every time** — a simple task needs less scaffolding than a complex one; the goal is matching the prompt's structure to the task's actual complexity, not maximizing every component reflexively.

## Output format

```
CORE PROMPT COMPONENTS: [task, context, constraints/format, role (optional), examples (optional)]

DIAGNOSIS (using Module 2's real gap): [which component(s) were missing or weak in the user's actual current prompt, and how that explains the output gap]

SPECIFICITY PRINCIPLE: [short explanation, tied to the user's example]
```

## Handoff

Feeds every subsequent module — Modules 4-9 each teach one component in depth, using this anatomy as the shared reference.
