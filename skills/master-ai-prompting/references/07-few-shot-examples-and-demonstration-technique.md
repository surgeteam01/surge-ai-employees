# Module 7: Few-Shot Examples & Demonstration Technique

**Purpose:** Teach using examples to guide style, format, and quality — one of the most reliable techniques for getting consistent output, since showing is often more effective than describing.

## Process

1. **Teach when examples help most**: matching a specific voice/style (an example of the desired tone often works better than adjectives describing it), matching a specific format (a filled-out example template removes ambiguity entirely), and calibrating quality level (a strong example shows what "good" looks like more concretely than a description).
2. **Teach how many examples are typically useful** — often even a single well-chosen example ("one-shot") meaningfully improves consistency; 2-3 varied examples ("few-shot") further reinforces a pattern without being excessive.
3. **Teach choosing examples that actually represent the range wanted** — if the real task varies (different lengths, different scenarios), a single narrow example may over-constrain the output; choose examples that show the actual range, not just one ideal case.
4. **Apply to Module 2's real use case** — would providing an example help here, and if the user has one (a past piece of output they liked, or a reference from elsewhere), how to use it in the prompt.

## Output format

```
WHEN EXAMPLES HELP MOST: [style matching, format matching, quality calibration]
HOW MANY: [one-shot vs. few-shot guidance]
CHOOSING REPRESENTATIVE EXAMPLES: [explanation]
APPLIED TO USER'S REAL USE CASE: [would an example help, and what to use]
```

## Handoff

Feeds Module 12's template library (templates often embed a strong example directly) and Module 14's live rewrite.
