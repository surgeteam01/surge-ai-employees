# Module 5: Role & Persona Assignment Guide

**Purpose:** Teach when and how assigning a role or persona to the AI actually improves output, and — just as important — when it doesn't help and is just adding words.

## Process

1. **Teach when role assignment genuinely helps**: when it shifts the AI's frame of reference in a way that changes the actual content of the response — "respond as a skeptical potential customer" changes what gets said, not just the tone, since it invokes a different perspective than a neutral assistant would default to.
2. **Teach when role assignment is cosmetic and doesn't help**: assigning a role like "expert" or "professional" without any accompanying specific perspective or constraint often changes only surface tone, not substance — the task and context (Modules 3-4) usually matter more than the label.
3. **Teach how to write an effective role assignment** — specific enough to actually shift perspective ("respond as a CFO reviewing this for budget risk" beats "respond as an expert"), and paired with what that role should actually be looking for or optimizing.
4. **Apply to Module 2's real use case** — would a role assignment genuinely help here, and if so, what specific role/framing would actually shift the output?

## Output format

```
WHEN ROLE ASSIGNMENT HELPS: [explanation + example]
WHEN IT'S COSMETIC: [explanation + example]
HOW TO WRITE AN EFFECTIVE ONE: [specific + paired with a perspective/goal]
APPLIED TO USER'S REAL USE CASE: [would this help here, and what specific role/framing]
```

## Handoff

Feeds Module 14's live rewrite if a role assignment is genuinely useful for the user's real prompt.
