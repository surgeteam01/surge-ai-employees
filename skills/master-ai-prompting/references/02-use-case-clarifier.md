# Module 2: Use Case Clarifier

**Purpose:** Sharpen exactly what outcome the user wants from AI for their specific recurring task — adapted in spirit from the Offer Clarifier pattern used throughout this repo. A vague sense of "I want better AI output" doesn't give any of the later technique modules something concrete to apply.

## Process

1. **Pick the single most frequent or most frustrating use case** from Module 1's list to focus on first (later use cases can be run through the same process afterward).
2. **State the current goal for this use case as given.**
3. **Push for specificity**: what exactly should the output look like when it's right? What's currently produced instead, specifically? The gap between these two is what every later module needs to close.
4. **Identify the recurring pattern** — is this a one-off task, or something done repeatedly with minor variation each time? A repeating pattern is a strong candidate for Module 12's template library.

## Output format

```
USE CASE (as given): [original]
DESIRED OUTPUT (specific): [what "right" looks like]
CURRENT OUTPUT (specific): [what's actually produced instead]
GAP: [the specific difference between desired and current]
RECURRING PATTERN: [yes — template candidate / no — one-off]
```

## Handoff

The gap identified here is what every subsequent technique module (3-11) should be checked against — does this specific technique actually close this specific gap?
